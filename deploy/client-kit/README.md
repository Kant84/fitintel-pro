# FitIntel Pro - клиентский комплект (администратор)

Комплект для личного удалённого доступа администратора с другого ПК (ноутбука).

Состав:
- FitIntelDesktop-Setup_v1.6.1.exe - установщик desktop-клиента;
- FitIntel-Client.bat - мастер первого запуска.

## Первый запуск на новом ПК

1. Скопируйте всю папку комплекта на ПК.
2. Запустите: FitIntel-Client.bat http://192.168.101.14
   (адрес - сервер клуба; далее bat запускается просто двойным кликом).
3. При первом запуске установит клиента, создаст ярлык "FitIntel Pro"
   на Рабочем столе и запомнит адрес сервера.
4. Войдите под своей учётной записью.

## Примечания

- Лицензия активируется на сервере один раз; клиент её не требует.
- Вкладку лицензии можно открыть вручную:
  FitIntelDesktop.exe --license (после входа: Настройки - Лицензия).
- Смена адреса сервера: повторный запуск bat с новым параметром.
