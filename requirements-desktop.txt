        "▸ «▶ Фон (плейлист)» — фоновое воспроизведение.\n"
        "   Открывает диалог выбора плейлиста. После выбора:\n"
        "   • сервер переводит зону в состояние playing,\n"
        "   • агент получает playlist и играет первый трек из него,\n"
        "   • дальше треки идут по кругу автоматически.\n"
        "   ТРЕБУЕТ действующую лицензию (см. раздел 11).\n\n"
        "▸ «⏸ Стоп» — остановить фон.\n"
        "   Шлёт на сервер: состояние зоны = stopped + пустой dj_state.\n"
        "   Агент получает «stopped» и паузит ВСЕ деки. Музыка замолкает,\n"
        "   но агент (и mpv) продолжает работать — следующий ▶ Фон стартует\n"
        "   мгновенно.\n"
        "   Если нужен полный стоп — «Плеер: ВЫКЛ» (убьёт все mpv).\n\n"
        "▸ «⚡ Energize» — пиковый режим.\n"
        "   Берёт плейлист с флагом is_energize (в БД) и играет его\n"
        "   на громкости 90. Используется в часы пик, когда зал переполнен.\n"
        "   Срабатывает и автоматически — через СКУД-триггер: если за окно\n"
        "   (по умолчанию 60 мин) зафиксировано больше N входов (по умолчанию\n"
        "   10) — сервер сам вызывает energize для всех local_agent зон.\n"
        "   ТРЕБУЕТ действующую лицензию.\n\n"

        "5. DJ-ПУЛЬТ — ДЕКИ A И B\n"

        "  Z — длительность перехода при сведении (0–30 сек).\n\n"
        "Кнопки загрузки — по 5 на каждый дек:\n\n"
        "▸ «Трек на A / B» — загрузить трек ИЗ ПЛЕЙЛИСТА.\n"
        "   Два модальных диалога: сначала плейлист, потом трек.\n"
        "   Дек готовится НА ПАУЗЕ — текущий эфир не прерывается.\n"
        "   Используйте, когда нужен стандартный трек из библиотеки.\n\n"
        "▸ «Файл на A / B…» — загрузить ЛЮБОЙ файл с диска.\n"

        "   (включая вложенные подпапки). Треки играются по очереди,\n"
        "   по кругу: после последнего — снова первый.\n"

        "   ЗАПРЕЩЕНО выбирать КОРЕНЬ ДИСКА (G:\\ или C:\\) — система\n"
        "   откажет: «Выбран корень диска…». Иначе os.walk обойдёт всю\n"
        "   флешку и подхватит мусор.\n\n"
        "▸ «Эфир A / Эфир B» — ПЕРЕКЛЮЧИТЬ эфир на этот дек.\n"

        "   снимает паузу и ставит мастер-громкость. Если играет — ничего.\n"
        "   Если активный другой дек — плавный кроссфейд: играющий плавно\n"
        "   уходит в 0, новый поднимается от 0 до мастера. Длительность —\n"
        "   значение «Кроссфейд, сек».\n"
        "   Кроссфейд = 0 — мгновенное переключение (без слышимого перехода).\n"
        "   Кроссфейд = 10 — комфортное 10-секундное перекрытие.\n\n"
        "▸ «Мастер-громкость» (ползунок) + цифра справа — общая громкость.\n"

        "▸ «Кроссфейд, сек» — длительность перехода между деками.\n"

        "   5–8 — быстрая смена.\n"
        "   10–15 — плавный микс (дискотека).\n"
        "   20–30 — очень медленный фейд (фоновое настроение).\n\n"

        "   С этого момента агент применяет изменения.\n"
        "   Если ничего не меняли — можно жать смело, хуже не будет.\n\n"
        "▸ «MUTE ALL» (красная) — экстренная тишина.\n"
        "   Обнуляет мастер-громкость (ставит 0) и сразу отправляет пульт.\n"
        "   Возврат: ползунок мастера на 70 (или рабочее значение) и\n"
        "   «Применить пульт».\n"
        "   Используется при ЧП, объявлении, эвакуации.\n\n"

        "9. АВТО-МИКС И КРОССФЕЙД\n"
        "═══════════════════════════════════════════════════════════════\n\n"
        "Как работает (для local_agent):\n"
        "• Агент опрашивает сервер каждые 3 сек (можно уменьшить).\n"
        "• Смотрит: сколько осталось играющему треку (rem).\n"
        "• Если rem < кроссфейд + 1.5 сек — запускает авто-микс:\n"
        "  1) на противоположный дек загружает следующий трек (по очереди\n"
        "     папки или следующий из плейлиста),\n"
        "  2) запускает его на громкости 0 и одновременно плавно поднимает\n"
        "     до мастер-громкости,\n"
        "  3) старый дек плавно уходит в 0,\n"
        "  4) по окончании фейда — старый дек паузится.\n\n"
        "Что получится на слух при кроссфейде 10 сек:\n"
        "• Последние 10 секунд текущего трека начинается следующий.\n"
        "• 3–4 секунды оба звучат одновременно (перекрытие).\n"
        "• 6–7 секунд текущий затихает, новый нарастает.\n"
        "• Никаких «дыр» тишины.\n\n"
        "Если кроссфейд 0 — резкое переключение, без перекрытия.\n"
        "Это нормально для новостей, объявлений, DJ-резки.\n\n"
        "Авто-микс работает ТОЛЬКО если:\n"
        "• активный дек — с папкой (folder_queue) ИЛИ playlist,\n"
        "• в очереди есть следующий трек,\n"
        "• состояние зоны playing.\n\n"
        "Если трек завершился, а сводить некуда (одна папка пустая, нет\n"

        "12. ГОТОВЫЕ АЛГОРИТМЫ\n"
        "═══════════════════════════════════════════════════════════════\n\n"
        "1) УТРО, ОТКРЫТИЕ\n"
        "   «⏵ Плеер: ВКЛ» → выберите зону local_agent →\n"
        "   «▶ Фон» → плейлист «Утро» → EQ: Бас −2.\n"

        "2) ФЛЕШКА ГОСТЯ / ТРЕНЕРА\n"
        "   Воткнуть флешку → «Папка на A…» → выбрать папку на флешке\n"

def _current_title(mw):
    lw = mw.findChild(QListWidget)
    if lw is not None and lw.currentItem() is not None:
        return lw.currentItem().text().strip()
    return ""


def _clean_title(title: str) -> str:
    """Убирает ТОЛЬКО ведущую эмодзи/иконку: '🔔 Уведомления' → 'Уведомления'.
    Пробелы и слэши ВНУТРИ названия ('Музыка/DJ', 'Входы/Выходы') сохраняет."""
    return re.sub(r"^[^0-9A-Za-zА-Яа-яЁё]+", "", title).strip()


def _active_subtab_title(mw) -> str:
    """Инструкция активной подвкладки. Если для самой вложенной подвкладки
    нет текста — откат на внешнюю вкладку (старое поведение, без заглушки)."""
    stack = getattr(mw, "stack", None)
    if stack is None:
        return ""
    cur = stack.currentWidget()
    if cur is None:
        return ""
    from PyQt6.QtWidgets import QTabWidget
    tabs = []
    for tw in cur.findChildren(QTabWidget):
        depth, pp = 0, tw.parentWidget()
        while pp is not None:
            depth += 1
            pp = pp.parentWidget()
        tabs.append((depth, tw))
    tabs.sort(key=lambda x: x[0])  # от внешних к вложенным
    titles = [_clean_title(tw.tabText(tw.currentIndex())) for _, tw in tabs if tw.count()]
    for t in reversed(titles):  # сначала самая вложенная
        if t in HELP_TEXTS or t in _ALIASES:
            return t
    return titles[-1] if titles else ""  # внешняя вкладка — как раньше


def show_help(mw):
    """Открывает прокручиваемое окно инструкции вместо QMessageBox.
    В хабах — инструкция активной ПОДВКЛАДКИ, не общая."""
    title = _active_subtab_title(mw) or _clean_title(_current_title(mw))
    title = _ALIASES.get(title, title)
    text = HELP_TEXTS.get(title, DEFAULT_HELP)
    dlg = QDialog(mw)
    dlg.setWindowTitle("Инструкция: " + (title or "экран"))
    dlg.resize(750, 650)
    dlg.setMinimumSize(700, 550)
    dlg.setStyleSheet("""
        QDialog { background-color: #0f172a; }
        QTextEdit { background: #1e293b; border: 1px solid #334155; border-radius: 8px; padding: 12px; color: #e2e8f0; font-family: 'Segoe UI', sans-serif; font-size: 13px; }
        QPushButton { background: linear-gradient(135deg, #06b6d4, #0891b2); border: none; border-radius: 6px; padding: 10px 32px; font-weight: 600; color: white; }
        QPushButton:hover { opacity: 0.85; }
    """)
    v = QVBoxLayout(dlg)
    v.setContentsMargins(16, 16, 16, 16)
    te = QTextEdit()
    if text.lstrip().startswith("<"):
        te.setHtml(text)
    else:
        te.setPlainText(text)
    te.setReadOnly(True)
    v.addWidget(te, 1)
    b = QPushButton("Закрыть")
    b.clicked.connect(dlg.accept)
    v.addWidget(b)
    dlg.exec()


def open_client_chat(mw):
    lw = mw.findChild(QListWidget)
    if lw is not None:
        for i in range(lw.count()):
            if "MAX" in lw.item(i).text():
                lw.setCurrentRow(i)
                return
    QMessageBox.information(mw, "MAX", "Вкладка «MAX сообщения» появится после перезапуска клиента.")


def _logs_tail(lines=40):
    for base in (os.getcwd(), os.path.dirname(os.getcwd())):
        files = glob.glob(os.path.join(base, "logs", "client_*.log"))
        if files:
            newest = max(files, key=os.path.getmtime)
            try:
                with open(newest, encoding="utf-8", errors="replace") as f:
                    return newest + "\n" + "".join(f.readlines()[-lines:])
            except Exception:
                pass
    return "Логи не найдены"

def install_help(mw):
    menu = mw.menuBar().addMenu("Помощь")
    menu.addAction("Инструкция по экрану (F1)", lambda: show_help(mw))
    menu.addAction("Чат с клиентами (MAX)", lambda: open_client_chat(mw))
    menu.addAction("Поддержка разработчика (MAX)", lambda: open_support(mw))
    sc = QShortcut(QKeySequence("F1"), mw)
    sc.activated.connect(lambda: show_help(mw))
    btn = QPushButton(" Инструкция")
    btn.setToolTip("Инструкция по текущему экрану (F1)")
    btn.clicked.connect(lambda: show_help(mw))
    try:
        mw.statusBar().addPermanentWidget(btn)
    except Exception:
        pass

def install_f1(widget, key: str):
    """Включает F1 в любом QDialog: показывает HELP_TEXTS[key]."""
    from PyQt6.QtWidgets import QWidget as _QW
    def _kp(event):
        from PyQt6.QtCore import Qt
        if event.key() == Qt.Key.Key_F1:
            show_help_text(widget, key)
        else:
            _QW.keyPressEvent(widget, event)
    widget.keyPressEvent = _kp
