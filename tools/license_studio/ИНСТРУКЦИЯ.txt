=====================================================
 FitIntel License Studio — ИНСТРУКЦИЯ
=====================================================

ЧТО ЭТО
-------
Программа генерирует лицензионные ключи для клубов,
которым ты продаёшь FitIntel Pro. Только для владельца.
Ключ = тариф + срок + лимит клиентов + название клуба,
подписанные твоим секретом. Подделать невозможно.

ПОЛЯ ОКНА (сверху вниз)
-----------------------
1. Мастер-секрет — главный секрет программы.
   Создаётся один раз при первом запуске
   (файл license_master.key). НИКОМУ НЕ ПОКАЗЫВАЙ.
   Его надо скопировать в файл .env сервера:
       LICENSE_SECRET=<этот секрет>
   и перезапустить сервер — тогда десктоп клуба
   сможет проверять ключи (экран "Лицензия").

2. Тариф (выпадающий список) — что купил клуб:

   Тариф      Клиентов   Цена/мес    Что включено
   ----------------------------------------------------------
   Freemium   до 50      0 руб       CRM, виджет, расписание
   Lite       до 100     3 000 руб   + онлайн-запись, push
   Start      до 300     7 000 руб   + СКУД, платежи
   Pro        до 500     12 000 руб  + аналитика, white-label
   Enterprise без лимита 25 000 руб  + мультитенантность, API, SLA

   Ставь тот тариф, за который клуб заплатил.

3. Клиентов (число) — лимит клиентов по договору.
   Обычно совпадает с тарифом (50/100/300/500),
   для Enterprise можно поставить 99999.

4. Дата — до какого числа действует лицензия.
   Обычно +1 год от оплаты.

5. Название клуба — для учёта (кому выдана).

КАК ВЫДАТЬ ЛИЦЕНЗИЮ КЛУБУ
-------------------------
1. Заполни тариф, лимит, дату, название клуба.
2. Нажми "Сгенерировать лицензию".
3. Ключ появится в поле и запишется в реестр (таблица).
4. Скопируй ключ и отправь клубу (почта/мессенджер).
5. Клуб вставляет ключ: десктоп -> экран "Лицензия"
   -> "Проверить".

ПРОВЕРКА КЛЮЧА
--------------
Вставь ключ в поле -> "Проверить ключ".
Покажет: тариф, срок, клуб, действителен ли.

РЕЕСТР ВЫДАННЫХ
---------------
Все ключи в таблице + файле licenses_issued.json.
"Экспорт реестра CSV" — выгрузка для учёта/бухгалтерии.

БЕЗОПАСНОСТЬ
------------
- license_master.key — НЕ УДАЛЯТЬ. Потеряешь = старые
  ключи перестанут проверяться.
- Если секрет утёк: удали license_master.key, запусти
  заново (создастся новый), обнови LICENSE_SECRET в .env,
  перевыпусти ключи клубам.
- Папку License Studio не коммить в git, не выкладывать.
