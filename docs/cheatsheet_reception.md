# 🏠 Шпаргалка: Ресепшен / Кассир

## Доступные экраны
✅ Главная, Клиенты, Входы/Выходы, Абонементы, Бухгалтерия (Платежи), Расписание, Настройки, Face ID, Браслеты/Карты

## Ключевые задачи
| Задача | Как сделать |
|--------|-------------|
| Впустить клиента вручную | «Входы/Выходы» → «🟢 Впустить» → клиент, способ, зона |
| Выпустить | «Входы/Выходы» → строка ACTIVE → «🔴 Выпустить» |
| Найти клиента | «Клиенты» → поиск по ФИО/телефону |
| Привязать браслет | «Браслеты/Карты» → «💾 Привязать к клиенту» |
| Пробить чек | «Платежи» → «✓ Подтвердить» (смена открыта) |
| Проверить Face ID | «Face ID» → «Движок Face ID» |

## Важно
- 🎯 Турникет по карте/QR/Face ID работает автоматически
- ⚠️ «Шкафчик закрыт» — клиенту нужно открыть шкафчик перед выходом
- 📞 Сомнения — сверяйте по телефону в «Клиентах»
