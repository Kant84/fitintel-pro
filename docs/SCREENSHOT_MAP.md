## Правила
1. Переименование — по таблице, без пропусков; имена не меняем (на них ссылаются гайд и KB).
2. Вес: 130 PNG ~25–40 МБ. Для git рекомендуется сжать (например, pngquant/oxipng до уровня «крупный интерфейс читаем») — цель < 10 МБ суммарно; альтернатива — хранить оригиналы вне репо, в репо только сжатые.
3. Новые скриншоты (окна ошибок и т.п.) — именовать по той же схеме scr-<тема>-<NN>, продолжая нумерацию темы.
