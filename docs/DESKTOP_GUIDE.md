# Руководство по desktop-клиенту FitIntel Pro (v1.5.3) — ПОЛНАЯ ВЕРСИЯ

Каждая кнопка, поле и элемент каждого экрана — с объяснением: что делает, что произойдёт после нажатия, какие ошибки бывают.
Места для скриншотов: **[СКРИН N]**.

# ЧАСТЬ 0. УСТАНОВКА И ПЕРВЫЙ ЗАПУСК

## 0.1 Установка программы

**[СКРИН 1: файл установщика] [СКРИН 2: приветствие Setup]**

1. Получите **`FitIntelDesktop-Setup_v1.5.3.exe`** (≈107 МБ). Проверьте хеш (должен совпасть с `RELEASES.md`):
   ```powershell
   Get-FileHash .\FitIntelDesktop-Setup_v1.5.3.exe -Algorithm SHA256
   ```
2. Запустите двойным щелчком. **Администраторские права не требуются.**
3. Мастер установки (Inno Setup):
   - **«Далее»** на экране приветствия;
   - экран **выбора папки** — по умолчанию «FitIntel Desktop»; «Обзор…» — сменить; **«Далее»**;
   - экран **дополнительных задач** — галочка **«Создать ярлык на рабочем столе»** (по желанию); **«Далее»**;
   - **«Установить»** — копирование файлов (≈1 минута);
   - **«Завершить»** — галочка **«Запустить FitIntel Desktop»** оставьте для старта сразу.
4. Удаление: «Параметры Windows → Приложения» → FitIntel Pro Desktop → «Удалить».
5. Обновление: запустите новый Setup — ставится поверх, настройки сохраняются.

💡 **Портабельный вариант:** `FitIntelDesktop.exe` (onefile) можно не устанавливать — положите в любую папку и запускайте. Настройки лежат рядом: `client_settings.json`, `connections.json`.

## 0.2 Первый запуск — адрес сервера (один раз на компьютере)

**[СКРИН 3: окно «Подключение к серверу»]**

Окно **«FitIntel Pro — Подключение к серверу»** появляется, только если программа запущена впервые (нет `client_settings.json`). Текст: «Введите адрес сервера вашего клуба. Примеры: http://192.168.0.10, http://fit.yourclub.ru. Адрес сохранится на этом компьютере».

- Поле ввода — впишите адрес из письма/от администратора: `http://192.168.0.10` или `http://fit.yourclub.ru`. Окончание `/api/v1` программа допишет сама.
- **«OK»** — сохранить и продолжить. Создастся профиль подключения «Сервер клуба».
- **«Отмена»** — программа запустится с адресом по умолчанию `http://localhost:8001/api/v1` (будет «Сервер недоступен», если локального сервера нет). Адрес можно задать позже в «Подключениях» (раздел 28).

## 0.3 Активация лицензии (только новый сервер)

**[СКРИН 4: окно активации]**

Перед окном входа программа спрашивает сервер `/license/status`. Если лицензия **не активирована** — откроется окно **«Активация лицензии»** (на остальных компьютерах клуба его не будет).

Текст в окне: «Первый запуск системы. Введите лицензионный ключ из письма. Логин главного администратора: SuperAdmin, пароль — тот, что указан в письме».

- **Поле ввода** — вставьте ключ целиком (начинается с `FIPRO-`). В письме: Ctrl+A → Ctrl+C, здесь: Ctrl+V.
- **«Активировать и войти»** — программа разберёт ключ (логин+пароль изнутри), активирует лицензию на сервере и сразу войдёт в систему.
- **«У меня уже есть доступ»** — пропустить активацию, перейти к обычному входу.

Сообщения об ошибках (красным под кнопками):
- «Ключ должен начинаться с FIPRO-» — вставлен не ключ;
- «Ключ повреждён при копировании — выделите поле целиком (Ctrl+A → Ctrl+C)» — копируйте заново, целиком;
- «В ключе нет пароля — сгенерируйте лицензию новой версией Studio»;
- «Сервер отклонил: 403» — лицензия уже привязана к другому серверу → нужен новый ключ;
- «Нет связи с сервером: …» — проверьте адрес (шаг 0.2).

## 0.4 Выбор информационной базы (если профилей больше одного)

**[СКРИН 5: окно баз]**

Если в `connections.json` **один** профиль — окно пропускается (автоподключение). Иначе — окно «Выбор информационной базы» (по образцу 1С):

- **Список баз** (слева) — щелчок выбирает; двойной щелчок = «Подключить».
- **«1. Подключить»** — применить выбранный профиль: записать его адрес/логин/пароль в `client_settings.json` и продолжить.
- **«2. Добавить…»** — новый профиль (окно из раздела 28).
- **«3. Изменить…»** — правка выбранного профиля.
- **«4. Удалить»** — удалить профиль (с подтверждением).
- **«? Справка»** — текстовая справка о профилях подключения.
- **«Выход»** — закрыть программу.

## 0.5 Вход в систему

**[СКРИН 6: окно авторизации]**

Элементы окна:
- **«Логин»** — поле ввода (подсказка-плейсхолдер «admin»).
- **«Пароль»** — поле с точками (плейсхолдер «••••••»).
- **«Запомнить меня»** (галочка) — сохранить логин/пароль на этом ПК (только своём!). При следующем запуске поля будут заполнены.
- **«Войти»** (зелёная кнопка) — войти. Клавиша **Enter** в любом поле — то же самое. На время входа кнопка блокируется и пишет «Вход...».
- **Строка статуса** (под кнопкой, красным) — ошибки.
- **Подвал** — «© 2026 ИП Санакин А.В. | FitIntel Pro v1.5.3».

Ошибки входа:
- «Введите логин и пароль» — пустое поле;
- «Ошибка: Неверный логин или пароль. Осталось попыток: N» — неверные данные (проверьте раскладку и Caps Lock);
- «Аккаунт заблокирован. Попробуйте позже» / «Аккаунт заблокирован на 5 минут после 5 неудачных попыток» — блокировка, подождите;
- «Сервер недоступен…» — не тот адрес/сеть.

## 0.6 Принудительная смена пароля (первый вход / сброс)

**[СКРИН 7: окно смены пароля]**

Если у учётки флаг смены пароля, после входа откроется **«Смена пароля — Обязательно»**:

- Жёлтая плашка: «Это ваш первый вход. Для безопасности смените пароль».
- **«Старый пароль»** — временный из письма/от администратора.
- **«Новый пароль»** — минимум 8 символов.
- **«Подтверждение»** — новый пароль повторно.
- **«Сохранить и войти»** — отправить на сервер.
- Ошибки: «Пароль минимум 8 символов», «Пароли не совпадают», «Неверный текущий пароль». Без успешной смены в систему не пустит.

## 0.7 Главное окно — что вы видите после входа

**[СКРИН 8: главное окно]**

- **Шапка:** «FitIntel Pro» слева; справа — «Имя | роль» и кнопка **«Выход»** (красная обводка; спросит «Вы уверены…?» → Да/Нет).
- **Меню слева (sidebar, 180 px):** список разделов, сформированный сервером под вашу роль. Подсветка текущего — зелёной полосой.
- **Рабочая область справа** — выбранный раздел.
- **Строка состояния снизу:** «Сервер подключён | FitIntel Pro v1.5.3»; при потере связи — «Сервер недоступен — проверьте бэкенд». Проверка каждые 10 секунд. Справа в ней — кнопка **«❓ Инструкция»**.

# ЧАСТЬ 1. МЕНЮ И ОБЩИЕ ЭЛЕМЕНТЫ (применяются везде)

## 1.1 Меню «Файл»

**[СКРИН 9: меню Файл]**

- **«Обновить» (F5)** — перечитать данные на текущем экране (если экран это поддерживает — почти все поддерживают).
- разделитель;
- **«Выход» (Ctrl+Q)** — закрыть программу.

## 1.2 Меню «Вид»

**[СКРИН 10: меню Вид]**

- **«Светлая тема»** — переключить оформление на светлое.
- **«Тёмная тема»** — тёмное неоновое оформление (цвета: циан/маджента на тёмно-синем).
- **«🌗 Переключить тему»** — мгновенно инвертировать текущую тему.
- **«🕐 Табло с часами (полный экран)» (F11)** — см. раздел 29.
- разделитель;
- **«Увеличить шрифт» (Ctrl + «+»)** и **«Уменьшить шрифт» (Ctrl + «−»)** — размер шрифта всего приложения, шаг 1 pt, диапазон 8–18. Сохраняется автоматически.

## 1.3 Меню «Помощь»

**[СКРИН 11: меню Помощь]**

- **«Инструкция по экрану (F1)»** — окно со справкой по текущему разделу (текст прокручивается). **F1** — горячая клавиша из любого места.
- **«Чат с клиентами (MAX)»** — сразу перейти на экран «MAX сообщения».
- **«Поддержка разработчика (MAX)»** — окно: адрес чата MAX; **«Открыть MAX»** — запустить чат; **«Скопировать логи»** — скопировать в буфер последние 40 строк лога (кнопка сменится на «Логи скопированы ✓»); **«Закрыть»**.

## 1.4 Печать и PDF (на экранах с таблицами)

**[СКРИН 12: кнопки Печать/В PDF]**

Внизу многих экранов с таблицами две кнопки:
- **«🖨 Печать»** — откроется предпросмотр печати текущей таблицы → выберите принтер → «Печать». Если таблица пустая — «На этом экране нет данных для печати».
- **«📄 В PDF»** — диалог «Сохранить в PDF» → выберите папку → файл `<Название>.pdf` готов, сообщение «Сохранено: путь».

## 1.5 RFID Монитор (плашка при поднесении карты)

**[СКРИН 13: RFID-плашка]**

При поднесении карты к USB-считывателю появляется тёмная плашка (всегда поверх окон; перетаскивается мышкой за заголовок — позиция запоминается):
- **«🔷 RFID Монитор (перетащите мышкой)»** — заголовок;
- **«UID:»** — уникальный номер карты;
- **«Сектор: 0»**;
- **«Тип карты:»** — расшифровка содержимого: «Пустая карта», «Карта доступа», «Карта администратора», «Сервисная карта», «Не обслуживается», «Карта клиента», «Индивидуальный режим», «Режим удаления», «Сброс замка», «Номер шкафчика N», «Неизвестный формат»;
- **«Шкафчик:»** — «🔒 Шкафчик №N» (розовым) или «🔓 Шкафчик не назначен» (серым);
- **«Клиент:»** — имя (зелёным, если найден в базе; красным «Неизвестный»);
- **«block_1:»** — сырые данные сектора (мелким шрифтом).
Карту убрали — плашка сама исчезает.

## 1.6 Устройство форм (FormDialog)

Почти все формы программы устроены одинаково: поля с подписями, пометка **\*** — обязательное поле; выпадающие списки; внизу **«OK»/«Сохранить»** (применить) и **«Cancel»/«Отмена»** (закрыть без изменений). Значения с пустыми обязательными полями не отправляются — появится предупреждение с текстом.

# ЧАСТЬ 2. ЭКРАНЫ (каждая кнопка)

## 2. Главная / Аналитика

**[СКРИН 14: Обзор] [СКРИН 15: Прогноз] [СКРИН 16: Тепловая карта] [СКРИН 17: AI Отток]**

«Главная» и «Аналитика» — это один экран из четырёх подвкладок (их можно перетаскивать мышкой, меняя порядок).

### Подвкладка «📊 Обзор»
- Пять карточек (только чтение): **«Посещений сегодня»**, **«Выручка сегодня, ₽»**, **«Прогноз недели, ₽»**, **«Клиентов в риске»**, **«К прошлой неделе, %»** (со стрелкой ▲/▼).
- Строка **«Сегменты риска: Низкий: N | Средний: N | Высокий: N (всего: N)»** — распределение по вероятности оттока.
- **«🔄 Обновить»** — перечитать все цифры.
- **«🧮 Пересчитать историю (56 дн)»** — собрать статистику за 56 дней (нужно один раз после установки/импорта; выполняется до минуты; потом обновит карточки).

### Подвкладка «📈 Прогноз»
- **«Метрика:»** — выпадающий список: Посещаемость / Выручка / Новые клиенты / Риск оттока.
- **«Дней:»** — счётчик 1–90 (по умолчанию 7).
- **«📈 Построить прогноз»** — запрос к ИИ; на графике: голубая линия — факт, розовый пунктир — прогноз, зелёная вертикаль — «сегодня». Если данных мало — сообщение «Прогноз: …» (нужно ≥14 дней истории).

### Подвкладка «🔥 Тепловая карта»
- **«🔄 Загрузить тепловую карту»** — сетка 7 дней (Пн–Вс) × 24 часа: чем ярче ячейка, тем больше посещений. Пусто — «Нет данных».

### Подвкладка «🤖 AI Отток»
- **«🎓 Обучить / дообучить»** — обучить модель. Успех: «Обучено! Примеров: N, точность: X». Мало данных: «Мало данных для обучения».
- **«📋 Обновить список риска»** — таблица: Клиент ID, Вероятность оттока, Дней без визитов, Визитов за 30 дн. Пусто — «Нет данных».
- **«✅ Сверить прогнозы с фактом»** — «Сверено: N, проверенная точность: X».
- Строка **«Модель: обучена/не обучена | примеров: N | точность: X»**.
- Внизу — график **«Рост точности модели»**.

## 3. Клиенты

**[СКРИН 18: экран Клиенты] [СКРИН 19: форма клиента]**

Таблица (показывает **только активных**): ФИО | Телефон | Email | Категория | Статус | Создан. Цвета статуса: Активен — зелёный, Неактивен — красный.

- **Поиск** (поле слева вверху) — фильтрация на лету по ФИО, телефону, email. Очистите поле — снова весь список.
- **«＋ Добавить»** — форма «Новый клиент»:
  - **Фамилия\*** — обязательно;
  - **Имя\*** — обязательно;
  - **Отчество** — необязательно;
  - **Телефон\*** — с `+7`, формат свободный;
  - **Email\*** — обязательно (связывает клиента с личным кабинетом);
  - **Пол** — список: Мужской / Женский / Не указан;
  - **Дата рождения** — `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД` (двузначный год `ДД.ММ.ГГ` станет `20ГГ`); неверный формат → «Неверный формат даты: …»;
  - **«OK»** — создать. Пустое обязательное поле → «Заполните обязательные поля: фамилия, имя, телефон, email». Дубль email/телефона → ошибка сервера текстом.
- **«✎ Изменить»** — форма правки (те же поля, заполненные текущими значениями) → «OK» → «Обновить» список.
- **«⊘ Деактивировать»** — подтверждение → клиент пропадёт из списков, история сохранится.
- **«🗑 Удалить»** — подтверждение «УДАЛИТЬ клиента … безвозвратно?» → технически выполняется деактивация на сервере (физически не удаляется, чтобы не потерять историю), клиент сразу исчезает из таблицы.
- **«Обновить»** — перечитать список с сервера.
- **Двойной клик по строке** = «✎ Изменить».

## 4. Абонементы

**[СКРИН 20: экран] [СКРИН 21: продажа] [СКРИН 22: заморозка]**

Таблица: Клиент | Тариф | Начало | Конец | Статус | Осталось визитов. Статусы цветом: ACTIVE зелёный, FROZEN синий, EXPIRED красный, CANCELLED серый.

- **«＋ Продать абонемент»** — форма «Продажа абонемента»:
  - **Клиент\*** — список «Фамилия Имя (телефон)» (первые 200);
  - **Тариф\*** — список активных тарифов «Название — цена RUB»;
  - **Дата начала (ГГГГ-ММ-ДД)\*** — по умолчанию сегодня;
  - **«OK»** — создано; дата окончания посчиталась по длительности тарифа. Нет клиентов/тарифов → «Нужны клиенты и тарифы».
- **«❄ Заморозить»** (только ACTIVE) — форма «Заморозка»:
  - **Заморозить до (ГГГГ-ММ-ДД, пусто = без срока)**;
  - **Причина** — свободный текст;
  - «OK» → статус FROZEN. При разморозке срок сдвинется на замороженные дни — дни не сгорают.
- **«▶ Разморозить»** — без формы: сразу выполняется → статус ACTIVE.
- **«Обновить»** — перечитать.

## 5. Входы/Выходы

**[СКРИН 23: экран] [СКРИН 24: форма впуска]**

Сверху три карточки-счётчика: **Сегодня / Неделя / Месяц** (число визитов). Поиск фильтрует по ФИО, телефону, статусу. Таблица: № | Клиент (ФИО) | Телефон | Способ входа | Время входа | Статус (ACTIVE зелёным, COMPLETED серым).

- **«🟢 Впустить»** — форма «Впустить клиента (вход)»:
  - **Клиент\*** — список клиентов;
  - **Способ** — список: Ручной (ресепшен) / Карта / QR / Face ID;
  - **Зона** — текст, по умолчанию `main`;
  - «OK» → создан визит (проверки сервера: нет ли уже активного входа — «Клиент уже находится в клубе»; активный абонемент; лимит визитов; время тарифа). Если настроен турникет — уйдёт команда открытия (её отсутствие не считается ошибкой).
- **«🔴 Выпустить»** — выделите строку со статусом ACTIVE → «Открыть выход для: ФИО? Визит будет закрыт.» → Да: визит закрывается (время выхода, длительность), турникет открывается. Не ACTIVE → ««Выпустить» можно только для визита со статусом ACTIVE». Ничего не выделено → «Выделите в таблице строку с активным визитом».
- **«Завершить»** — то же, но **без открытия турникета** (клиент ушёл, выход не записался). Не ACTIVE → «Этот визит уже закрыт».
- **«Обновить»** — перечитать.

## 6. Расписание

**[СКРИН 25: экран] [СКРИН 26: новая запись]**

### Кнопки платежей (первый ряд)
- **«Обновить»** — перечитать клиентов, платежи и проводки.
- **«＋ Провести платёж»** — форма «Провести платёж»:
  - **Сумма** — число (запятая или точка); ≤0 → «Сумма должна быть положительным числом»;
  - **Способ оплаты** — список: Наличные / Карта / СБП (по QR) / Перевод / Онлайн-оплата / Абонемент (зачёт) / QR-код / Внутренний баланс / Другое;
  - **Направление** — список: Приход (клиент платит) / Расход (выдача денег);
  - **Категория** — список: (пусто) / Абонемент / Услуга / Товар / Прочее;
  - **Комментарий** — свободный текст (попадёт в чек и проводку);
  - **«OK»** — платёж создан со статусом **«Ожидает»** (в кассу ещё не входит). Если смена закрыта — сверху красное предупреждение: чек не пробьётся, пока не «Открыть смену».
- **«✓ Подтвердить»** — выделите «Ожидает» → сервер пробивает **фискальный чек** на АТОЛ → статус «Завершён» → деньги в балансе смены → автопроводка. Закрытая смена → «Смена закрыта…» и платёж останется «Ожидает». Уже подтверждённый → «Платёж уже подтверждён или недоступен».
- **«↩ Возврат»** — форма «Возврат платежа»:
  - **Сумма возврата (пусто = полная)** — можно частичную;
  - **Причина возврата \*** — без неё «Причина возврата обязательна»;
  - «OK» → «Возврат оформлен»: уменьшает баланс (нал из наличных, безнал из безналичных) + сторно-проводка.
- **«✕ Отмена платежа»** — «Отменить платёж полностью? Будет оформлен возврат полной суммы.» → Да → возврат с причиной «Отмена платежа».
- **«⇩ Экспорт CSV»** — диалог сохранения → файл `payments.csv` (кодировка UTF-8 с BOM — Excel откроет кириллицу) → «Экспорт сохранён: путь».

### Кнопки кассовой смены (второй ряд)
- **«🔓 Открыть смену»** — открыть смену на сервере. Уже открыта → «Смена уже открыта» (это нормально).
- **«🔒 Закрыть смену»** — закрытая смена не открыта → «Смена уже закрыта»; иначе окно-отчёт: «Закрытая смена: Наличные X / Безнал Y» и «Остаток на кассе (не снят бухгалтером): нал / безнал». Сверьте наличные с ящиком.
- **«💵 Снятие кассы»** — «Снять весь остаток прошлых смен? …» → Да → окно «Снято: Наличные X / Безнал Y» → остаток обнулён. Чужая роль → 403 текстом.
- **«Обновить статус»** — опросить сервер о состоянии смены и балансах.
- **«⚙ Настройки кассы»** — окно «Настройки кассы (АТОЛ)»:
  - сверху в баннере текущие значения: «Сейчас: драйвер X | адрес Y | ОФД Z. Пустые поля = без изменений.»;
  - **Драйвер** — список: АТОЛ / Штрих-М;
  - **Адрес кассы http://IP:порт** — пусто = не менять;
  - **Логин ДТО** — пусто = не менять;
  - **Пароль ДТО** — пусто = не менять;
  - **ОФД** — список: ofd-ru / taxcom / первый-офд / yandex;
  - **«OK»** — «Настройки кассы сохранены» (роль admin, иначе 403).

### Строка балансов (под кнопками)
«Текущая смена — нал: X ₽ | безнал: Y ₽  ||  Остаток прошлых смен (не снят): нал A ₽ | безнал B ₽». Нал и безнал **раздельно, не суммируются**. Считаются только подтверждённые («Завершён») платежи после открытия смены.

Объявление тренера: перед речью — «Пад 1» (джингл), говорите в микрофон — дакинг сам приглушит музыку на 20% громкости и вернёт через 2 сек тишины.
## 29. Табло с часами

**[СКРИН 74: табло]**

Меню **Вид → «🕐 Табло с часами» (F11)**: компактная плашка всегда поверх окон, в верхнем центре экрана: крупное время `ЧЧ:ММ:СС` (циан) + дата + кнопка **«✕»**. **Esc** — закрыть. Можно открыть повторно. Не перехватывает работу.

|---|---|
| Нет нужного раздела в меню | Роли не назначен экран: «Экраны ролей» (администратор). Строгая модель: не отмечено = не видно |

| «Считыватель не найден» | USB; кнопка «🔍 Проверить считыватель» |
| Забыл пароль | Администратор: «Пользователи» → создать/удалить-сбросить; 5 попыток → блокировка 5 мин |

| Логи разработчику | «Помощь → Поддержка разработчика (MAX)» → «Скопировать логи» |
| Сменить тему/шрифт | Меню «Вид» или «Настройки» (Ctrl++/Ctrl−) |
