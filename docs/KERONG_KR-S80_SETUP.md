# 🔒 Настройка Kerong KR-S80 с FitIntel Pro

## 📋 Параметры подключения

| Параметр | Значение | Описание |
|----------|----------|----------|
| Модель | KR-S80 | Шкафчик с RFID |
| Сервер | `http://IP:8001/api/v1/kerong` | API FitIntel Pro |
| Синхронизация | 300 сек (5 мин) | Обновление белого списка |
| Автозакрытие | 5 сек | Время до автоматического запирания |

---

## 🚀 Быстрый старт

### Шаг 1: Регистрация замка в FitIntel Pro

```bash
curl -X POST http://IP:8001/api/v1/kerong/locks/register \
  -H "Content-Type: application/json" \
  -d '{
    "lock_id": "KR-S80-001",
    "model": "KR-S80",
    "lock_type": "cabinet",
    "location": "раздевалка М",
    "group": "man"
  }'
```

### Шаг 2: Настройка замка

В админ-панели замка Kerong:
1. **Сетевые настройки** → введите IP сервера FitIntel Pro
2. **API Endpoint** → `http://IP:8001/api/v1/kerong`
3. **Режим работы** → `hybrid` (офлайн + онлайн)
4. **Интервал синхронизации** → `300` секунд

### Шаг 3: Синхронизация карт

Замок автоматически запросит список авторизованных карт:

```bash
curl -X POST http://IP:8001/api/v1/kerong/sync \
  -H "Content-Type: application/json" \
  -d '{"lock_id": "KR-S80-001"}'
```

**Ответ:**
```json
{
  "lock_id": "KR-S80-001",
  "authorized_cards": ["1D870731000001", "..."],
  "revoked_cards": [],
  "config": {
    "sync_interval_sec": 300,
    "auto_lock_sec": 5,
    "model": "KR-S80"
  }
}
```

## 🔐 Логика работы

### Режим Hybrid (рекомендуется)

```
┌─────────────┐     sync (каждые 5 мин)    ┌─────────────────┐
│   KR-S80    │ ←───────────────────────── │  FitIntel Pro   │
│  (offline)  │   получить whitelist       │   (порт 8001)   │
└─────────────┘                            └─────────────────┘
       │
       │ карта поднесена
       ↓
┌─────────────┐     auth (если нет в whitelist)   ┌─────────────────┐
│   KR-S80    │ ─────────────────────────────────→ │  FitIntel Pro   │
│  (проверка) │                                    │  (онлайн чек)   │
└─────────────┘ ←───────────────────────────────── └─────────────────┘
```

### Режим Offline

- Замок хранит whitelist локально (до 10 000 карт)
- Работает без интернета
- Синхронизация раз в 5 минут при наличии сети

### Режим Online

- Каждое открытие → запрос к серверу
- Максимальная безопасность
- Требует стабильного интернета

## 📡 API Endpoints

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/kerong/auth` | POST | Проверка карты при открытии |
| `/kerong/sync` | POST | Синхронизация whitelist |
| `/kerong/locks` | GET | Список замков |
| `/kerong/locks/register` | POST | Регистрация нового замка |

---

## ⚠️ Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Замок не открывается | Проверьте `granted: true` в ответе `/auth` |
| Синхронизация не работает | Проверьте доступность сервера по IP |
| Карта не найдена | Убедитесь, что карта привязана в FitIntel Pro |
| Абонемент просрочен | Продлите абонемент клиенту |
| Нет связи с сервером | Переключите замок в offline-режим |

## 🔧 Технические характеристики KR-S80

- **Питание:** 3xAAA батарейки (до 2 лет) или USB-C
- **RFID:** 13.56 MHz (Mifare Classic/DESFire)
- **Емкость whitelist:** 10 000 карт
- **Сеть:** WiFi 2.4GHz / Ethernet (опционально)
- **Корпус:** ABS пластик, влагозащита IP54
