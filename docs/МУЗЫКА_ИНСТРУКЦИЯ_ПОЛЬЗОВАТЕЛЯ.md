# FitIntel Pro — Музыка/DJ: инструкция пользователя

Два сценария: А) свой плеер на ПК клуба (без провайдера — рекомендуется);
Б) существующая «коробка» провайдера. Повседневная работа — одинакова (пульт).

═══════════════════════════════════════════════════════════════
СЦЕНАРИЙ А. Свой плеер на ПК зала (без провайдера)
═══════════════════════════════════════════════════════════════
Что понадобится: ПК (Windows 10/11 или Linux) в зале, колонки к его звуковухе,
интернет/локальная сеть до сервера FitIntel, папка с музыкой (MP3/FLAC).

ШАГ 1. Музыка. Создайте папку, например C:\music\club:
  C:\music\club\utro\01.mp3        (спокойные треки)
  C:\music\club\pik\01.mp3         (энергичные)
  C:\music\club\sfx\siren.mp3      (сэмплы для падов)

ШАГ 2. Плеер mpv:  winget install mpv   (проверка: в cmd «mpv --version»).

ШАГ 3. Микрофон (опционально, для авто-дакинга):
  pip install sounddevice

ШАГ 4. Создание зоны. От имени администратора (curl на сервер или попросить
админа): POST /api/v1/music/zones {name: "Тренажёрный зал", provider_type:
"local_agent"} → сохраните agent_token (показывается один раз!).

ШАГ 5. Агент (второе окно консоли):
  python scripts\music\fitintel_player_agent.py ^
    --server http://СЕРВЕР/api/v1 --token ТОКЕН --lib C:\music\club --mic
  Сначала проверьте с --dry-run --debug (логика без звука).
  Успех = строки «DECK A|B | загружен…», «DJ | применено…», «PAD | …».

ШАГ 6. Автозапуск (чтобы работало после перезагрузки ПК), от администратора:
  winget install nssm
  nssm install FitIntelDJAgent "C:\...\python.exe" ^
    "C:\...\scripts\music\fitintel_player_agent.py --server http://СЕРВЕР/api/v1 ^
     --token ТОКЕН --lib C:\music\club --mic"
  nssm set FitIntelDJAgent AppStdout C:\music\logs\agent.log
  nssm set FitIntelDJAgent AppStderr C:\music\logs\agent.log
  nssm set FitIntelDJAgent Start SERVICE_AUTO_START
  nssm start FitIntelDJAgent
  (Для Linux — systemd-юнит из технической документации.)

ШАГ 7. Пульт. Desktop → «🎧 Музыка/DJ» → «Обновить» → выбрать зал.

═══════════════════════════════════════════════════════════════
СЦЕНАРИЙ Б. «Коробка» провайдера уже стоит в клубе
═══════════════════════════════════════════════════════════════
1. Попросите провайдера: есть ли у коробки HTTP-управление (адрес, порт, команды).
2. Админ создаёт зону: provider_type "external", provider_config
   {"base_url": "http://IP-коробки:порт", "cmd_path": "/команды"}.
3. Базовые кнопки (Фон/Стоп/Громкость/Energize/Пады) уйдут на коробку сразу.
4. DJ-деки/EQ — только если у коробки есть такие команды (чаще нет): тогда
   живой пульт делайте по Сценарию А на втором входе микшера.

═══════════════════════════════════════════════════════════════
ПОВСЕДНЕВНАЯ РАБОТА (пульт «🎧 Музыка/DJ»)
═══════════════════════════════════════════════════════════════
Обновить — перечитать зоны/плейлисты/сэмплы/лицензию.
▶ Фон (плейлист) — фоновое звучание зоны; ⏸ Стоп — остановить.
⚡ Energize — энергичный плейлист + громкость 90 (сам срабатывает по потоку
  входов через турникеты — порог настраивает администратор).

DJ-ПУЛЬТ:
  «Загрузить трек на A/B» — плейлист → трек. Трек готовится на паузе,
  музыка не прерывается.
  «Эфир → A / Эфир → B» — ПЛАВНОЕ сведение: играющий уходит в тишину, новый
  дек поднимается. Длительность — «Кроссфейд, сек» (0–30).
  «Мастер-громкость» + «Применить пульт» — общая громкость зала.
  MUTE ALL — экстренная тишина (возврат: ползунок обратно + «Применить пульт»).
  Экран «ЭФИР» показывает: дек, мастер, кроссфейд.
  Агент сам сводит треки: к концу трека автоматически подмешивается следующий
  из текущего плейлиста (авто-микс).

ЭКВАЛАЙЗЕР (−12…+12 дБ, отдельно на каждый дек):
  Бас (80 Гц), Середина (1.2 кГц), Верха (6.5 кГц). «Применить EQ» — музыка не
  прерывается, фильтр меняется на лету. Пример: пик вечера — Бас +4…+6.

СЭМПЛЕР (ПАДЫ 1–8):
  Один-шот поверх музыки: джинглы, сирены, сигналы. «＋ Добавить сэмпл» —
  название + путь к файлу (например sfx\siren.mp3) + громкость.
  Серые пады — не назначены.

ЛИЦЕНЗИЯ (строка снизу):
  Учёт договора на коммерческий фон (РАО/ВОИС или провайдер).
  🟢 действует | 🟡 не указана | 🔴 истекла — ФОН ЗАБЛОКИРОВАН (play/Energize
  вернут ошибку). Указание договора — у администратора (экран лицензии/API).

TYPICAL DAY: утро — «▶ Фон» (спокойный плейлист), Бас −2; пик — «⚡ Energize»
(или само по турникетам), живое сведение: трек на B → «Эфир → B»; объявление —
«Пад 1» (джингл) + речь: музыка приглушится сама (дакинг); ЧП — MUTE ALL.

═══════════════════════════════════════════════════════════════
ПРОБЛЕМЫ И РЕШЕНИЯ
═══════════════════════════════════════════════════════════════
Нет звука: 1) агент запущен? (лог agent.log / окно консоли) 2) mpv установлен?
3) Windows-громкость и выход звуковухи 4) «Мастер» на пульте не 0.
«bad token» в логе агента — зону пересоздали/токен скопирован с ошибкой.
Пады молчат — «Обновить сэмплы», файл существует в --lib, путь относительный.
Сведение дёргается — агент перезапустить; проверить, что один агент на зону.
Вкладка не видна — «Экраны ролей»: роли admin/superadmin/owner — галочка music.
«Токен истёк» нигде не появляется — норма: сессия молча обновляется (30 мин
access + 30 дней refresh).
