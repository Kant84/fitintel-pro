## Общая информация

FitIntel Pro поддерживает работу с:
- **RFID-браслетами и картами** (Mifare Classic 1K/4K)
- **Оффлайн-замками** ITC-30, S80F (KERONG)
- **Онлайн-замками** TTLock, KERONG Cloud, Sciener
- **Считыватели** ACS ACR122U, ACR1252, OMNIKEY 5022

> ⚠️ **Важно:** Считыватель должен быть подключён напрямую в USB порт ПК (без хабов и переходников).

## Вкладка «Клиентская карта»

### 1. Выбор клиента
1. Введите ФИО, телефон или ID клиента в поле поиска.
2. Нажмите **«Найти»**.
3. Информация о клиенте отобразится в левой панели.

### 2. Очистка носителя (🔷)
- Поднесите браслет/карту к считывателю.
- Нажмите **«Очистить носитель»**.
- Карта станет «Пустая карта» — готова к привязке.

### 3. Привязка к клиенту (💾)
1. Выберите **Производитель** и **Модель** (например, KERONG → KR-S50).
2. Нажмите **«Привязать к клиенту»**.
3. Поднесите браслет/карту к считывателю.
4. Система считает UID и запишет его в базу данных.
5. Запись появится в таблице **«Носители клиента»** справа.

> 💡 **Если UID уже привязан к другому клиенту** — система автоматически удалит старую запись и создаст новую.

### 4. Сброс к заводским (🗑️)
- Нажмите **«Сброс к заводским»**.
- Поднесите карту — она вернётся к factory default (ключи FFFFFFFFFFFF).

## Вкладка «Программирование замков»

### Подготовка замка (ITC-30 / S80F)

#### Шаг 1: Выбор сектора
- По умолчанию все замки работают на **секторе 0**.
- Если нужно сменить — выберите сектор 0, 1 или 2.

#### Шаг 2: Карта доступа (🛡️)
1. Нажмите **«Карта доступа»**.
2. Поднесите карту к считывателю.
3. Приложите карту к замку (1 писк = успех).

> ⚠️ **Карта доступа должна быть одна на все замки!**

#### Шаг 3: Мастер-карта (👑)
1. Нажмите **«Мастер-карта»**.
2. Поднесите карту к считывателю.
3. Приложите к замку.

> 💡 Мастер-карта открывает замок и сбрасывает клиентскую карту.

#### Шаг 4: Назначить номер (🔢)
1. Введите номер шкафчика в поле **«Номер шкаф...»**.
2. Нажмите **«Назначить номер»**.
3. Поднесите карту к считывателю.
4. Приложите к замку (замок закроется).
5. Приложите ту же карту повторно — замок откроется.

> 💡 Номер автоматически увеличивается на 1 для следующего замка.

#### Шаг 5: Очистка носителя
- После программирования всех замков очистите карту кнопкой **«Очистить носитель»**.
- Карта станет «Пустая карта» и готова к выдаче клиенту.

### Дополнительные режимы

| Кнопка | Назначение |
|--------|-----------|
| 🔐 Режим личный | Переводит замок в индивидуальный режим (только выбранная карта) |
| 🚫 Очистить замок | Удаляет все привязанные карты из замка |
| ⏰ Таймер открытия | Задаёт время автоматического открытия (ЧЧ:ММ) |
| 💥 Перезагрузить замок | Полный сброс замка (все настройки сбрасываются) |
| 📍 Сменить сектор | Переводит замок на другой сектор (0/1/2) |

### Индивидуальный режим
1. Нажмите **«Режим личный»** — запишите на карту.
2. Приложите к замку (2 писка = режим активирован).
3. Приложите **Мастер-карту** — замок заморгает зелёным.
4. Приложите **клиентскую карту** во время мигания — замок запомнит её.

> ⚠️ В индивидуальном режиме замок запоминает максимум 4 карты.

## Вкладка «Онлайн-замки»

### Создание цифрового ключа

1. Введите **ID клиента** (UUID из системы).
2. Выберите **Провайдер**: TTLock / KERONG Cloud / Sciener.
3. Введите **Lock ID** — ID замка в облаке провайдера.
4. Для TTLock укажите **временный пароль** (опционально).
5. Нажмите **«Создать цифровой ключ»**.

Ключ сохранится в базе данных и будет доступен для управления через API.

## Типичные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| «Носитель не обнаружен» | Считыватель не видит карту | Поднесите карту плотнее к считывателю |
| «Ошибка аутентификации сектора» | Неправильный ключ или сектор заблокирован | Используйте Key A, проверьте сектор |
| «RFID-метка уже привязана» | UID существует в БД | Нажмите «Привязать» повторно — система перезапишет |
| «Данные должны быть 32 hex» | Неверная длина HEX-строки | Проверьте, что данные ровно 32 символа |
| Считыватель не найден | Не подключен USB | Проверьте USB-подключение, перезагрузите ПК |
| 408 Request Timeout | Карта не поднесена вовремя | Поднесите карту быстрее (в течение 10 сек) |

## Технические требования

### Сервер
- Windows Server 2019+ / Ubuntu 24.04+ / Debian 12+
- Python 3.11+
- PostgreSQL 14+

### Клиент (ПК с считывателем)
- Windows 10/11
- USB-порт 2.0+
- Драйвер ACS ACR1252 (устанавливается автоматически)

### Поддерживаемые носители
- Mifare Classic 1K (S50)
- Mifare Classic 4K (S70)
- Браслеты KERONG KR-S50 / KR-S80 / KR-S100
- Пластиковые карты ISO 14443A

### Поддерживаемые замки
- **Оффлайн:** ITC-30, S80F (KERONG)
- **Онлайн:** TTLock, KERONG Cloud, Sciener
