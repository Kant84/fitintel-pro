# 🛡️ Шпаргалка: Суперадминистратор

## Доступные экраны
✅ ВСЕ 18 (включая Лицензию, Экраны ролей, Подключения)

## Ключевые задачи
| Задача | Как сделать |
|--------|-------------|
| Создать пользователя | «Пользователи» → «Создать пользователя» |
| Настроить экраны роли | «Экраны ролей» → роль → чекбоксы → «Сохранить» |
| Матрица прав RBAC | «Роли и права» |
| Проверить лицензию | «Лицензия» — срок, статус, лимиты |
| Подключить устройство | «Устройства» → «Найти устройства» / «Добавить вручную» |
| Уведомления клиентам | «Клиенту» → каналы MAX/Telegram, события, привязки |
| AI-прогноз | «Главная» → график выручки + таблица риска оттока |

## Важно
- ⚠️ «Экраны ролей» нельзя скрыть у себя — защита от самоблокировки
- 🔑 Только вы управляете лицензией и матрицей экранов
- 💾 Регулярный бэкап БД (полный архив: systemd-timer, см. INSTALL_SERVER.md §11)

# 👔 Шпаргалка: Администратор

## Доступные экраны
✅ 17 (все, кроме «Подключения»)

## Ключевые задачи
| Задача | Как сделать |
|--------|-------------|
| Добавить клиента | «Клиенты» → «＋ Добавить» |
| Продать абонемент | «Абонементы» → «＋ Продать абонемент» |
| Заморозить / разморозить | «Абонементы» → «❄ Заморозить» / «▶ Разморозить» |
| Провести платёж с чеком | «Платежи» → «＋ Провести платёж» → «✓ Подтвердить» (смена открыта!) |
| Возврат / отмена | «Платежи» → выделить → «↩ Возврат» / «✕ Отмена» |
| Открыть/закрыть смену | «Платежи» → «🔓 Открыть смену» / «🔒 Закрыть смену» |
| Привязать карту/браслет | «Браслеты/Карты» → найти клиента → «Привязать к клиенту» |
| Записать клиента на услугу | «Расписание» → «＋ Добавить запись» |
| Каналы уведомлений клиентам | «Клиенту» → MAX/Telegram webhook, события |
| Поддержка разработчика | «Помощь» → обращение уходит с логами и версиями |

## Важно
- 📊 «Главная»: красные строки в таблице оттока — позвонить клиенту
- 🚨 Ошибки: «Настройки → Логи»

# 📊 Шпаргалка: Менеджер

## Доступные экраны

## Ключевые задачи
| Задача | Как сделать |

# 🏠 Шпаргалка: Ресепшен / Кассир

## Доступные экраны
✅ Главная, Клиенты, Входы/Выходы, Абонементы, Бухгалтерия (Платежи), Расписание, Настройки, Face ID, Браслеты/Карты

## Ключевые задачи
| Задача | Как сделать |
|--------|-------------|
| Впустить клиента вручную | «Входы/Выходы» → «🟢 Впустить» → клиент, способ, зона |
| Выпустить | «Входы/Выходы» → строка ACTIVE → «🔴 Выпустить» |
| Найти клиента | «Клиенты» → поиск по ФИО/телефону |
| Привязать браслет | «Браслеты/Карты» → «💾 Привязать к клиенту» |
| Пробить чек | «Платежи» → «✓ Подтвердить» (смена открыта) |
| Проверить Face ID | «Face ID» → «Движок Face ID» |

## Важно
- 🎯 Турникет по карте/QR/Face ID работает автоматически
- ⚠️ «Шкафчик закрыт» — клиенту нужно открыть шкафчик перед выходом
- 📞 Сомнения — сверяйте по телефону в «Клиентах»
