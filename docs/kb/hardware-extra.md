## АТОЛ ДТО 10: установка и запуск
Категория: cash-fiscal
Вариации запроса: дто 10 установить, атол драйвер терминал, настройка дто
📷 Скриншоты: scr-rfid-01.png

**Пошагово (ПК кассы, администратор Windows).**
1. Скачайте ДТО 10 с сайта АТОЛ (актуальная версия под вашу ОС).
2. Установите → перезагрузка → запустите службу ДТО (порт 16732 по умолчанию).
3. В веб-интерфейсе ДТО (`http://localhost:16732`) добавьте ККТ (USB/сеть), укажите параметры ФН.
4. В FitIntel: «Платежи → ⚙ Настройки кассы» → адрес `http://<IP-ПК>:16732` → «Сохранить» → тестовый чек 1 ₽.
Ожидание: чек уходит в ОФД, в ДТО виден документ.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## ФН: ресурс, переполнение, замена
Категория: cash-fiscal
Вариации запроса: фн ресурс, фн переполнен, замена фн, 13 месяцев
📷 Скриншоты: scr-rfid-01.png

**Ключевое.** Срок ФН — 13 месяцев (или 36 в некоторых сценариях), ресурс — 30/150 тыс. чеков (модель). При переполнении/истечении ККТ перестаёт пробивать чеки («Касса вернула ошибку»).
**Пошагово.**
1. Мониторинг: веб-интерфейс ДТО → состояние ФН (срок, остаток чеков).
2. Замена: в ДТО — закрыть архив старого ФН (перерегистрация), вставить новый ФН, настроить заново.
3. После замены — тестовый чек, сверка с ОФД.
4. Старый ФН хранить 5 лет.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Считыватели EM-Marine vs MIFARE
Категория: skud-hardware
Вариации запроса: em или mifare, 125 кгц 13.56, какой браслет выбрать
📷 Скриншоты: scr-rfid-01.png

**Сравнение.**
- EM-Marine (125 кГц): дешёвые браслеты/карты, дальность до ~15 см, только UID; ACR1252 НЕ читает.
- MIFARE (13.56 МГц): браслеты дороже, читаются ACR1252 (привязка на ресепшене), защита секторов, классика для клубов.
**Рекомендация.** Единый стандарт MIFARE в клубе: и турникет, и ресепшен. Проверка выданного браслета: приложите к ACR1252 — прочитался = MIFARE.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Контроллер ITC: схема подключения
Категория: skud-hardware
Вариации запроса: контроллер itc подключение, схема контроллера, wiegand на контроллер
📷 Скриншоты: scr-rfid-01.png

**Схема.** Считыватели → клеммы Wiegand (D0/D1/GND/+12В) контроллера; контроллер → LAN клуба (роутер/свитч); реле контроллера → соленоид турникета; вход «fire alarm» → пожарная сигнализация (открытие при тревоге). Питание: отдельный БП 12В; кабель витая пара экранированная для Wiegang при длине >5 м.
**Проверка.** Индикация контроллера (питание/связь), ping контроллера с сервера.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## ITCService: установка и служба
Категория: skud-hardware
Вариации запроса: itcservice установка, служба itc, настройка сервиса
📷 Скриншоты: scr-rfid-01.png

**Пошагово (ПК/сервер Windows или Linux-сервис).**
1. Установите ITCService по документации вендора; убедитесь, что ПК/сервер видит контроллер в LAN.
2. Реестр (Windows): `HKEY_LOCAL_MACHINE\SOFTWARE\ITCService` — `ServerURL` = `http://<IP-сервера-клуба>`, `BasicAuthUser` = `itc`, `BasicAuthPass` = пароль из `deploy/.env` (после ротации — обновить!).
3. Перезапуск службы (`services.msc` → ITCService).
4. Проверка: событие прохода карты появляется в FitIntel («Входы/Выходы»).
Лог: `journalctl -u itcservice` (на nfs работает как служба).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Онлайн-замки: шлюз и доска раздевалок
Категория: skud-hardware
Вариации запроса: шлюз замков, bluetooth шлюз, доска раздевалок связь
📷 Скриншоты: scr-rfid-09.png

**Схема.** Замки Kerong/TTLock ↔ (Bluetooth) ↔ шлюз (Wi-Fi/LAN) ↔ FitIntel. Доска раздевалок показывает состояния (открыт/закрыт, батарея, аренда) и отсылает команды «Открыть».
**Диагностика.**
1. Замок не на доске → привязка (серийник) в настройках + шлюз в сети.
2. «Открыть» не работает → связь шлюза (питание/Wi-Fi), дистанция BT.
3. Батарейка — по индикации; менять сразу, иначе клиент без шкафчика.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

Вариации запроса: камера для face id, требования камеры, установка камеры турникет

**Требования.** Разрешение ≥720p, фронтальное освещение лица (не контровое), высота 1.4–1.7 м, угол анфас; RTSP-поток для IP-камер. USB-камеры — на ПК с desktop/агентом.
**Пошагово (IT).**

2. Подключите (USB/RTSP) → проверьте превью в ОС/VLC.
3. «Face ID → Камеры» → выберите/добавьте источник → «Сохранить».
4. Тестовые проходы в разное время суток (свет!).

## Сеть клуба: требования и топология
Категория: server
Вариации запроса: сеть клуба, топология, требования к сети
📷 Скриншоты: scr-rfid-01.png

**Минимум.** Маршрутизатор/свитч с VLAN-изоляцией (гостевой Wi-Fi отдельно от СКУД/кассы), Cat5e+ для стационарных точек, резервный канал интернета для ОФД/webhook'ов. Сервер — в серверном шкафу/запертой комнате с ИБП.

## ИБП и электропитание оборудования

📷 Скриншоты: scr-rfid-01.png

**Регламент.** Сервер + сетевое оборудование — на ИБП (время автономии 10–15 мин для корректного завершения); ККТ/ПК кассы — ИБП по возможности; турникет — механический разблок при отключении питания (аварийный режим).
