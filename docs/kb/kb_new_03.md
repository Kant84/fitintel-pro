## Как настроить график смен и рассчитать зарплату: штатное расписание, начисления, выплаты с проводками
Ключевые слова: зарплата, график смен, начисления, выплаты, штатное расписание, премии, удержания, расчёт
Формулировки вопроса: как посчитать зарплату тренеру; где график смен; как выдать зарплату с проводками; премия сотруднику
**Ответ.**
Зарплата живёт в «Бухгалтерия → Зарплата» (подвкладка хаба). Цепочка: штатное расписание (должность, ставка) → график сотрудника (карточка сотрудника) → начисления за период → «Выплачено» (выплата с бухгалтерскими проводками). Без штатного расписания начисления не считаются.
**Сценарий 1. Штатное расписание.**
1. «Бухгалтерия → Зарплата → Штатное расписание» → «Добавить должность».
2. Укажите: название, тип оплаты (оклад/часовая/процент), ставку, график по умолчанию.
3. Для тренеров — процент от продаж/посещений: выберите тип «процент» и базу расчёта.
4. Сохраните. Должность появится в карточках сотрудников.
**Сценарий 2. График сотрудника.**
1. «Пользователи» → карточка сотрудника → «График».
2. Расставьте смены по дням недели; ночные и разрывные — отдельными строками.
3. График — основа для часовых начислений и для отметок «на смене».
**Сценарий 3. Начисления за период.**
1. «Бухгалтерия → Зарплата → Начисления» → период → «Рассчитать».
2. Система собирает: оклады по графику, часовые по отработанным, проценты по продажам тренера.
3. Добавьте вручную: премии, штрафы, авансы — отдельными строками с комментарием.
4. Проверьте каждого сотрудника: детализация по дням кликабельна.
5. Ошибка 500 на payroll/calc при расчёте — редкий бэкенд-сбой: повторите расчёт; при повторе — пересоздайте период.
**Сценарий 4. Выплата.**
1. Вкладка «Выплачено» → «Выплатить» по сотруднику или массово.
2. Способ: через кассу (чек не нужен, это не товарная операция) или перевод (безнал).
3. Проводки формируются автоматически — видны в бухгалтерских выгрузках.
4. Запись о выплате — в карточке сотрудника и в «Истории».
**Проверка.**
- Начисления за месяц = оклад/часы + премии − удержания; по каждому сотруднику детализация сходится с графиком.
**Возможные ошибки.**
- Сотрудник не попал в расчёт — нет должности в штатном расписании или не назначен график.
- Часы нулевые — смены не проставлены в графике за период.
- Проценты тренера нулевые — нет продаж/посещений в периоде.
**FAQ.**
- Аванс: строкой «аванс» в начислениях, при окончательном расчёте учитывается автоматически.
**Если не помогло:** «не помогло» + период и логин сотрудника.

## Как устроены QR-входы: динамический QR в MAX, статический для гостя, счётчики «Входы/Выходы"
Ключевые слова: qr, вход по qr, qr-код вход, гостевой проход, динамический qr, счётчики входов
Формулировки вопроса: как клиент проходит по qr; qr не работает на турникете; сколько человек в зале
**Ответ.**
Два вида кода. Динамический QR — в MAX-клиенте клуба, живёт короткое время (параметр клуба QR_TTL, стандартно 2 минуты): безопасно, не передать «вперёд». Статический QR — для гостя/разового посещения: печатается на ресепшене, привязан к конкретному визиту. Оба считываются турникетом/сканером на входе.
**Сценарий 1. Динамический QR для клиента.**
1. Клиент открывает MAX-клиент клуба → «Мой QR».
2. Код обновляется автоматически; старый код мгновенно недействителен.
3. Подносит к сканеру турникета → проход засчитан, в «Входы/Выходы» визит.
**Сценарий 2. Гостевой (статический) QR.**
1. «Входы/Выходы» → «Гостевой пропуск» → выберите тип (разовое посещение/пробное).
2. Система печатает QR и создаёт визит гостя; при необходимости — заявку на менеджера.
3. Гость проходит по QR; при выходе визит закрывается.
**Сценарий 3. Контроль загрузки зала.**
1. «Входы/Выходы» — 5 счётчиков сверху: в зале сейчас, за сегодня, вошли/вышли, гости.
2. Переполнение: «Настройки → Параметры клуба» — лимит зала; при превышении — предупреждение администратору.
**Проверка.**
- QR из MAX проходит турникет; код через 3 минуты уже не проходит (проверка TTL).
- Счётчик «в зале» совпадает с фактом.
**Возможные ошибки.**
- QR не читается: яркость экрана внизу, трещины на защитном стекле сканера, угол поднесения 90°.
- «QR просрочен» на турникете — телефон клиента ушёл в офлайн: пусть откроет клиент заново (код обновится).
- Гость прошёл, но визита нет: сканер гостевого канала офлайн — «Входы/Выходы → ручной ввод».
**FAQ.**
- Можно ли скриншотом QR передать другу? Динамический — нет, протухает. Гостевой — нет, привязан к визиту.
**Если не помогло:** «не помогло» + тип QR и поведение турникета (пищит/молчит/красный).

## Как настроить музыку в зале: DJ-плеер, микширование, дакинг микрофона, энерджайзинг, лицензии РАО/ВОИС
Ключевые слова: музыка, dj, плеер, дакинг, микрофон, энерджайзинг, mute all, рао, воис, фоновая музыка
Формулировки вопроса: музыка не играет в зале; как включить автоматическую музыку; говорю в микрофон музыка не приглушается
**Ответ.**
Вкладка «Музыка/DJ» — плеер зала: подвкладки с треками, деками, настройками звука. Движок — mpv (проигрыватель), поэтому часть проблем — диагностика mpv. Отдельная тема — лицензии РАО/ВОИС: публичное исполнение фонограмм в клубе требует договоров; поля для номеров договоров — в настройках плеера.
**Сценарий 1. Запуск и автоплей.**
1. «Музыка/DJ» → выберите плейлист/трек → «Играть в зале».
2. Автоматическая смена треков — по списку очереди; ручной переход — кнопками дек.
3. Громкость общая — слайдером; по зонам — если аудиосистема многозонная.
**Сценарий 2. Дакинг микрофона.**
1. «Музыка/DJ → Настройки звука» → «Дакинг микрофона» — включить.
2. Порог и глубина приглушения: стандарт −12 дБ, атака 50 мс.
3. Тест: говорите в микрофон — музыка приглушилась, после тишины — вернулась.
4. Не работает: проверьте, что микрофон выбран в поле «Микрофон анонсов» (не в Face ID!).
**Сценарий 3. Энерджайзинг (автоподбор темпа).**
1. «Настройки плеера → Энерджайзинг» → включить, задайте диапазон BPM под тип тренировки.
2. Плейлист выстроится по энергии; ручные вставки не ломаются.
**Сценарий 4. MUTE ALL и тишина.**
1. «MUTE ALL» — мгновенная тишина всех зон; повторное нажатие — возврат уровней.
2. Если после MUTE ALL тишина осталась: проверьте, что зоны не выведены в mute отдельно.
**Проверка.**
- Трек играет, счётчик времени идёт, в зале звук.
- Дакинг: музыка падает на речи.
**Возможные ошибки.**
- Плеер запущен, звука нет: mpv «не умирает" корректно — перезапуск вкладки; проверьте аудиовыход ПК (устройство по умолчанию).
- Тишина после обновления: очередь пуста — добавьте треки заново.
- Треки не добавляются: формат не поддерживается — конвертируйте в mp3 320.
**FAQ.**
- РАО/ВОИС обязательны? Для публичного показа — да; номера договоров фиксируются в настройках, проверяющие просят именно их.
**Если не помогло:** «не помогло» + что именно: не играет/не приглушает/не добавляются треки.

## Как вести склад магазина: приход, списание, остатки, инвентаризация, связка с вендингом
Ключевые слова: склад, магазин, товары, остатки, приход, списание, инвентаризация, переучёт, продажа товара
Формулировки вопроса: как завести товар на склад; списать просрочку; складские остатки не сходятся; продать товар клиенту
**Ответ.**
«Магазин» — вкладка sidebar с серверным складом: товары, остатки, документы движения. Продажа товара — как платёж с категорией «Товар»; списание в вендинг-автомат уходит со склада автоматически при продаже.
**Сценарий 1. Завести товар и приход.**
1. «Магазин → Товары» → «Добавить»: название, штрихкод, категория, закупочная и розничная цена.
2. «Склад → Приход» → товар, количество, поставщик, документ (накладная).
3. Остаток появился; себестоимость партии учтётся в отчётах.
**Сценарий 2. Продажа клиенту.**
1. «Бухгалтерия → Платежи → Провести платёж» → способ, категория «Товар», выбор товара со склада.
2. Остаток уменьшился автоматически; чек — по обычной кассовой схеме.
**Сценарий 3. Списание и инвентаризация.**
1. «Склад → Списание» → причина (просрочка, бой, внутреннее использование).
2. Инвентаризация: «Склад → Инвентаризация» → пересчёт фактических остатков → документ расхождений.
**Проверка.**
- Остаток товара = приход − продажи − списания; отчёт «Склад → Движения» сходится.
**Возможные ошибки.**
- Минусовой остаток — продажа без списания вручную (обход склада): проводите продажи только через категорию «Товар».
- Цена не подтянулась в платёж — у товара пустая розничная цена.
**Если не помогло:** «не помогло» + товар и тип операции.

## Как настроить расписание и онлайн-запись: сетка занятий, time slots, отмена, лимиты мест
Ключевые слова: расписание, запись на занятие, онлайн-запись, слоты, time slots, отмена записи, лимит мест, расписание тренера
Формулировки вопроса: клиент записывается на занятие; как убрать запись; слоты не показываются; запись из макса
**Ответ.**
Вкладка «Расписание»: сетка по дням, услуги, тренеры. Онлайн-запись — из MAX-миниаппа клуба: клиент видит свободные слоты (time slots) и бронирует. Параметры: длительность слота (SLOT_MINUTES, стандартно 45 мин), лимит мест на занятие, срок бесплатной отмены (24 ч).
**Сценарий 1. Построить сетку.**
1. «Расписание» → «Услуги» → добавьте занятия: название, тренер, длительность, вместимость, цена/списание с абонемента.
2. Перетащите занятие в сетку дня; повторы — «Еженедельно».
3. Тренер видит своё расписание в своей роли (4 права).
**Сценарий 2. Запись клиента.**
1. Ресепшен: карточка клиента → «Расписание → Записать» → слот.
2. Онлайн: клиент в MAX-миниаппе → «Запись» → свободные слоты → бронь.
3. Подтверждение — уведомлением (канал по настройкам «Клиенту»).
**Сценарий 3. Отмена.**
1. До 24 часов — бесплатно: клиентом в миниаппе или с ресепшена.
2. Позже 24 ч — по правилам клуба: штраф/списание — настройка услуги.
3. Тренер отменил занятие — массовое уведомление записанным.
**Проверка.**
- Свободные места в слоте уменьшаются после записи; переполнение невозможно.
- Онлайн-запись видит только будущие слоты.
**Возможные ошибки.**
- Слоты не появляются онлайн: услуга без галочки «Онлайн-запись» или сетка на прошедшую дату.
- Запись есть, место не списалось: конфликт абонемента — проверьте тип абонемента (лимиты по услугам).
- «Уже в клубе» (409) при записи — клиент физически прошёл, система сама решит конфликт; при ошибке — отмените визит.
**FAQ.**
- Лист ожидания: при заполнении слота клиент может встать в очередь — место предложится автоматически.
**Если не помогло:** «не помогло» + услуга, время слота, кто записывал (ресепшен/онлайн).
