# schedule: продвинутое расписание (10 статей)

> Категория: schedule-services · Серии, замены, лист ожидания, залы, отметки, онлайн-конфиг.

## Серии занятий: создание на период
Категория: schedule-services
Вариации запроса: серия занятий, еженедельно создать, расписание на месяц
📷 Скриншоты: scr-sched-01.png

**Пошагово.**
1. «Расписание → ＋ Добавить запись» (или создание занятия в сетке).
2. При повторяющемся занятии — задайте повтор по дням недели и период (если форма поддерживает) либо копируйте занятие на нужные даты.
3. Проверка: сетка на месяц вперёд заполнена.
4. Замена/отмена серии — правка каждого занятия или серии (подтверждение «применить ко всей серии»).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Замена тренера на один день
Категория: schedule-services
Вариации запроса: замена тренера, подмена на сегодня, другой тренер на занятии
📷 Скриншоты: scr-sched-01.png

**Пошагово.**
1. «Расписание» → занятие → «✏ Правка» → поле «Тренер» → новый тренер.
2. «Сохранить» — с галочкой «только это занятие» (не серия).
3. Записанным клиентам уходит уведомление о замене (событие «Запись/перенос»).
4. На табло/расписании в зале — обновить объявление.
График заменённого тренера не тратится.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Лист ожидания на занятие
Категория: schedule-services
Вариации запроса: лист ожидания, запись в ожидание, место освободилось
📷 Скриншоты: scr-sched-01.png

**Механика.** При заполненной вместимости запись уходит в ожидание; при освобождении места (отмена) — клиент из ожидания подтверждается автоматически (уведомление).
**Действия сотрудника.**
1. Записать в ожидание: «➕ Записать» → при отказе системы по местам — запись в waiting list.
2. При отмене — следить за уведомлениями.
3. Ручной обзвон по ожиданию при форс-мажоре (отмена занятия).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Расписание по залам и оборудованию
Категория: schedule-services
Вариации запроса: расписание по залам, несколько залов, бронь зала
📷 Скриншоты: scr-sched-01.png

**Настройка.** Занятия привязаны к «зоне/месту» (текстовое поле при создании; уточняйте у администратора набор залов клуба).
**Правила.**
1. Одно занятие — один зал в один слот (контроль вручную при пересечениях).
2. Оборудование (мячи, коврики) — по регламенту зала, в расписание не входит.
3. Отчёт загрузки по залам — фильтр в «Загруженность по часам» + журнал визитов (зона).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Отмена занятия клубом (дождь, болезнь)
Категория: schedule-services
Вариации запроса: отмена занятия клубом, занятие не будет, массовая отмена
📷 Скриншоты: scr-sched-01.png

**Пошагово.**
1. «Расписание → занятие → Отменить» (подтверждение).
2. Записанным уходит уведомление об отмене (проверьте журнал: sent всем).
3. Лимиты посещений — возвращаются автоматически (проверьте по 1–2 клиентам).
4. Массовая отмена (неделя) — отмена серии с уведомлениями.
5. Компенсация — по регламенту клуба (перенос/бонус).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Отметка посещения по записи: порядок
Категория: schedule-services
Вариации запроса: отметить пришедших, кто пришёл на занятие, check-in тренером
📷 Скриншоты: scr-sched-01.png

**Порядок.**
1. Тренер/администратор: «Расписание → занятие → Записанные».
2. У пришедших — «✓ Пришёл». Ожидание: посещение зафиксировано, безлимит списался.
3. Опоздал/не отметил — исправление администратором (аудит).
4. Авто-отметка: проход через турникет в окне занятия фиксирует приход (если настроено зонами).
Итог: отчёт по посещаемости и зарплата тренера считаются по этим отметкам.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Онлайн-запись: настройка слотов и лимитов
Категория: schedule-services
Вариации запроса: слоты онлайн записи, сколько мест онлайн, лимит онлайн
📷 Скриншоты: scr-sched-01.png

**Настройка.**
1. `SLOT_MINUTES` — шаг слотов (на nfs 45 мин).
2. Вместимость услуги — общий лимит (онлайн + ресепшен).
3. Отдельный «онлайн-лимит» в текущей версии не выделяется: онлайн занимает места из общей вместимости. Для приоритета ресепшена — меньшая вместимость услуги + запись на месте.
4. Отмена онлайн — до `CANCEL_WINDOW` (24 ч).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Расписание тренера: его вид и редактирование
Категория: schedule-services
Вариации запроса: расписание тренера, тренер своё расписание, фильтр по тренеру
📷 Скриншоты: scr-sched-01.png

**Вид тренера.** Роль «Тренер» видит свои занятия (фильтр по себе) и отмечает посещения. Редактирование сетки — менеджер/администратор.
**Пошагово (для менеджера).** «Расписание» → фильтр по тренеру → правка занятий. График работы тренера — карточка сотрудника («График») — влияет на его доступность в расписании.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Конфликт: два занятия одного тренера в одно время
Категория: schedule-services
Вариации запроса: пересечение занятий, тренер в двух местах, конфликт расписания
📷 Скриншоты: scr-sched-01.png

**Почему допускается.** Система фиксирует занятия; жёсткого контроля двойного бронирования тренера может не быть.
**Профилактика.**
1. Перед созданием — фильтр «Расписание → по тренеру» на дату/время.
2. Тепловая карта загрузки тренеров — еженедельный контроль.
3. Ошибочное пересечение — перенос одного занятия + уведомления записанным.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
