## Каждый KPI на Главной: как читать
Категория: analytics-ai
Вариации запроса: kpi посещаемость выручка риск оттока, плитки что значат
📷 Скриншоты: scr-ai-02.png

**Плитки «📊 Обзор».**
1. «Посещений сегодня» — число визитов за сегодня (входы по любым способам). Резкий провал vs обычный день — проверяйте турникет/сеть.
2. «Выручка сегодня» — подтверждённые платежи за сегодня (нал+безнал). Не путать с кассой смены: тут — день, там — смена.
3. «Прогноз недели» — сумма дневных прогнозов на 7 дней вперёд (модель: день недели + тренд).
4. «Клиентов в риске» — активный абонемент + нет визитов 14+ дней. Работа со списком — статья «Список риска».
5. «К прошлой неделе, %» — динамика выручки текущих 7 дней vs предыдущие 7.
6. «Сегменты риска: Низкий|Средний|Высокий» — распределение клиентов по модели оттока.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Модель оттока: какие признаки использует
Категория: analytics-ai
Вариации запроса: как считается отток, признаки модели, почему клиент в риске
📷 Скриншоты: scr-ai-02.png

**Признаки (по коду analytics_ai).** Клиент в риске: активный абонемент И нет визитов более 14 дней. Модель обучается на истории (посещаемость, давность, частота) — сегменты Низкий/Средний/Высокий. Обучение требует достаточно примеров: «Мало данных» при скудной истории.
**Практика.** Высокий риск — звонок в течение дня; Средний — сообщение с оффером; Низкий — автонапоминания. Результат возвращения — в статистике визитов.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Обучение модели: расписание и ручной запуск
Категория: analytics-ai
Вариации запроса: обучение по расписанию, дообучить когда, автообучение
📷 Скриншоты: scr-ai-02.png

**Ручной запуск.** «Главная → AI Отток → 🎓 Обучить / дообучить» → «Обучено! Примеров: N, точность: X».
**Расписание.** Обучение периодическое — через celery-beat (при включённом AI-модуле); следите за строкой статуса «Модель: обучена | примеров: N | точность: X».
**Когда дообучать.** После накопления новых данных (еженедельно/ежемесячно); при падении точности на сверке («✅ Сверить прогнозы с фактом»).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Прогноз: доверительная интерпретация
Категория: analytics-ai
Вариации запроса: насколько точен прогноз, можно ли верить прогнозу, погрешность
📷 Скриншоты: scr-ai-02.png

**Ответ.** Прогноз — ориентир для планирования (персонал, закупки), не кассовый план. Модель: среднее по дню недели (последние 8 недель) + тренд двух недель. Точность растёт с историей: ≥14 дней — минимум, 2–3 месяца — уверенно. События (праздники, акции) прогноз не учитывает — поправляйте вручную.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Heatmap: планирование персонала по данным
Категория: analytics-ai
Вариации запроса: планирование смен по тепловой карте, пики загрузки, когда больше людей
📷 Скриншоты: scr-ai-02.png

**Пошагово.**
1. «Главная → 🔥 Тепловая карта → 🔄 Загрузить».
2. Найдите пики: яркие ячейки по часам/дням (обычно вечер будней + утро выходных — у вашего клуба своя картина).
3. Планируйте смены тренеров и персонала под пики; слабые часы — для уборки/инвентаризаций/обучения.
4. Повторяйте ежемесячно (сезонность меняет картину).
Карта строится из всей истории визитов (фильтра по периоду нет).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## RFM: работа с каждым сегментом
Категория: analytics-ai
Вариации запроса: rfm сегменты действия, чемпионы лояльные засыпающие, что делать с сегментами
📷 Скриншоты: scr-ai-02.png

**Сегменты и действия.**
- **Чемпионы** (частые, недавние, высокий чек): бонусы, ранний доступ к акциям, благодарности — удерживать.
- **Лояльные**: регулярные офферы, «приведи друга».
- **Засыпающие** (давность растёт): возвращающая акция, звонок менеджера.
- **На грани оттока** (риск + нет визитов): персональный оффер, пауза/заморозка вместо потери.
- **Потерянные**: win-back кампания; при безответности — исключить из активных рассылок (репутация).
**Инструмент.** «AI центр → Клиентская аналитика → RFM» → период → сегмент → список → действие.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## CSAT: реакция на низкие оценки
Категория: analytics-ai
Вариации запроса: низкий csat что делать, плохая оценка реакция, жалобы на оценки
📷 Скриншоты: scr-ai-06.png

**Пошагово.**
1. «Клиентская аналитика → Шкала» — средний балл и распределение.
2. Низкие оценки — в «MAX сообщения → Отзывы»: текст жалобы, дата, клиент.
3. Реакция в тот же день: звонок/сообщение, фиксация причины, решение (извинение/бонус/разбор сотрудника).
4. Повторяющиеся причины — процессный фикс (регламент/обучение), не только «заглаживание».
Мало оценок — не приговор: мотивируйте оценки (QR на выходе, бонус за отзыв).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Backfill 56 дней: что это и когда нужен
Категория: analytics-ai
Вариации запроса: бэкфилл, заполнить историю, после импорта базы
📷 Скриншоты: scr-ai-02.png

**Что делает.** Пересчитывает метрики за прошлые 56 дней, чтобы прогноз и тепловая карта имели историю сразу. Автоматически — при первом запуске; вручную — «🧮 Пересчитать историю (56 дн)» на Главной.
**Когда.** После установки сервера, восстановления из бэкапа, импорта клиентской базы с историей. После — «📈 Построить прогноз» заново.

## Аналитика пустая после восстановления из бэкапа
Категория: analytics-ai
Вариации запроса: аналитика нули после бэкапа, метрики пропали
📷 Скриншоты: scr-ai-02.png

**Пошагово.**
1. Данные на месте? («Входы/Выходы», «Платежи» — есть записи?) Если нет — восстановили не ту БД/не тот дамп.
2. Данные есть → «🧮 Пересчитать историю (56 дн)» → подождать минуту → «🔄 Обновить».
3. Прогноз всё ещё «Мало данных» → истории <14 дней в восстановленном периоде; backfill доберёт автоматически по мере работы.

**Структура (1.6.2).**
1. **Аналитика** — 12 KPI за период (выручка, посещаемость, новые клиенты, средний чек, конверсии) + графики.

## 12 KPI аналитики за период: список и чтение
Категория: analytics-ai
Вариации запроса: 12 kpi аналитики, показатели периода, средний чек конверсия
📷 Скриншоты: scr-ai-02.png

**Как читать.** Откройте «AI центр → Аналитика» → период. Показатели: выручка (по видам оплаты), посещаемость (визиты/уникальные), новые клиенты, средний чек, продажи абонементов (кол-во/сумма), конверсия новых в повторные, возвращаемость, отток, загрузка по дням недели.
**Применение.** Сравнение периодов (текущий vs прошлый) — эффект акций; провалы по дням — планирование; низкий средний чек — работа с тарифами/допродажами.
