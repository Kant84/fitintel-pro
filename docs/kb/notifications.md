# notifications — уведомления: email, SMS, MAX, Telegram, webpush

> Категория: notifications · Проверено для: 1.6.2 · Для кого: администратор, менеджер.

## Как настроить Email (SMTP)
Ключевые слова: smtp, email настройка, почта, отправка писем
**Ответ.** «Уведомления → Email»: галочка «Включить Email-уведомления»; SMTP хост (smtp.mail.ru / smtp.yandex.ru / smtp.gmail.com); порт 465 (SSL) или 587 (TLS); Логин — полный адрес (club@mail.ru); Пароль — ПАРОЛЬ ПРИЛОЖЕНИЯ (создаётся в настройках ящика, не пароль входа!); «От кого» — тот же адрес; время дайджеста (например 09:00) → «💾 Сохранить Email» → тест из «📨 Отправка» (ИНСТРУКЦИЯ §17.2, EMAIL_SETUP_GUIDE).
📷 [SCR-notif-01: вкладка «Email» с заполненными полями]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## «535 Application password is REQUIRED» (mail.ru)
Ключевые слова: 535, пароль приложения, mail.ru authentication failed
**Ответ.** В поле «SMTP пароль» вписан пароль ящика — mail.ru так не пускает. Создайте пароль приложения: Настройки аккаунта mail.ru → Безопасность → Пароли приложений → вставьте его в настройки. Для Яндекса/Gmail — аналогично (только при включённой 2FA). Свой сервер (Mailcow) — обычный пароль ящика (EMAIL_SETUP_GUIDE §2, §6).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Ежедневный дайджест не приходит
Ключевые слова: дайджест, утренняя сводка, digest не приходит
**Ответ.** 1) Email-уведомления включены и SMTP настроен (тест проходит). 2) Время дайджеста — «Уведомления → Email» (по умолчанию 09:00). 3) Письмо всегда идёт через очередь — до минуты паузы норма. 4) Статус: «Уведомления → Журнал» (EMAIL_SETUP_GUIDE §1, §4).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как настроить SMS (SMSC)
Ключевые слова: sms, smsc, смс настройка, подпись отправителя
**Ответ.** «Уведомления → SMS»: галочка «Включить SMS (smsc.ru)»; логин и пароль smsc.ru; подпись отправителя (например FitIntel). Без регистрации подписи SMS идут с пустой подписью (~5–7 ₽); с незарегистрированной подписью ~46 ₽ (премиум-канал). Регистрация sender id у SMSC ~2550 ₽/мес (ИНСТРУКЦИЯ §17.3, A5).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как включить бота MAX клуба
Ключевые слова: max бот, токен бота, webhook max, бот клуба
**Ответ.** 1) Кабинет MAX для разработчиков → создать бота (нужно верифицированное юрлицо РФ) → получить токен. 2) Вписать: «Клиенту → Каналы → MAX» (токен + «Установить webhook») или через API `/max-bot/settings`. 3) Webhook — только публичный HTTPS-домен клуба (например https://<клуб>.fixintel.ru/api/v1/max-bot/webhook), не IP локалки. 4) Тест: клиент пишет боту /start → регистрация (docs_MAX_bot_shop §2, §9).

**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

**Ответ.** (Исторически: BotFather → токен в «Клиенту».) ⚠️ В desktop 1.6.2 канал Telegram из UI убран (фолбэк в коде остался) — актуальные каналы клиенту: **MAX (бесплатно)** и **SMS через SMSC.ru (~5–11 ₽/шт)**; приоритет MAX → SMS.

## Web Push — что это и как включить
Ключевые слова: web push, push уведомления, vapid, пуш в браузер
**Ответ.** Push-уведомления в браузер (ПК/Android/iOS-PWA) даже при закрытом приложении. Включение: «Уведомления → Web Push» → галочка → сгенерировать пару VAPID-ключей (команда в WEBPUSH_SETUP §1.2) → поле «VAPID sub» заполнить реальным доменом (mailto:почта@домен-клуба) — иначе Apple отклонит пуши с 403 BadJwtToken. Для iOS: добавить на экран «Домой» как PWA. Требование — публичный HTTPS (WEBPUSH_SETUP).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Клиент не получает чек на email после оплаты
Ключевые слова: чек на почту, чек клиенту, тег 1008, копия чека
**Ответ.** 1) «Уведомления → Клиенту»: включены «Уведомления клиентам» и событие «Оплата принята» → «Сохранить "Клиенту"». 2) В карточке клиента email корректный. 3) Письмо копится в очереди и уходит процессингом (до минуты); статус — «Уведомления → Журнал». 4) Проверьте «Спам» (до настройки DKIM для домена). Чек дублируется в ОФД по тегу 1008 (ИНСТРУКЦИЯ §17А, FISCAL_GUIDE).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Рассылка клиентам (MAX)
Ключевые слова: рассылка, массовая отправка, новости акции
**Ответ.** «MAX сообщения → Рассылка»: Кому (Клиенты/Тренеры/Все/конкретный) → Тип (Акция/Напоминание/Инфо) → текст → «📣 Отправить». Уходит только по привязкам MAX — клиент должен был сам первым написать боту. Результат: «в очереди N, sent=X, failed=Y» (ИНСТРУКЦИЯ §16.3). Новости: «MAX сообщения → Новости» → заголовок + текст → «Опубликовать и разослать» (лента миниапп + рассылка).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Автонапоминания: истечение абонемента и «пропавшие» клиенты
Ключевые слова: напоминания об истечении, пропавшие клиенты, скучаем
**Ответ.** «MAX сообщения → Напоминания → 🔔 Сгенерировать напоминания сейчас». Правила: абонемент истекает ≤3 дней → продление; клиент не был 14+ дней → «мы скучаем». Повтор в тот же день не создаётся (защита от спама). Журнал со статусами — там же (ИНСТРУКЦИЯ §16.5).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как проверить отправку (тест)
Ключевые слова: тест уведомления, отправить тест, проверить канал
**Ответ.** «Уведомления → 📨 Отправка»: Канал (email/sms/webpush) → получатель (из базы или вручную) → текст → «📨 Отправить тест». Для MAX/Telegram — напишите боту сами с телефона. Статусы и ошибки — «Журнал» (ИНСТРУКЦИЯ §17.5).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Письма уходят в Спам у получателей
Ключевые слова: спам, доставляемость, dkim
**Ответ.** До настройки DKIM письма с нового домена часто в Спаме — проверяйте там. Для массовых рассылок настройте SPF/DKIM/DMARC для домена клуба (почтовая доверенность) — см. ROADMAP «Почтовая доверенность». Тестовые письма — из «📨 Отправка».
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как настроить уведомления клиентам (вкладка «Уведомления → Клиенту»)
Ключевые слова: клиенту, уведомления клиентам, события клиенту
**Ответ.** 1) Галочка «Включить уведомления клиентам (MAX → SMS)». 2) Каналы: MAX (мессенджер, бесплатно) / SMS через SMSC.ru (платно, по умолчанию выкл). 3) **События (5):** «Оплата принята» · «Вендинг-покупка» · «Напоминание о записи» (за 3 ч) · «Абонемент истекает» · «Аренда шкафчика истекает». 4) Токен бота MAX (от @masterbot) + статус подключения → «Сохранить токен MAX» / «Сохранить "Клиенту"». Клиент должен сам первым написать боту (привязка). Скриншот: scr-notif-03.png, scr-notif-11-clientu-162.png.
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».
