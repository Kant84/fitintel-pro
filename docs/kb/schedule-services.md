# schedule-services — расписание, услуги, тренеры

> Категория: schedule-services · Проверено для: 1.6.2 · Для кого: менеджер, администратор, тренер.

## Как создать услугу
Ключевые слова: создать услугу, новая услуга, каталог услуг
**Ответ.** «Услуги → ＋ Добавить услугу»: Название*, Категория (Бассейн/Сауна/Массаж/Аэробика/Танцы/Перс. тренировка), Цена (1–1 000 000), Длительность мин (1–600), Вместимость (1–200), Тренер (или «без тренера»), галочка «Активна» → «Сохранить» (ИНСТРУКЦИЯ §13.3).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как создать тренера
Ключевые слова: новый тренер, профиль тренера, специализация, ставка
**Ответ.** «Услуги → 👤 Новый тренер»: Пользователь* (учётка без профиля тренера — если все уже тренеры, сначала создайте пользователя), Специализация, Ставка ₽/час (по умолчанию 1000), Комиссия % (0–100, обычно 10), Макс. клиентов/день (1–50) → «Создать» (ИНСТРУКЦИЯ §13.4).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как записать клиента на услугу
Ключевые слова: запись на услугу, записать клиента, добавить запись
**Ответ.** «Расписание → ＋ Добавить запись»: Клиент* → Услуга* (только активные) → Дата и время (календарик) → «Записать». Проверки: слот занят / вместимость исчерпана → «Запись не создана: <причина>» (ИНСТРУКЦИЯ §14.5).
📷 [SCR-sched-01: форма «Новая запись»]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Отмена записи клиентом (окно 24 часа)
Ключевые слова: отменить запись, отмена записи, за 24 часа
**Ответ.** Выделите строку → «✕ Отменить запись» → подтверждение. Клиент может отменить бесплатно только за 24 часа (параметр `CANCEL_WINDOW_HOURS`); позже сервер откажет. Статус записи станет CANCELLED (ИНСТРУКЦИЯ §14.6, USER_GUIDE).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Сетка занятий по дням
Ключевые слова: расписание по дням, сетка занятий, неделя
**Ответ.** «Расписание → Занятия по дням»: Пн–Вс × время (08:00–20:00), в ячейке — занятие и число записавшихся. Кнопки: добавить/отменить запись, изменить/удалить услугу (ИНСТРУКЦИЯ §14.2).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Онлайн-запись клиентов из мини-приложения MAX не работает
Ключевые слова: онлайн запись, запись из приложения, слоты не показываются
**Ответ.** Услуга видна в мастере записи только если у неё заполнено онлайн-расписание `services.schedule` (JSONB: days[] + time_slots[] с capacity). Услуга без time_slots в приложении не появится. Проверка/массовая заливка — SQL из Docs_MAX_miniapp §«Настройка онлайн-записи» (там же формат JSON).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Свободные слоты: как считается «мест: N»
Ключевые слова: свободные места, слоты, вместимость занята
**Ответ.** Свободные места = capacity слота − записи со статусами BOOKED/CONFIRMED/PAID. Данные слота задаются в `time_slots` расписания услуги. Антипереполнение: при заполнении — 409 (Docs_MAX_miniapp §1.2, §1.3).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Статусы записей
Ключевые слова: booked, confirmed, completed, cancelled, статус записи
**Ответ.** BOOKED — создана; CONFIRMED — подтверждена (кнопка у ресепшена/клиента за N часов); COMPLETED — занятие прошло; CANCELLED — отменена. No-show (не пришёл) — минус 0.5 к рейтингу клиента (docs_MAX_bot_shop §4, USER_GUIDE).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Фото тренера не загружается
Ключевые слова: фото тренера, загрузить фото, 400×400
**Ответ.** «Расписание → Тренеры → 📷 Загрузить фото»: файл JPG/PNG, авто-ресайз 400×400. Если кнопка недоступна — проверьте права и формат файла (ИНСТРУКЦИЯ §14.3).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Зарплата тренеров — где считается
Ключевые слова: зарплата тренера, kpi, расчёт зарплаты
**Ответ.** Отчёт «Бухгалтерия → Отчёты → Зарплата тренеров»: сессии × ставка (прогрессивно +5/15/30/50% от объёма) + комиссия % от продаж + бонусы − штрафы. Экспорт для 1С (Зарплата XML): диалог сохранения, проводки Дт44/Кт70, Дт70/Кт50 (USER_GUIDE «Тренер», ИНСТРУКЦИЯ §15.8).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».
