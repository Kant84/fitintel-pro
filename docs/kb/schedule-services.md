# schedule-services — расписание, услуги, тренеры, запись (14 статей)

## Создание услуги (справочник)
Категория: schedule-services
Вариации запроса: новая услуга, создать услугу, добавить занятие, справочник услуг

**Пошагово (admin).**
1. «Услуги» → «➕ Новая услуга».
2. Название, категория, длительность (мин), цена, тип (индивидуальная/групповая), вместимость (для групповых), тренер по умолчанию.
3. «Сохранить». Ожидание: услуга доступна в продаже и в расписании.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Создание тренера
Категория: schedule-services
Вариации запроса: новый тренер, добавить тренера, карточка тренера

**Пошагово (admin).**
1. «Пользователи» → «➕ Новый сотрудник» → роль «Тренер» (или совмещённая).
2. В карточке сотрудника заполните: контакты, ставку/оклад (раздел «К зарплате»), график работы.
3. Фото тренера — в карточке (показывается клиентам в мини-приложении).
4. Ожидание: тренер появляется в списке при создании занятий.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Построение расписания (сетка занятий)
Категория: schedule-services
Вариации запроса: расписание, сетка занятий, добавить занятие в расписание, планирование недели

**Пошагово.**
1. «Расписание» → «➕ Новое занятие».
2. Услуга, тренер, дата, время начала, зал/место, вместимость.
3. Повтор: «Еженедельно по дням» — отметьте дни недели и период. Ожидание: занятия создались на весь период.
4. Сетка показывает неделю; листайте стрелками ‹ ›.

📷 [SCR-sched-01: сетка расписания]
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Запись клиента на услугу (с ресепшена)
Категория: schedule-services
Вариации запроса: записать на занятие, запись клиента, записать на тренировку, запись с администратора

**Пошагово.**
1. «Расписание» → клик по занятию → вкладка «Записанные» → «➕ Записать клиента».
2. Найдите клиента (ФИО/телефон). Ожидание: клиент в списке, счётчик «свободно −1».
3. Списание — по правилам абонемента (лимит/безлимит); при лимите списание сразу, при безлимите — по факту посещения.
4. Клиенту уходит уведомление «Запись» (при включённом событии и привязанном канале).

**Типичные ошибки.** «Нет свободных мест» — вместимость занятия исчерпана; клиент без абонемента — сначала продажа.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Онлайн-запись клиента из мини-приложения MAX
Категория: schedule-services
Вариации запроса: онлайн запись, запись через max, клиент сам записался, слоты записи

**Ответ.** Клиент в мини-приложении MAX: «Расписание» → выбор услуги/тренера → слоты (шаг `SLOT_MINUTES`, по умолчанию 45 мин) → «Записаться». Ожидание: запись появляется в расписании desktop с пометкой «онлайн», клиенту — уведомление-подтверждение. Сотрудник видит её без действий; за 24 ч до занятия клиент может отменить сам (см. «Отмена записи»).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Отмена записи (клиентом и сотрудником)
Категория: schedule-services
Вариации запроса: отменить запись, отмена записи, отказ от тренировки, перенос записи

**Пошагово.**
1. Клиент: мини-приложение → «Мои записи» → «Отменить» (доступно до 24 ч до занятия; позже — только через клуб).
2. Сотрудник: «Расписание» → занятие → «Записанные» → клиент → «✖ Отменить запись» → причина.
3. Ожидание: место освободилось; лимит посещения возвращён (если списывался заранее).
4. Клиенту уходит уведомление об отмене.

**Типичные ошибки.** Поздняя отмена без причины — фиксируйте, тариф может списывать визит (правило тарифа).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Нет свободных мест» — как добавить места
Категория: schedule-services
Вариации запроса: нет мест, свободные места, увеличить вместимость, добавить слот

**Пошагово.**
1. «Расписание» → занятие → «✏ Правка» → вместимость: увеличьте число → «Сохранить».
2. Или создайте параллельное занятие с тем же тренером/временем (второй зал).
3. Онлайн-слоты пересчитаются автоматически.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Отметка посещения по записи (check-in)
Категория: schedule-services
Вариации запроса: отметить посещение, кто пришёл на занятие, отметка тренера, check-in

**Пошагово.**
1. «Расписание» → занятие → «Записанные» → у пришедшего клиента «✓ Пришёл».
2. Ожидание: посещение зафиксировано; безлимитный абонемент списался; у непришедших статус «Не пришёл».
3. Альтернатива: проход через турникет в окне занятия автоматически отмечает приход (если настроено).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Статусы записи: что означают
Категория: schedule-services
Вариации запроса: статусы записи, что значит записан, подтверждена, в списке ожидания

**Ответ.** Записан (awaiting подтверждения онлайн) → Подтверждена (клуб подтвердил/клиент пришёл) → Посетил / Не пришёл / Отменена (с указанием кем). «В списке ожидания» — мест нет, клиент ждёт освобождения; при освобождене запись подтверждается автоматически (уведомление клиенту).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Зарплата тренеров: как считается
Категория: schedule-services
Вариации запроса: зарплата тренера, расчёт зарплаты, ставка тренера, оклад и процент

**Ответ.** «Бухгалтерия → К зарплате» → подвкладка «Зарплата»: штатное расписание (оклады/ставки по должностям) → параметры сотрудника (индивидуальные ставки) → «Начисления» (расчёт за период: оклад + % с выручки/посещений) → «Выплачено» (фиксация выплаты с проводкой). Проводки уходят в бухгалтерию автоматически. Подробные шаги — статья в cash-fiscal/users-rbac.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Фото тренера и услуги (что видят клиенты)
Категория: schedule-services
Вариации запроса: фото тренера, картинка услуги, описание в приложении

**Пошагово (admin).**
1. Карточка тренера → «Фото» → загрузите (требования: jpg/png, до 2 МБ).
2. «Услуги» → услуга → «Описание/фото» — текст и изображение для мини-приложения.
3. Ожидание: клиент видит фото/описание при выборе услуги в MAX.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Перенос занятия (другое время/тренер)
Категория: schedule-services
Вариации запроса: перенести занятие, сменить тренера, замена тренера, перенос времени

**Пошагово.**

2. Ожидание: записанным клиентам уходит уведомление о переносе (при включённом событии).
3. Для серии (еженедельное) — правка с галочкой «применить к серии».

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
