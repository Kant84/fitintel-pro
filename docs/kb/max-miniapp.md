# max-miniapp: мини-приложение MAX для клиентов (19 статей)

> Категория: desktop/max-miniapp · Клиентский контур: запись, QR, баланс, вендинг, отзывы.

## Запуск мини-приложения клиентом (первый раз)
Категория: max-miniapp
Вариации запроса: как открыть приложение клуба, миниапп запуск, клиенту зайти
📷 Скриншоты: scr-max-01.png

**Пошагово (для клиента).**
1. Откройте чат с ботом клуба в MAX → кнопка «Мини-приложение» (или по ссылке клуба).
2. Разрешите запуск (профиль/фото — по запросу).
3. Ожидание: главный экран приложения: записи, QR, баланс, вендинг (набор разделов — по настройкам клуба `miniapp_config`).
4. Если бот не отвечает — сначала «Запустить/Начать» в чате бота (notifications.md «Бот MAX не отвечает»).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Онлайн-запись из мини-приложения
Категория: max-miniapp
Вариации запроса: записаться самому, онлайн запись клиентом, слоты в приложении
📷 Скриншоты: scr-max-01.png

**Пошагово (клиент).**
1. Раздел «Расписание/Запись» → выберите услугу → тренера.
2. Выберите свободный слот (шаг `SLOT_MINUTES`, на nfs 45 мин).
3. «Записаться» → подтверждение с датой/временем.
4. Ожидание: запись появилась у сотрудников («Расписание»), уведомление клиенту (событие «Запись»).
5. Отмена: «Мои записи → Отменить» (доступно до `CANCEL_WINDOW` = 24 ч).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Приложение не открывается / вечная загрузка
Категория: max-miniapp
Вариации запроса: приложение не грузится, белый экран, не открывается миниапп
📷 Скриншоты: scr-max-01.png

**Пошагово.**
1. Обновите MAX до последней версии; перезапустите приложение.
2. Проверьте интернет клиента.
3. С другого телефона открывается? Нет — сервер/домен клуба недоступен (IT: health, домен, HTTPS).
4. Очистите кэш MAX (Настройки MAX → Очистить кэш) → открыть заново.
5. Сообщите клубу с моделью телефона и версией MAX.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
