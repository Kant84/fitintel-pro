## Команды бота для сотрудника клуба
Категория: support-bot
Вариации запроса: команды бота поддержки, что писать боту, как обратиться в поддержку
📷 Скриншоты: scr-max-09-bot-chat.png

**Как обратиться.** Откройте бота FitIntel Assist в MAX (ссылка из desktop «Помощь → Поддержка разработчика» или поиск по имени бота) → напишите вопрос своими словами (вариации формулировок не важны — поиск идёт по смыслу и вариациям запросов).
**Что происходит.** Бот ищет в базе знаний (724 статьи) → присылает пошаговый ответ со скриншотами, если они привязаны.
**Если ответ не помог** — «не помогло»/продолжайте диалог — бот эскалирует обращение администраторам поддержки.
**Лицензия.** Проверка клуба по лицензии платформы: при no_license — бот сообщит обратиться к администратору платформы.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## SLA и регламент поддержки
Категория: support-bot
Вариации запроса: sla поддержки, время ответа регламент, приоритеты обращений
📷 Скриншоты: scr-max-09-bot-chat.png

**Регламент (предложение владельцу).**
- Критичные (касса/СКУД не работает, клуб стоит): ответ ≤ 15 мин в рабочее время (10:00–19:00 пн–пт), вне — следующее утро; пометка «СРОЧНО».
- Стандартные (вопросы по функциям): ≤ 2 часов в рабочее время.
- Пожелания/баги неблокирующие: ≤ 1 рабочего дня с тикетом.
**Пометки.** Критичность — в первом сообщении; без пометки — стандартная очередь.
**Контроль.** Еженедельная статистика: время первого ответа, доля в SLA.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Отличие бота поддержки от бота клуба
Категория: support-bot
Вариации запроса: бот поддержки и бот клуба разница, два бота, кому писать
📷 Скриншоты: scr-max-09-bot-chat.png

**Два разных контура.**
- **Бот клуба** (на сервере клуба): для КЛИЕНТОВ клуба — записи, QR, баланс. Его токен — в настройках клуба.
- **Бот поддержки FitIntel Assist** (на 125, fixintel.ru/bot/): для СОТРУДНИКОВ клубов — вопросы по работе ПО. Идентификация клуба через платформу.
**Клиент клуба никогда не попадает в бот поддержки** — он пишет клубному боту. Сотрудник попадает через desktop «Помощь → Поддержка разработчика» или с телефона.
**Токены разные** — не путать при ротации.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Проблемы подключения бота: чек-лист
Категория: support-bot
Вариации запроса: бот не отвечает, webhook не работает, бот молчит поддержка
📷 Скриншоты: scr-max-09-bot-chat.png

**Чек-лист (root@debianNOUT).**
1. Контейнер: `docker compose ps` — Up; `docker logs support-bot --tail=30` — ошибки.
2. Подписка webhook: в БД бота/логе создана? `POST /subscriptions` прошёл?
3. Фронт-nginx: location `/bot/` в fixintel.conf проксирует на 192.168.101.125:8091 (см. README-runbook).
4. Снаружи: `curl -s https://fixintel.ru/bot/health` (или какой путь настроен) — должен отдать JSON, не 404/000.
5. Секрет: заголовок `X-Max-Bot-Api-Secret` совпадает с настройкой подписки.
6. Токен бота валиден (после перевыпуска в кабинете MAX — обновить в настройках бота).
Сквозная проверка round-trip: сообщение в MAX → лог контейнера (запрос пришёл) → ответ ушёл.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Тестовый диалог с ботом: сценарий приёмки
Категория: support-bot
Вариации запроса: проверить бота, тест бота, как проверить что бот работает
📷 Скриншоты: scr-max-09-bot-chat.png

**Сценарий приёмки (5 минут).**
1. С вашего MAX напишите боту: «не пробивается чек, пишет смена закрыта».
2. Ожидание: ответ со статьёй «Смена закрыта при пробитии чека» — пошагово (Бухгалтерия → Платежи → Открыть смену → Подтвердить), возможно со скриншотом.
3. Спрошайте вариацию: «чек не пробивается» → тот же/близкий ответ (работают вариации запроса).
4. Напишите бред: «как сварить суп» → честный «не нашёл, эскалирую» (или ближайшая статья).
5. Критично: «СРОЧНО турникет не пускает всех» → ответ по чек-листу + фиксация обращения админу.
**Маркеры.** Ответы по существу, скриншоты прикрепляются, эскалация при «не помогло» — фаза 1–2 работают.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Обновление KB у бота без пересборки
Категория: support-bot
Вариации запроса: обновить статьи бота, перезалив kb, как обновить базу знаний бота
📷 Скриншоты: scr-max-09-bot-chat.png

**Пошагово.**
1. Правите/добавляете статьи в docs/kb/ → коммит → push с ПК.
2. root@debianNOUT: `cd /home/andrei/fitintel-pro && git fetch origin && git reset --hard origin/main`.
3. `cd deploy/support-bot && docker compose run --rm support-bot python kb_import.py` (без reset — догрузка/обновление; с `reset` — с нуля).
4. Маркер: `IMPORTED=N` → `curl -s http://192.168.101.125:8091/health` → `kb_articles=N`.
Пересборка образа (`up -d --build`) нужна только при изменении КОДА бота (app.py, kb_import.py) — статьи читаются из смонтированной папки.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
