## Открытие клуба утром (регламент)
Категория: processes
Вариации запроса: открытие клуба, утренний регламент, начало рабочего дня

**Пошагово (ресепшен + администратор).**
1. Запустить desktop, проверить статус сервера (зелёный).
2. Касса: «🔓 Открыть смену» на кассира; проверить ККТ (бумага, ДТО отвечает).
3. Турникет: тестовый проход тестовой картой; «Сейчас в зале» = 0 (иначе закрыть висящие визиты).
4. Шкафчики: доска раздевалок, батарейки замков.
5. Музыка: пульт/автоматика, громкость зала.
Ожидание: клуб готов к приёму; фиксируйте отклонения администратору.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Закрытие клуба вечером
Категория: processes
Вариации запроса: закрытие клуба, вечерний регламент, конец дня

**Пошагово.**
1. «Сейчас в зале» = 0: нет — найти и «Завершить» висящие визиты (аудит).
2. Шкафчики: аренды закрыты/освобождены, вещи — по регламенту.
3. Касса: все «Ожидает» подтверждены/отменены, X-отчёт, «🔒 Закрыть смену» со сверкой наличных.
4. Снятие кассы — бухгалтером/администратором («💵 Снятие кассы»).
5. Персонал: выход учёток, ПК выключить/заблокировать, музыка off, свет/климат — по регламенту здания.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Расчёт и выплата зарплаты end-to-end
Категория: processes
Вариации запроса: расчёт зарплаты регламент, выплата зарплаты, ведомость

**Пошагово (бухгалтер + HR).**
1. «Бухгалтерия → К зарплате → Штатное расписание» — актуальные оклады/должности.
2. Параметры сотрудников: ставки/комиссии/график заполнены.
3. «Начисления → Рассчитать» за период (оклад + % с посещений/выручки).

5. «Выплачено» — фиксация выплат: дата, сумма, способ → проводки.
6. Печать/выгрузка ведомости; подписи; документы сотрудникам.

## Возвратная политика клуба (шаблон процесса)
Категория: processes
Вариации запроса: возврат денег политика, как оформлять возвраты, основания

**Процесс.**
1. Клиент заявляет на возврат → основание (мед. справка, переезд, ошибка продажи) документируется.
2. «Платежи → ↩ Возврат» — сумма (полная/частичная), причина обязательна → чек возврата.
3. Деньги: нал из кассы, безнал — на карту/реквизиты (сроки банка).
4. Абонемент: отмена/заморозка по правилам тарифа.
5. Журнал возвратов — бухгалтеру (частые возвраты = разбор причин).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Аварийные сценарии клуба
Категория: processes
Вариации запроса: аварийный регламент, что делать при сбое, план Б

**Сценарии.**
- Нет света/сети: работа по бумажным бланкам → внесение в ПО после восстановления (аудит отметить).
- Сервер недоступен: «Сервер недоступен» — регламент ошибки; локальные впуски по списку (ресепшен), затем догрузка визитов.
- ККТ молчит: «Касса недоступна» — работа по регламенту ФН (см. cash-fiscal), критично — поддержка.
- Пожарная тревога: турникеты открываются аппаратно; эвакуация; учёт людей — по «Сейчас в зале».
- Утечка данных: смена паролей/токенов, аудит, уведомление владельца.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Ежедневная сверка «Сейчас в зале»
Категория: processes
Вариации запроса: сверка в зале регламент, висящие визиты, закрытие

**Регламент.** Утро и вечер: «Входы/Выходы» — счётчик «Сейчас в зале» должен быть 0 до открытия и после закрытия. Не 0 — закрыть висящие («Завершить») с фактическим временем. Причины накопления: выход не считался (карта), ручные впуски без выпуска. Повторяется — IT: события выхода с контроллера.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Учёт браслетов (выдача/возврат/списание)
Категория: processes
Вариации запроса: учёт браслетов регламент, выдать вернуть, списать

**Регламент.**
1. Выдача: привязка к клиенту («Браслеты/Карты»), депозит — по правилам клуба.
2. Возврат при расторжении: отвязка/блок, депозит вернуть (платёж-расход).
3. Утеря: lost → перевыпуск (оплата по регламенту).
4. Списание: износ — «Сбросить карту» + списание (аудит).
5. Ревизия браслетов — ежеквартально (количество = учёт).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
