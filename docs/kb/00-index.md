# База знаний поддержки FitIntel Pro (docs/kb/)

> Назначение: источник ответов для умного бота MAX (ТЗ «Бот техподдержки») и для живых
> администраторов. Формат статей — под инжест бота: заголовок H2 = вопрос дословно,
> поля «Ключевые слова» и «Категория» маппятся на таблицу `kb_articles`
> (title → keywords[] → answer_text → category → screenshot_path).
> Версия продуктa: **1.6.2** (06.11.2026). При бампе версии — пересматривать файлы.

## Правила наполнения
1. Вопрос формулируем языком сотрудника клуба («чек не пробивается»), не языком разработчика.
2. Ответ: до 8 строк, шаги нумерованные, ссылки на разделы ИНСТРУКЦИИ_ПОЛЬЗОВАТЕЛЯ / DESKTOP_GUIDE.
3. Каждая статья заканчивается строкой **«Если не помогло»** — эскалация в поддержку
   (desktop: «Помощь → Поддержка разработчика (MAX)» — обращение уходит с логами и версиями;
   email support@fixintel.ru).
4. Скриншоты: места помечены `📷 [SCR-<тема>-NN: что снять]`; файлы — в docs/kb/screenshots/,
   после съёмки помечать 📷 → вставить ссылку.
5. Категории (папки): errors · desktop · cash-fiscal · payments · notifications ·
   visits-access · clients-subs · schedule-services · analytics-ai · music-dj ·
   users-rbac · faceid · settings-help · server · skud-hardware · vending.
