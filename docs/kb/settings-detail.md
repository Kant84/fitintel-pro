# desktop: настройки детально (16 статей)

> Категория: desktop · Подвкладки хаба «Настройки» и сопутствующие системные настройки.

## Подвкладка «Интерфейс» — все опции
Категория: desktop
Вариации запроса: интерфейс настройки, тема шрифт масштаб опции

**Опции.** Тема — Светлая/Тёмная/Контрастная; Шрифт — размер/семейство; Масштаб — ползунок. «💾 Сохранить» → применяется сразу, локально для ПК. Контрастная — для слабовидящих и работы на солнце; масштаб — для небольших мониторов/презентации.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Подвкладка «Касса» в Настройках
Категория: desktop
Вариации запроса: касса в настройках, драйвер атол штрих, настройки кассы подвкладка

**Что внутри.** Дублирует «Платежи → ⚙ Настройки кассы»: драйвер (АТОЛ/Штрих-М), адрес ДТО, логин/пароль, ОФД. Изменения общие для клуба (хранятся на сервере). После смены адреса/драйвера — тестовый чек 1 ₽.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Подвкладка «Расписание» в Настройках
Категория: desktop
Вариации запроса: расписание в настройках, слоты запись онлайн, настройки расписания

**Что внутри.** Шаг сетки/слотов онлайн-записи (`SLOT_MINUTES`, на nfs = 45 мин), окно отмены (`CANCEL_WINDOW` = 24 ч), доступность онлайн-записи по услугам/тренерам. Правки сохраняются на сервере; мини-приложение подхватывает автоматически.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Параметры клуба: ключи по группам
Категория: settings-help
Вариации запроса: параметры клуба список ключей, qr ttl slot minutes cancel window

**Группы ключей (instance-конфигурация).**
- Доступ: `QR_TTL_MINUTES` (=2 мин на nfs), `GYM_ACCESS`.
- Расписание: `SLOT_MINUTES` (=45), `CANCEL_WINDOW` (=24 ч).
- Вендинг: `VENDING_ENABLED`, привязка автоматов.
- Уведомления: включённые каналы/события.
- Интеграции: ключи API (1С, A&A, банки).
Правка: по ключу → значение → «Сохранить». Неизвестный ключ — сервер откажет/проигнорирует.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Service-аккаунты: создание и применение
Категория: users-rbac
Вариации запроса: service аккаунт создать, техническая учётка, api ключ сервисный

**Пошагово.**
1. «Настройки → Service-аккаунты → ＋».
2. Имя (например, «1с-обмен»), права (только нужные: чтение платежей и т.п.).
3. Система выдаёт токен — сохраните в менеджер паролей (показывается один раз).
4. Используйте токен в интеграции (заголовок Authorization). Ротация — перевыпуск токена; старый сразу отзывается.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Мастер первого запуска: шаги
Категория: desktop
Вариации запроса: мастер установки шаги, первичная настройка пошагово, wizard порядок

**Шаги мастера (пошаговая настройка нового клуба).**
1. Профиль клуба: название, контакты, время работы.
2. Подключение: адрес сервера, проверка связи.
3. Касса: драйвер, адрес ДТО, ОФД.
4. Уведомления: SMTP/SMS/MAX, тестовая отправка.
5. Пользователи: первый администратор, роли.
6. Тарифы/услуги: базовые позиции.
«Далее»/«Назад» между шагами; прервать можно — мастер доступен повторно из «Настройки». На уже работающем клубе мастер запускать не нужен.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Настройка онлайн-записи (мини-приложение)
Категория: schedule-services
Вариации запроса: онлайн запись настройка, что видно клиентам, слоты онлайн

**Пошагово.**
1. «Настройки → Расписание»: `SLOT_MINUTES` (шаг слотов), `CANCEL_WINDOW`.
2. У услуг — галочка «Активна» и тренер (только активные услуги видны онлайн).
3. У тренеров — заполненный график.
4. Доступность мини-приложения — IT (домен, HTTPS).
Ожидание: клиент в MAX видит услуги, тренеров, свободные слоты.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Часовой пояс сервера и времена уведомлений
Категория: server
Вариации запроса: часовой пояс, время дайджеста не совпадает, tz

**Проверка.** `timedatectl` на сервере — зона должна быть вашей (Europe/Moscow и т.п.). Дайджест шлётся по серверному времени; расхождение с локальным временем клуба сдвинет время писем. Смена: `timedatectl set-timezone Europe/Moscow`, затем перезапуск контейнеров.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Автозапуск desktop при входе Windows
Категория: desktop
Вариации запроса: автозапуск программы, старт с windows, автозагрузка

**Пошагово.**

## Настройки прокси для desktop
Категория: desktop
Вариации запроса: прокси, интернет через прокси, не ходит наружу

## Сброс настроек desktop
Категория: settings-help
Вариации запроса: сброс настроек, вернуть по умолчанию, переустановка настроек

**Пошагово.**
1. Мягкий сброс: удалить профиль подключения и создать заново («Настройки → Подключения»).
2. Полный сброс: выйти, удалить `%APPDATA%\FitIntel` (настройки/профили/кэш), запустить — настройки станут заводскими (данные на сервере не пострадают).
3. Ожидание: первый запуск как после установки.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Настройка темы для проектора/ТВ (табло)
Категория: settings-help
Вариации запроса: табло настройки, f11 телевизор, второй экран настройка

**Пошагово.**
1. Подключите ТВ как второй монитор (Win+P → «Расширить»).
2. В desktop: F11 — табло на текущем экране; перенесите окно табло на ТВ (Win+Shift+стрелка).
3. Тёмная тема + крупный шрифт («Настройки → Интерфейс») улучшают читаемость с расстояния.
Ожидание: ФИО и цвет прохода видны залу.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Ограничения настройки для не-admin ролей
Категория: users-rbac
Вариации запроса: настройки недоступны, 403 в настройках, кто меняет настройки

**Ответ.** «Настройки», «Роли и права», «Экраны ролей», «Параметры клуба», настройки кассы — только admin (и частично бухгалтер: касса/аудит). Остальным — 403 «Нет прав» (см. errors.md): это RBAC, не сбой. Тонкая раздача — через роли/индивидуальные права.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
