# notifications: тексты и шаблоны сообщений (10 статей)

> Категория: notifications · Переменные, готовые тексты событий, структура рассылок, правила тона.

## Переменные в текстах «Клиенту»
Категория: notifications
Вариации запроса: переменные в уведомлениях, {name} {date}, шаблоны сообщений клиенту
📷 Скриншоты: scr-notif-03.png

**Переменные.** В текстах событий «Клиенту» работают: {name} (имя клиента), {date} (дата события), {sum} (сумма), {tariff} (тариф), {club} (название клуба). Неизвестная переменная уйдёт как текст — проверяйте тестовой отправкой. Формулировка текста — на языке клиента, без внутренних терминов.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Готовые тексты: «Абонемент истекает»
Категория: notifications
Вариации запроса: текст абонемент истекает, шаблон напоминания продление
📷 Скриншоты: scr-notif-03.png

**Пример текста.** «{name}, здравствуйте! Ваш абонемент в {club} заканчивается {date}. Продлите сейчас — сохраним условия и бонусы. Запись/вопросы: {phone}».
**Настройка.** «Клиенту» → событие → «✏» → вставить текст → «💾 Сохранить» → «Тест».
**Правило.** Один призыв к действию, контакт клуба, без давления.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Готовые тексты: «Абонемент истёк»
Категория: notifications
Вариации запроса: текст абонемент истёк, сообщение после истечения, возврат клиента
📷 Скриншоты: scr-notif-03.png

## Рассылка акции: структура сообщения
Категория: notifications
Вариации запроса: рассылка акция текст, структура промо сообщения, как писать акции
📷 Скриншоты: scr-notif-03.png

**Структура.** 1) Обращение по имени. 2) Выгода (что именно получит). 3) Срок (до когда). 4) Условия одной строкой. 5) Призыв + контакт. 6) Возможность отписаться.
**Пример.** «{name}, только до воскресенья: месяц групповых −30%. Успейте продлить по старой цене: {phone}». Тип «Акция», канал MAX.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Тональность и правила коммуникации
Категория: notifications
Вариации запроса: тон сообщений клиентам, правила общения, что нельзя писать
📷 Скриншоты: scr-notif-03.png

**Правила.**
1. Уважительное обращение, без канцелярита и жаргона.
2. Без обещаний вне полномочий (конкретные скидки — только по акциям клуба).
3. Личные данные других клиентов — никогда.
4. Спорные ситуации — не в рассылках, а лично.
5. Каждая акция — с датой окончания (бесконечные акции обесцениваются).
6. Эскалация жалоб — администратору, не переписка-перекидывание.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## A/B подход для рассылок вручную
Категория: notifications
Вариации запроса: ab тест рассылки, два варианта текста, сравнить рассылки
📷 Скриншоты: scr-notif-03.png

**Ручной A/B (в текущей версии).**
1. Разделите сегмент пополам (RFM: два списка).
2. Отправьте два варианта текста (разные формулировки выгоды/призыва).
3. Через 3–7 дней: сравните возвращаемость/продажи по сегментам (визиты, платежи).
4. Победивший вариант — в базу шаблонов.
Метрика: не открываемость, а действие (визит/продление).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Автотексты: что трогать нельзя
Категория: notifications
Вариации запроса: что нельзя менять в шаблонах, переменные обязательные, критичные тексты
📷 Скриншоты: scr-notif-03.png

**Осторожно.**
1. Ссылка/команда отписки в акциях — не удалять.
2. Переменные {name}/{date}/{sum} — не переименовывать (сломается подстановка).
3. Текст события «Оплата» — не убирать упоминание чека (юр. значение для клиента).
4. Согласие/отписка — юридические формулировки менять только с юристом.
Всё остальное — правьте свободно, тестируйте перед массовой отправкой.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
