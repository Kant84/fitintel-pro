## Как открыть кассовую смену (начало дня)
Категория: cash-fiscal
Вариации запроса: открыть смену, начало дня, как начать смену, кассовая смена открытие, где кнопка открыть смену

**Пошагово.**
1. Вкладка «Бухгалтерия» → подвкладка «Платежи» (верхняя строка подвкладок).
2. В блоке кнопок смены нажмите «🔓 Открыть смену».
   Ожидание: баннер «Смена открыта, кассир <ФИО>». Если смена уже открыта — «Смена уже открыта», это норма, ничего делать не нужно.
3. Только после этого подтверждайте платежи — иначе ошибка «Смена закрыта».

**Типичные ошибки.** Искать кнопку в «Бухгалтерия → Бухгалтерия» — она в подвкладке «Платежи».
📷 [SCR-cash-01: кнопка «Открыть смену»]
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Как закрыть смену (конец дня)
Категория: cash-fiscal
Вариации запроса: закрыть смену, з отчёт, z-report, сверка кассы в конце дня, закрытие смены порядок

**Пошагово.**
1. «Бухгалтерия → Платежи»: убедитесь, что НЕТ платежей в статусе «Ожидает» — подтвердите или отмените каждый.
2. Нажмите «🔒 Закрыть смену».
   Ожидание: окно отчёта закрытия: наличные X ₽ / безнал Y ₽ / количество чеков.
3. Сверьте наличные с деньгами в ящике. Расхождение — не закрывайте глаза: найдите платёж, пока смена открыта.
4. После закрытия обороты уходят в «Остаток прошлых смен» до инкассации.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Снятие кассы (инкассация) — забрать остаток
Категория: cash-fiscal
Вариации запроса: снятие кассы, инкассация, обнулить остаток, забрать деньги из кассы, 403 снятие

**Пошагово.**
1. «Бухгалтерия → Платежи» → кнопка «💵 Снятие кассы».
2. Подтвердите действие в диалоге.
   Ожидание: окно «Снято: Наличные X / Безнал Y», остаток обнуляется.
3. Каждое снятие пишется в аудит доступа (кто/когда/сколько).

**Причина 403.** Кнопка доступна только ролям Бухгалтер и Администратор. Войдите под такой ролью.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Как настроить кассу (АТОЛ ДТО 10)
Категория: cash-fiscal
Вариации запроса: настройки кассы, атол, дто 10, адрес кассы, как подключить ккт, ofd настройка

**Пошагово (только admin).**
1. «Платежи → ⚙ Настройки кассы».
2. Драйвер — «АТОЛ» (или «Штрих-М» по факту оборудования).
3. Адрес — `http://<IP-ПК-кассы>:16732` (АТОЛ ДТО 10 слушает этот порт на ПК, где установлено ПО кассы).
4. Логин/пароль ДТО — только если заданы в настройках самого ДТО; иначе оставить пустыми (пустое = не менять).
5. ОФД — ваш оператор: ofd-ru / taxcom / первый-офд / yandex.
6. «Сохранить» → пробейте тестовый чек на 1 ₽.
   Ожидание: чек уходит, в настройках зелёный баннер с текущими значениями.

**Типичные ошибки.** Указывают IP сервера вместо ПК кассы; порт другой после обновления ДТО.
📷 [SCR-cash-03: окно «Настройки кассы (АТОЛ)»]
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Переход с тестового mock на боевую ККТ
Категория: cash-fiscal
Вариации запроса: mock, тестовая касса, боевая ккт, перейти на атол, отключить мок

**Пошагово.**
1. «⚙ Настройки кассы» → адрес боевой АТОЛ `http://<IP>:16732» → «Сохранить».
2. «🔓 Открыть смену» → пробейте тестовый чек на 1 ₽. Ожидание: реальный чек из ФН.
3. Закройте смену, сверьте с Z-отчётом ККТ.
4. Регистрация ФН/привязка ОФД — в кассовом ПО ККТ (вне FitIntel), если ещё не сделано.
5. Mock на `:18004` можно остановить — мешать не будет.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

**Пошагово.**

## X-отчёт без закрытия смены
Категория: cash-fiscal
Вариации запроса: x отчёт, промежуточный отчёт, отчёт не закрывая смену, обороты за день без закрытия

**Пошагово.**
1. Смена должна быть открыта («Платежи» → баннер смены).
2. Нажмите «X-отчёт» в блоке кнопок смены.
   Ожидание: диалог с оборотами (нал/безнал, количество чеков) БЕЗ закрытия смены.
3. Смена продолжает работать — это контрольный срез, а не закрытие.

**Отличие.** X = срез оборотов; Z («Закрыть смену») = закрытие смены и финальный отчёт.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Возврат денег клиенту с фискальным чеком
Категория: cash-fiscal
Вариации запроса: возврат, sellreturn, чек возврата, вернуть деньги клиенту, как оформить возврат

**Пошагово.**
1. «Бухгалтерия → Платежи» → найдите исходный платёж (по клиенту/дате).
2. Выделите строку → кнопка «↩ Возврат».
3. В форме: сумма (пусто = полный возврат; можно частичный) → обязательная причина → «OK».
   Ожидание: статус платежа «Возвращён»; на ККТ уходит чек возврата (sellReturn); в бухгалтерии — сторно-проводка (Дт 90.1 Кт 50/57).
4. Если оплата была с кошелька клиента — сумма вернётся на баланс автоматически.

**Типичные ошибки.** Возврат без указания причины не пройдёт; частичный возврат уменьшает баланс на часть суммы.
📷 [SCR-cash-04: форма «Возврат платежа»]
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Отмена платежа и возврат — в чём разница
Категория: cash-fiscal
Вариации запроса: отмена или возврат, чем отличается отмена, отменить платёж

**Ответ.**
- **Отмена** — только для платежа «Ожидает» (деньги фактически не получены): платёж аннулируется без чека.
- **Возврат** — для «Подтверждённого» платежа: деньги реально были, поэтому обязателен фискальный чек возврата и сторно.

**Пошагово.** Статус «Ожидает» → кнопка «✖ Отменить». Статус «Подтверждён» → «↩ Возврат».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Чек завис: статус «Отправляется в ОФД» долго висит
Категория: cash-fiscal
Вариации запроса: чек не уходит в офд, висит отправляется, чек в очереди

**Пошагово.**
1. Проверьте интернет на ПК с ДТО 10 — очередь ОФД уходит именно с него.
2. В веб-интерфейсе ДТО (порт 16732) → «Документы/Очередь»: там видно зависшие чеки и ошибки ОФД.

## Расхождение наличных при закрытии смены
Категория: cash-fiscal
Вариации запроса: не сходится касса, расхождение наличных, в ящике меньше чем в программе

**Пошагово.**
1. Пока смена открыта: X-отчёт → сверьте каждый наличный платёж со списком «Платежи» (фильтр способ = наличные).
2. Ищите: пропущенный расход (ПКО/РКО в «Бухгалтерия → Касса»), платёж с неверным способом (нал вместо безнал), отменённый/возвращённый платёж.
3. Найденный платёж с неверным способом → «↩ Возврат» → новый платёж с правильным способом (не правьте подтверждённый!).
4. Не нашли — закройте смену с расхождением и зафиксируйте сумму/причину для бухгалтера.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
