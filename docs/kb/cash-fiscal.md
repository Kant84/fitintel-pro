# cash-fiscal — касса, смены, чеки, ККТ

> Категория: cash-fiscal · Проверено для: 1.6.2 · Для кого: кассир, администратор, бухгалтер.

## Как открыть кассовую смену (начало дня)
Ключевые слова: открыть смену, начало дня, кассовая смена
**Ответ.** «Бухгалтерия → Платежи → 🔓 Открыть смену». Если смена уже открыта — система скажет «Смена уже открыта», это нормально, ничего делать не нужно. Без открытой смены чеки не пробиваются (ИНСТРУКЦИЯ §15.6, FISCAL_GUIDE «Смены E33»).
📷 [SCR-cash-01: кнопка «Открыть смену» и ответ «Смена уже открыта»]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как закрыть смену (конец дня)
Ключевые слова: закрыть смену, з отчёт, z-report, сверка кассы
**Ответ.** 1) Убедитесь, что нет платежей со статусом «Ожидает» (подтвердите или отмените). 2) «🔒 Закрыть смену». 3) Появится отчёт: наличные X ₽ / безнал Y ₽ — сверьте наличные с деньгами в ящике. Обороты уходят в «Остаток прошлых смен» до инкассации (ИНСТРУКЦИЯ §26, FISCAL_GUIDE).
📷 [SCR-cash-02: окно отчёта закрытия смены]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Снятие кассы (инкассация) — забрать остаток
Ключевые слова: снятие кассы, инкассация, обнулить остаток, 403 снятие
**Ответ.** «💵 Снятие кассы» → подтверждение → окно «Снято: Наличные X / Безнал Y», остаток обнуляется. Доступно только ролям Бухгалтер/Администратор (иначе 403 — так задумано, каждая инкассация пишется в аудит). Если кнопка недоступна — войдите под нужной ролью (ИНСТРУКЦИЯ §15.2).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как настроить кассу (АТОЛ ДТО 10)
Ключевые слова: настройки кассы, атол, дто 10, адрес кассы, ofd
**Ответ.** «Платежи → ⚙ Настройки кассы» (только admin): Драйвер — АТОЛ (или Штрих-М); Адрес — `http://<IP-кассы>:16732`; Логин/Пароль ДТО (если заданы в кассовом ПО); ОФД — ofd-ru / taxcom / первый-офд / yandex. Пустые поля = не менять. Для боевой ККТ: ДТО 10 установлено на ПК кассы, Web Requests включён (FISCAL_GUIDE, ADMIN_GUIDE §3).
📷 [SCR-cash-03: окно «Настройки кассы (АТОЛ)»]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Переход с тестового mock на боевую ККТ
Ключевые слова: mock, тестовая касса, боевая ккт, перейти на атол
**Ответ.** 1) «⚙ Настройки кассы» → адрес боевой АТОЛ (`http://<IP>:16732`). 2) Пробейте тестовый чек на 1 ₽. 3) Закройте смену и сверьте. 4) Регистрация ФН/привязка ОФД делается в кассовом ПО ККТ (вне FitIntel). Mock на :18004 можно остановить — мешать не будет (FISCAL_GUIDE «Переход на боевую ККТ»).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Тестовый чек не пробивается на mock
Ключевые слова: тестовый чек, mock не работает, 18004
**Ответ.** Mock должен быть запущен (`http://<VM>:18004`, state-файл, сквозная нумерация ФД). Проверка: в настройках кассы адрес mock'а, затем чек на 1 ₽. Ошибку ККТ смотрите в журнале mock'а (FISCAL_GUIDE «Ошибки»).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## X-отчёт без закрытия смены
Ключевые слова: x отчёт, промежуточный отчёт, отчёт не закрывая смену
**Ответ.** В течение дня можно сформировать X-отчёт (обороты без закрытия) — кнопка в блоке смены. Z-отчёт = закрытие смены. Оба доступны только при открытой смене (API `/fiscal/x-report`, `/fiscal/z-report`, FISCAL_GUIDE).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Возврат денег с фискальным чеком
Ключевые слова: возврат, sellreturn, чек возврата, вернуть деньги
**Ответ.** «Платежи» → выделить платёж → «↩ Возврат» → сумма (пусто = полная) → обязательная причина → OK. Статус платежа «Возвращён», на ККТ уходит чек возврата (sellReturn), в бухгалтерии — сторно-проводка (Дт 90.1 Кт 50/57). Частичный возврат уменьшает баланс на часть суммы (ИНСТРУКЦИЯ §29, FISCAL_GUIDE).
📷 [SCR-cash-04: форма «Возврат платежа»]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Кто может открывать и закрывать смену
Ключевые слова: роли касса, кто закрывает смену, права на смену
**Ответ.** Открытие/закрытие смены — кассир, администратор, бухгалтер. «Снятие кассы» — только бухгалтер/администратор (403 остальным). Права настраиваются в «Роли и права» (`cash_desk.open/close/read`, RBAC.md §6).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Где смотреть проводки по кассе
Ключевые слова: проводки, бухгалтерия, дт кт, журнал проводок
**Ответ.** «Платежи → Проводки (бухгалтерия)» — журнал: Дт | Кт | Сумма | Описание. Автопроводки от платежей: нал Дт 50 Кт 90.1, безнал Дт 57 Кт 90.1, расход Дт 91.2 Кт 50/57. Выгрузки: `GET /accounting/export/1c` и `/export/buh` (FISCAL_GUIDE «Проводки»).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».
