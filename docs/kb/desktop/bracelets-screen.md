# desktop: Браслеты/Карты (16 статей)

> Категория: desktop · Экран «Браслеты/Карты»: 4 подвкладки — Программирование · Клиентская карта ·
> Онлайн-замки · Аренда шкафчика. Статусы карт: active=зел, lost=красн, blocked=сер.

## Подвкладки экрана: что где находится
Категория: desktop
Вариации запроса: браслеты карты подвкладки, где программирование, аренда шкафчика где, структура экрана

**Ответ.** «Браслеты/Карты» содержит 4 подвкладки:
1. **Программирование** — выбор носителя и запись на MIFARE.
2. **Клиентская карта** — список привязок карт/QR к клиентам.
3. **Онлайн-замки** — Kerong/TTLock: доски раздевалок.
4. **Аренда шкафчика** — выдача/закрытие аренд.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Записать браслет (MIFARE) с нуля
Категория: desktop
Вариации запроса: записать браслет, программирование mifare, записать карту, пустая карта

**Пошагово.**
1. «Программирование» → «Носитель:» — MIFARE браслет.
2. Поднесите браслет к ACR1252 → пикнет.
3. «Записать карту». Ожидание: «Записано»; пикнет 2 раза.
4. Записать снова → «Карта уже записана» (пропустить сброс/перевыпуск).
5. Ошибка → «Не удалось записать: <причина>» (карта не MIFARE, битый сектор, занятость порта).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Сбросить браслет (MIFARE, очистка)
Категория: desktop
Вариации запроса: сбросить карту, стереть браслет, очистить mifare, обнулить

**Пошагово.**
1. «Программирование» → «Сбросить карту» → подтверждение «Сбросить карту безвозвратно?» → Да.
2. Ожидание: «Сброшена»; пикнет 3 раза.
3. После сброса браслет как новый — запишите заново.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Браслет заблокирован сервером» — красный статус
Категория: desktop
Вариации запроса: заблокирован сервером, красный статус карты, не пускает браслет

**Пошагово.**
1. «Клиентская карта» → найдите карту (поиск по ФИО/UID) → статус blocked/lost.
2. Красный статус = найден блок/утеря: «Причина блокировки: <текст>».
3. Действие: снимите блок в карточке клиента («Блоки») или оформите перевыпуск (visits-access.md).
4. Турникет на blocked/lost отвечает отказом.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Привязка вручную (по UID) без считывателя
Категория: desktop

1. «Клиентская карта» → «Привязка вручную».

3. «Привязать». Ожидание: «✅ Привязка создана». Неверный UID → «UID должен состоять из 8 hex-символов».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Статус lost: браслет утерян
Категория: desktop
Вариации запроса: lost статус, утерянный браслет, карта потеряна

**Пошагово.**
1. «Клиентская карта» → карта → статус lost (красный).
2. Турникет отказывает. Снимите lost (раздел «Блоки» карточки клиента) только если браслет найден.
3. Иначе — перевыпуск: новый браслет → привязка к тому же клиенту.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Аренда шкафчика: выдача
Категория: desktop
Вариации запроса: аренда шкафчика выдача, выдать шкафчик, начать аренду

**Пошагово.**
1. «Аренда шкафчика» → Замок — список онлайн-замков; Клиент — список; «Оплачено» — галочка.
2. «Выдать в аренду». Ожидание: замок открыт, аренда создана; на доске шкафчик занят.
3. Платная аренда без галочки «Оплачено» — оформите платёж отдельно (payments.md).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Статусы карт в «Клиентская карта»

## «Карта уже записана» при программировании
Категория: desktop
Вариации запроса: уже записана, повторная запись, карта занята

**Пошагово.**
1. Это защита от перезаписи чужого носителя. Если браслет клиента — всё ок, привязка уже есть.
2. Перезаписать нужно → «Сбросить карту» → «Записать карту» заново.
3. Повторяется на новых браслетах → партия предзаписанных; сбрасывайте перед записью.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Батарейки онлайн-замков: контроль
Категория: desktop
Вариации запроса: батарейка замка, низкий заряд, замок не открывается

**Ответ.** Состояние батареи видно на доске (подсветка низкого заряда). Меняйте батарейки при первой подсветке — замок внезапно недоступен = клиент без шкафчика и возможная блокировка выпуска («Откройте шкафчик перед выходом!»).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
