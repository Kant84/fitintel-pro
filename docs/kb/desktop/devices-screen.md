# desktop: Устройства (8 статей)

> Категория: desktop · Экран «Устройства»: таблица устройств (Тип|Имя|Адрес|Статус|Версия|Обновлено),
> поля поиска, «Зарегистрировать устройство» / «Открыть устройство» / «Назначить зону».

## Зарегистрировать устройство (окно)
Категория: desktop
Вариации запроса: зарегистрировать устройство, добавить устройство, новое устройство

**Пошагово.**
1. «Устройства» → «＋ Зарегистрировать устройство». Ожидание: окно.
2. Тип — Терминал/Сенсор/Контроллер/Прочее; Имя* (пусто → «Введите имя»); Адрес — IP/hostname; API ключ* (uuid от сервера/платформы); Зона — текст; Токен — необязательно (сгенерируется при сохранении); Версия ПО — необязательно.
3. «OK». Ожидание: «Устройство зарегистрировано: Имя (ID N)», устройство в таблице со статусом online/«—».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Открыть устройство (команда)
Категория: desktop
Вариации запроса: открыть устройство, команда открыть, дверь турникет открыть из устройств

**Пошагово.**
1. Выделите устройство → «Открыть устройство» → «Открыть «Имя» (ID N)?» → Да.
2. Ожидание: «Отправлена команда…»; устройство открылось (физически проверьте).
3. Не выделено → «Выберите устройство».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Назначить зону устройству
Категория: desktop
Вариации запроса: назначить зону, зона устройства, привязка зоны

**Пошагово.**
1. Выделите устройство → «Назначить зону».
2. Выберите зону (список зон клуба) → «OK». Ожидание: зона применена; в таблице колонка «Зона».
3. Зоны используются для отчётов по проходам и правил доступа.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Статус устройства в таблице (online/offline)
Категория: desktop
Вариации запроса: статус устройства, offline красный, мониторинг устройств

**Ответ.** Колонка «Статус»: online (зелёный) — на связи; offline/«—» — нет обновлений. «Обновлено» — время последнего heartbeat. Устройство offline → проверка сети/питания (IT), потом перерегистрация при смене адреса.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Поиск устройства (тип/имя/адрес/статус)
Категория: desktop
Вариации запроса: найти устройство, фильтр устройств, поиск по ip устройства

**Пошагово.**
1. Поля поиска: Тип / Имя / Адрес / Статус.
2. Заполните → список отфильтруется. Очистка — весь список.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## API ключ устройства: где взять и что с ним
Категория: desktop
Вариации запроса: api ключ устройства, где взять ключ, uuid устройства

**Ответ.** API ключ — uuid, который сервер/платформа выдаёт при регистрации устройства (или генерируется при сохранении, если поле пусто). Устройство предъявляет его при подключении. Потерян/скомпрометирован → перевыпуск через IT (перерегистрация). Не публикуйте ключи в чатах.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Типы устройств в списке
Категория: desktop
Вариации запроса: типы устройств, терминал сенсор контроллер, какой тип выбрать

**Ответ.** Типы: Терминал (киоск/стационарный терминал), Сенсор (датчики), Контроллер (СКУД/двери), Прочее. Тип влияет на отображение и команды; для турникетов используется СКУД-контур (skud-hardware.md).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Устройство пропало из списка
Категория: desktop
Вариации запроса: устройство исчезло, нет в списке, куда пропало

**Пошагово.**
1. Очистите фильтры поиска.
2. Проверьте статус/перерегистрацию: возможно, устройство удалено администратором (аудит).
3. «Обновить» список. Нет — зарегистрируйте заново (новый ID/ключ при необходимости).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
