# desktop/install-login — установка, первый запуск, вход

> Категория: desktop · Проверено для: 1.6.2 · Для кого: все роли.

## Как установить программу на рабочий ПК
Ключевые слова: установка, инсталлятор, setup, как поставить программу
**Ответ.** 1) Получите `FitIntelDesktop-Setup_v1.6.2.exe` (~154 МБ) от администратора. 2) Проверьте хеш: `Get-FileHash .\FitIntelDesktop-Setup_v1.6.2.exe -Algorithm SHA256` — должен совпасть с RELEASES.md. 3) Запустите двойным щелчком (прав администратора не требуется) → «Далее» → по желанию ярлык на рабочем столе → «Установить» → «Завершить». Альтернатива — portable-вариант: один .exe в любой папке (ИНСТРУКЦИЯ §2).
📷 [SCR-desktop-01: окно приветствия Setup]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Первый запуск: окно «Подключение к серверу»
Ключевые слова: адрес сервера, первый запуск, подключение к серверу, api_base
**Ответ.** Введите адрес сервера клуба: `http://192.168.x.x` (или домен, если есть). Окончание `/api/v1` программа допишет сама. «OK» — профиль сохранится, окно больше не появится. Не знаете адрес — спросите администратора клуба. Сменить позже: «Настройки → Сервер API» или «Подключения» (superadmin) (ИНСТРУКЦИЯ §3.1).
📷 [SCR-desktop-02: окно «Подключение к серверу»]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Активация лицензии (первый запуск сервера)
Ключевые слова: активация, лицензия, fipro, ключ
**Ответ.** Окно появляется только на новом сервере и только один раз. 1) Вставьте ключ из письма целиком (начинается с `FIPRO-`, Ctrl+A → Ctrl+C в письме). 2) «Активировать и войти» — система войдёт сама. После активации сохраните логин/пароль SuperAdmin из ответа. Ошибки: «должен начинаться с FIPRO-» — скопируйте заново; «403» — ключ привязан к другому серверу, нужен новый у платформы; «нет связи» — проверьте адрес сервера (ИНСТРУКЦИЯ §3.2, INSTALL_SERVER.md §10).
📷 [SCR-desktop-03: окно активации лицензии]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как войти в систему
Ключевые слова: вход, логин, войти, авторизация
**Ответ.** Поля «Логин» (ваш email) и «Пароль» → «Войти» или Enter. Галочка «Запомнить меня» — только на своём ПК! Если пароль временный — после входа откроется обязательная смена (ИНСТРУКЦИЯ §4).
📷 [SCR-desktop-04: окно входа]
**Если не помогло:** см. статьи «Неверный логин или пароль» и «Аккаунт заблокирован» в errors.md.

## Забыл пароль
Ключевые слова: забыл пароль, сброс пароля, восстановить доступ
**Ответ.** Пароль восстанавливает администратор клуба: «Пользователи» → выбрать учётку → «Сбросить пароль» → сообщить вам новый. При первом входе с ним вы зададите свой (ИНСТРУКЦИЯ §19.5).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как сменить свой пароль
Ключевые слова: сменить пароль, поменять пароль
**Ответ.** Меню «Файл → Сменить пароль…» → старый, новый (минимум 8 символов), повтор → «Сохранить» (ИНСТРУКЦИЯ §5.3).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как обновить программу
Ключевые слова: обновление, новая версия, апдейт
**Ответ.** Просто запустите новый установщик — он поставится поверх, настройки и профили подключений сохранятся. Версия видна внизу главного окна и в «Настройки → О программе» (ИНСТРУКЦИЯ §2.4).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Несколько клубов/серверов на одном ПК (профили)
Ключевые слова: несколько баз, профиль подключения, второй клуб, подключения
**Ответ.** «Подключения» (видит superadmin): «Добавить…» → название + тип («Веб-сервер (URL)») → адрес, логин, пароль → «Сохранить». «Подключить» — применить профиль (нужен перезапуск клиента). При нескольких профилях при старте появится окно «Выбор информационной базы» — как в 1С (ИНСТРУКЦИЯ §24).
📷 [SCR-desktop-05: окно выбора информационной базы]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Перенос программы на другой ПК
Ключевые слова: перенос, другой компьютер, переустановка
**Ответ.** Установите Setup на новом ПК и введите адрес сервера — данных на ПК не хранится, ничего переносить не нужно. Личные настройки (тема, профили) лежат в `client_settings.json` и `connections.json` рядом с программой — можно скопировать при желании (ИНСТРУКЦИЯ §2).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Программа не запускается / сразу закрывается
Ключевые слова: не запускается, закрывается, белое окно, crash
**Ответ.** 1) Windows 10/11 64-разрядная — проверьте. 2) Антивирус не должен блокировать `FitIntelDesktop.exe` (добавьте в исключения). 3) Запустите из консоли и пришлите текст ошибки:
```powershell
cd "C:\Program Files\FitIntel Desktop"
.\FitIntelDesktop.exe
```
4) Логи: «Настройки → Логи → Открыть папку логов» (файл `client_ГГГГММДД.log`).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)» + последние строки лога.
