## Системные требования desktop
Категория: desktop
Вариации запроса: требования, на каком компьютере работает, windows версия, сколько места

**Ответ.** Windows 10/11 (64-бит), 4 ГБ RAM (рекомендуется 8), 500 МБ на диске (с кэшем — до 1,5 ГБ), разрешение от 1280×720. Интернет/локальная сеть до сервера клуба. Для кассового места — дополнительно: АТОЛ ДТО 10, USB-считыватель ACR1252 (порты USB напрямую, без хабов).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Установка desktop (Setup v1.6.2)
Категория: desktop

## Проверка целостности дистрибутива (SHA-256)
Категория: desktop
Вариации запроса: хеш, sha256, контрольная сумма, проверить файл установки

**Пошагово (Windows, PowerShell).**
1. Перейдите в папку с установщиком: `Set-Location <папка>`.
2. `Get-FileHash .\FitIntelDesktop-Setup_v1.6.2.exe -Algorithm SHA256`.
3. Сверьте с хешем из письма/документации клуба. Ожидание: полное совпадение строк.
4. Не совпадает — файл битый/подменён: скачайте заново из доверенного источника.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Первый запуск после установки
Категория: desktop
Вариации запроса: первый запуск, запуск программы, старт после установки, что дальше

**Пошагово.**
1. Ярлык «FitIntel Desktop» → запуск (первый старт — 5–10 секунт).
2. Если адрес сервера не был задан в установщике — откроется «Настройки → Подключения»: введите `http://<IP-сервера>/api/v1` → «Проверить связь» → «Сохранить».
3. Ожидание: окно входа (поля Логин/Пароль), внизу — зелёный статус сервера.
4. Войдите по учётке сотрудника (email + пароль от администратора).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Активация лицензии на ПК
Категория: desktop
Вариации запроса: активация, лицензионный ключ, активировать, код лицензии

**Пошагово.**
1. При первом запуске откроется окно активации (или «Настройки → Лицензия»).
2. Введите код лицензии клуба (выдаёт администратор/владелец).
3. «Активировать». Ожидание: зелёный статус «Лицензия активна», тариф и срок.

**Ошибки активации.**
- WinError 10061 / таймаут — нет связи с сервером (проверьте адрес и сеть, errors.md).
- «Недействительный ключ» — проверьте копирование (без пробелов в начале/конце).
- «Лицензия просрочена» — обратитесь к тому, кто выдаёт лицензии.

## Вход в систему (логин/пароль)

Вариации запроса: вход, залогиниться, как войти, логин пароль

**Пошагово.**

## Забыли пароль: восстановление
Категория: desktop
Вариации запроса: забыл пароль, восстановить пароль, сбросить пароль, не помню пароль

**Пошагово.**
1. Самостоятельного восстановления по email нет — пароль сбрасывает администратор клуба.
2. Обратитесь к администратору: «Пользователи» → ваша карточка → «Сбросить пароль» → временный пароль.
3. Войдите с временным → система сама откроет смену пароля → задайте новый 8+ символов.
   Ожидание: вход выполнен, пароль обновлён.
4. Пароль — личный: не передавайте, не храните на стикерах у монитора.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Смена пароля самостоятельно
Категория: desktop
Вариации запроса: сменить пароль, поменять пароль, новый пароль

**Пошагово.**
1. Меню «Файл → Сменить пароль» (или кнопка профиля в шапке).

Категория: desktop

1. Получите новый установщик (Setup vX.Y.Z) от администратора/разработчика.

## «Не запускается»: диагностика
Категория: desktop
Вариации запроса: не запускается, не открывается, ошибка запуска, вылетает при старте

**Пошагово.**
1. Перезагрузите ПК — часто помогает (зависший порт/драйвер считывателя).
2. Запуск от имени администратора (права на каталог установки).
3. Антивирус/Defender: добавьте папку FitIntel в исключения (иногда блокирует PyQt-приложения).
4. Посмотрите логи: `%APPDATA%\FitIntel\logs` — последний файл, последние строки ошибки.
5. Переустановка поверх (настройки сохранятся) или чистая переустановка.
   Ожидание на каждом шаге: программа стартует — фиксируйте шаг.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)». + лог запуска.

## Установка на кассовое рабочее место
Категория: desktop
Вариации запроса: кассовое место, установка на кассу, пк кассира, атол на рабочем месте

**Пошагово.**
1. Стандартная установка desktop.
2. Установите АТОЛ ДТО 10 на ЭТОТ ПК (с сайта АТОЛ, регистрация/лицензия по договору).
3. Подключите ККТ к ПК (USB/сеть), включите, проверьте связь в ДТО.
4. В FitIntel: «Платежи → ⚙ Настройки кассы» → адрес `http://localhost:16732` (или IP ПК) → «Сохранить» → тестовый чек 1 ₽.
5. Подключите USB-считыватель ACR1252 (напрямую в порт).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Windows SmartScreen блокирует установку
Категория: desktop
Вариации запроса: smartscreen, windows защитил, не даёт установить, неизвестное приложение

**Пошагово.**
1. Это стандартное предупреждение для новых программ — не вирус.
2. «Подробнее» → «Выполнить в любом случае».
3. Если кнопки нет (корпоративная политика) — попросите IT добавить установщик в исключения или подписать дистрибутив.
4. Для спокойствия: сверьте SHA-256 дистрибутива (статья «Проверка хеша»).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
