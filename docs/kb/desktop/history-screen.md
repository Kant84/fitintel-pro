# desktop: История (7 статей)

> Категория: desktop · Экран «История»: фильтры Сущность/Действие/Кто/период, «Загрузить», «Срок хранения…».

## Журнал изменений: фильтры и загрузка
Категория: desktop
Вариации запроса: журнал истории, кто что менял, фильтры истории, загрузить историю

**Пошагово.**
1. «История» → задайте фильтры: «Сущность:» (Все/Пользователи/Клиенты/Платежи/Абонементы/Визиты/Роли), «Действие:» (Все/Создано/Изменено/Удалено), «Кто:» (логин, частично), «С:/по:» (по умолчанию месяц).
2. «Загрузить». Ожидание: таблица Когда | Кто | Действие | Сущность | ID | Детали (старые/новые значения); сверху «Записей: N».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Детали записи: старые и новые значения
Категория: desktop
Вариации запроса: детали изменения, что было и что стало, разбор правки

**Ответ.** Колонка «Детали» показывает изменённые поля со старым и новым значением. Для разбора споров («кто изменил телефон клиента») найдите запись фильтром по сущности/клиенту и смотрите колонку «Кто» и детали.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Срок хранения…» — политика хранения журнала
Категория: desktop
Вариации запроса: срок хранения, сколько хранится история, очистка журнала

**Пошагово.**
1. «Срок хранения…» → текущий срок → форма: Месяц (30) / Полгода (180) / Год (365) / 2 года (730) / Бессрочно (0).
2. «OK». Ожидание: «Срок хранения: N дн.» + журнал перезагружен.
3. Записи старше срока удаляются автоматически.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Кто удалил клиента/платёж — как найти
Категория: desktop
Вариации запроса: кто удалил, найти удаление, разбор инцидента

**Пошагово.**
1. «История» → Сущность: Клиенты (или Платежи) → Действие: Удалено → «Загрузить».
2. Ожидание: записи с логином и временем.
3. Детали — что именно изменилось/удалено.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## История не показывает нужную запись
Категория: desktop
Вариации запроса: записи нет в истории, не ищется, пустой журнал

**Пошагово.**
1. Расширьте период «С/по».
2. Ослабьте фильтры (Сущность: Все, Действие: Все, «Кто» — пусто).
3. Проверьте срок хранения — запись могла устареть и удалиться.
4. «Загрузить» заново.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Фильтр «Кто» — поиск по логину
Категория: desktop
Вариации запроса: фильтр кто, поиск по сотруднику, действия конкретного пользователя

**Ответ.** Поле «Кто:» фильтрует по логину (частичное совпадение). Для сверки действий сотрудника за смену: «Кто:» = логин + «С/по» = смена → «Загрузить».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Записей: N» — статус загрузки
Категория: desktop
Вариации запроса: записей n, сколько записей, счётчик истории

**Ответ.** Строка «Записей: N» — число строк, попавших под фильтры. Большие периоды урежьте фильтрами, иначе загрузка медленная.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
