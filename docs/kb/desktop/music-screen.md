# desktop: Музыка/DJ (12 статей)

> Категория: desktop · Экран «Музыка/DJ»: левая колонка (библиотека/режимы/A.I.DJ),
> A.I.DJ панель, 2 деки (A/B) с фейдером, Jingles (4 пада), AURA баннеры/пресеты.

## Загрузить трек в библиотеку
Категория: desktop
Вариации запроса: загрузить трек, добавить музыку, библиотека музыка, mp3 в программу

**Пошагово.**
1. «Музыка/DJ» → левая колонка → «📂 Загрузить файл». Ожидание: диалог выбора.
2. Выберите MP3/FLAC → «Открыть». Ожидание: трек появился в списке (Название/Исполнитель — из тегов).
3. Ошибка формата → «⚠ Неверный формат аудиофайла».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Загрузить папку сразу
Категория: desktop
Вариации запроса: загрузить папку, импорт музыки, много треков сразу

**Пошагово.**
1. «📂 Загрузить папку». Ожидание: диалог выбора папки.
2. Выберите папку с MP3/FLAC → «Выбрать папку». Ожидание: треки загружаются списком; счётчик обновляется.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Режимы воспроизведения (подвкладки AUTO/DJ/MEGA)
Категория: desktop
Вариации запроса: режимы музыки, auto dj mega, переключение режимов

**Ответ.** Подвкладки левой колонки: AUTO (автоподбор/радио-подобный поток), DJ (ручное управление деками), MEGA (расширенный режим). Переключение — кликом; активный режим подсвечен. Для стандартной работы зала — DJ; AUTO — фон без оператора.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Поставить трек на деку A или B
Категория: desktop
Вариации запроса: поставить на деку, дека а б, загрузить в деку, play deck

**Пошагово.**
1. Выделите трек в библиотеке → «→ A» или «→ B». Ожидание: трек загружен на деку (обложка/название/длительность/битрейт).
2. Кнопки деки: ▶/⏸, перемотка, громкость канала, питч (±%), CUE.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Фейдер и сведение A↔B
Категория: desktop
Вариации запроса: фейдер, crossfader, свести деки, плавный переход

**Пошагово.**
1. Обе деки загружены; играет A (фейдер к A).
2. Запустите B с нужного места (CUE → ▶).
3. Плавно ведите фейдер к B. Ожидание: громкость A падает, B растёт — переход без паузы.
4. Точный crossfade по секундам — в A.I.DJ панели (автосведение).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## A.I.DJ: автоматический диджей
Категория: desktop
Вариации запроса: ai dj, автодиджей, автоматическая музыка, энергетика

**Ответ.** Панель A.I.DJ: автоподбор следующих треков по энергетике/BPM, автосведение, автовolume. Включите режим → задайте энергетику (Energize) → система ведёт сет сама. Ручное вмешательство всегда возможно (деки остаются под контролем).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Пады Jingles (4 кнопки)
Категория: desktop
Вариации запроса: джинглы, jingles пады, звуковые кнопки музыка

**Пошагово.**
1. Блок «Jingles» — 4 пада (1–4).
2. Назначение: удержать/клик по пустому → выбор файла (джингл/applause).
3. Клик — воспроизведение поверх музыки (не прерывая деки). Ожидание: сэмпл играет.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## AURA: баннеры и пресеты звука
Категория: desktop
Вариации запроса: aura, пресеты звука, обработка звука, баннеры

**Ответ.** Блок AURA — обработка/пресеты звучания зала (эквализация/компрессия общего микса) и информационные баннеры. Выберите пресет под зал/время суток → «💾 Сохранить». Индивидуальная настройка — ползунки блока.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## MUTE ALL и экстренная тишина
Категория: desktop
Вариации запроса: mute all, выключить звук, экстренно музыку off

**Пошагово.**
1. Кнопка «MUTE ALL» (в блоке управления). Ожидание: обе деки и джинглы приглушены мгновенно, индикация красная.
2. Повторное нажатие — вернуть громкость.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Неверный формат аудиофайла»
Категория: desktop
Вариации запроса: не грузится трек, ошибка формата, какие форматы

**Ответ.** Поддерживаются MP3 и FLAC. WAV/OGG/M4A — конвертируйте в MP3 (любой конвертер). DRM-защищённые файлы (купленные в стримингах) не воспроизводятся.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Треки в библиотеке без названий
Категория: desktop
Вариации запроса: без названий исполнителей, теги не читаются, unknown

**Ответ.** Название/исполнитель берутся из ID3-тегов файла. Без тегов — «Неизвестный исполнитель». Проставьте теги (Mp3tag и т.п.) и загрузите заново.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Лицензия провайдера музыки (AURA/License)
Категория: desktop
Вариации запроса: лицензия музыка, provider license, до какого числа лицензия

**Ответ.** В блоке AURA отображается лицензия музыкального провайдера (на nfs — до 2027-12-31, MU-2026-118). Просрочка — ограничения автоподбора. Продление — у провайдера/владельца. Отдельно: публичное исполнение в зале — договоры РАО/ВОИС (music-dj.md).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
