# desktop: Face ID (экран) (10 статей)

> Категория: desktop · Экран «Face ID»: список шаблонов (N записей), 4 диалога настроек
> (Камеры / Порог / События / Шаблоны). Без согласия 152-ФЗ шаблоны не создаются.

## Экран Face ID: структура
Категория: desktop
Вариации запроса: экран face id, где настройки face id, шаблоны список, структура экрана

**Ответ.** Экран показывает список зарегистрированных лиц (ФИО, дата, источник) и открывает 4 диалога:
1. **Камеры** — список и выбор источников видео.
2. **Порог** — схожесть для распознавания (по умолчанию 0.6).
3. **События** — журнал распознаваний (время, камера, счётчик, результат).
4. **Шаблоны** — управление: добавить/переснять/удалить.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Диалог «Камеры»: выбрать источник
Категория: desktop
Вариации запроса: камеры диалог, выбрать камеру, источник видео face id

**Пошагово.**
1. «Face ID → Камеры». Ожидание: список устройств (USB/RTSP).
2. Отметьте нужные, задайте приоритет → «Сохранить».
3. Камера не в списке → проверьте подключение/драйверы (skud-hardware.md «Камера не найдена»).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Диалог «Порог»: настроить схожесть
Категория: desktop
Вариации запроса: порог схожести, настроить порог, 0.6 порог

**Пошагово.**
1. «Face ID → Порог». Ожидание: текущее значение (0.6 по умолчанию).
2. Двигайте ползунок (обычно 0.6–0.7) → «Сохранить».
3. Тест: несколько проходов. Ложные пуски — поднимайте; не узнаёт своих — понижайте/переснимайте шаблоны.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Диалог «События»: журнал распознаваний
Категория: desktop
Вариации запроса: события face id, журнал распознаваний, счётчик схожести в логе

**Пошагово.**
1. «Face ID → События» → «Обновить».
2. Ожидание: таблица Время | Камера | Клиент/«неизвестно» | Схожесть | Результат (проход/отказ).
3. Поиск по времени для разбора конкретного прохода.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Диалог «Шаблоны»: добавить/переснять/удалить
Категория: desktop
Вариации запроса: шаблоны диалог, переснять лицо, удалить шаблон face id

**Пошагово.**
1. «Face ID → Шаблоны».
2. «➕ Добавить» → клиент (только с согласием биометрии) → захват кадров.
3. Выбор шаблона → «Переснять» (новые кадры) или «Удалить» (подтверждение).
4. Ожидание: список обновлён; изменения сразу действуют на турникете.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «N записей» — счётчик шаблонов
Категория: desktop
Вариации запроса: сколько лиц зарегистрировано, записей face id, счётчик шаблонов

**Ответ.** Заголовок экрана «N записей» — число шаблонов лиц в системе. Согласовано с журналом шаблонов. Резкий рост без регистраций — проверьте аудит (кто добавлял).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Клиент есть в базе, но не распознаётся на турникете
Категория: desktop
Вариации запроса: есть в базе не узнаёт, шаблон есть не пускает, face id не срабатывает

**Пошагово.**
1. «События» — найдите проход: какая схожесть? Ниже порога → переснимите шаблон, проверьте свет.
2. Шаблона нет в списке → регистрация не завершилась (403 consent?) — оформите согласие и добавьте.
3. Порог завышен → временно 0.6 → тест.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## 403 при регистрации лица (biometric_consent_required)
Категория: desktop
Вариации запроса: 403 биометрия, consent required, не даёт добавить лицо

**Пошагово.**
1. Карточка клиента → «Согласия» → подпишите согласие на биометрию.
2. Повторите «Шаблоны → ➕ Добавить». Ожидание: захват проходит.
3. Согласие отозвано → шаблоны удалены автоматически; регистрация снова невозможна до нового согласия.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## RTSP-камеры турникета: добавление
Категория: desktop
Вариации запроса: rtsp камера, ip камера face id, добавить камеру турникета

**Пошагово (IT).**
1. «Face ID → Камеры → ➕» → URL вида `rtsp://user:pass@IP:554/stream`.
2. Проверьте доступность потока с ПК/сервера (VLC) до добавления.
3. «Сохранить» → превью пошло → тестовый захват.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Порог и ложные срабатывания: баланс
Категория: desktop
Вариации запроса: ложные пуски порог, подобрать порог, точность face id

**Ответ.** Порог 0.6 — стартовый. Ложные пуски → 0.65–0.7 + качественные шаблоны + второй фактор (браслет). Не узнаёт своих → пересъёмка при хорошем свете + 0.55–0.6. Меняйте по одному параметру и тестируйте на 10+ проходах.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
