# desktop: Бухгалтерия (12 статей)

> Категория: desktop · Экран «Бухгалтерия»: подвкладки «💰 Касса» (ПКО/РКО), «📊 Отчёты» (ОСВ/P&L/Баланс),
> «📝 Проводки», «🔄 1С» (mock-экспорт). План счетов: 50/51/57/60/62/66/90.1/90.2/91.2/99.

## ПКО — приходный кассовый ордер (быстрый)
Категория: desktop
Вариации запроса: пко, приходный ордер, принять наличные в кассу, кнопка пко

**Пошагово.**
1. «Бухгалтерия → 💰 Касса».
2. Поля ПКО: Сумма (по умолчанию 1000), Описание («Абонемент»), Номер (необязательно).
3. «📥 ПКО (приход)». Ожидание: «✅ ПКО создан: …», проводка Дт 50.
4. Ошибки — красным под формой.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## РКО — расходный кассовый ордер (быстрый)
Категория: desktop
Вариации запроса: рко, расходный ордер, выдать деньги из кассы, кнопка рко

**Пошагово.**
1. «Бухгалтерия → 💰 Касса».
2. Поля РКО: Сумма (500), Описание («Расход»), Номер.
3. «📤 РКО (расход)». Ожидание: «✅ РКО создан: …», проводка Кт 50.
4. Не хватает наличных в кассе — сервер откажет текстом.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## ОСВ — оборотно-сальдовая ведомость
Категория: desktop
Вариации запроса: осв, оборотно сальдовая, построить осв, бухгалтерская ведомость

**Пошагово.**
1. «Бухгалтерия → 📊 Отчёты» → «Период:» (список месяцев, например 2026-08).
2. «📊 ОСВ». Ожидание: таблица Счёт | Сн Дт | Сн Кт | Оборот Дт | Оборот Кт | Ск Дт | Ск Кт; статус «ОСВ: N счетов».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## P&L — отчёт о прибылях и убытках
Категория: desktop
Вариации запроса: p&l, прибыль убыток, финансовый результат, доходы расходы отчёт

**Пошагово.**
1. «Отчёты» → «Период» → «💰 Прибыль/убыток».
2. Ожидание: Доходы / Себестоимость / Расходы / Прочие доходы / Прибыль.
3. Месяц берётся из поля «по».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Баланс (активы = пассивы)
Категория: desktop
Вариации запроса: баланс, активы пассивы, сходится баланс

**Пошагово.**
1. «Отчёты» → «⚖️ Баланс».
2. Ожидание: Активы | Пассивы | «сходится ✅ / не сходится ❌».
3. «Не сходится» — разбор с бухгалтером по журналу проводок.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Подвкладка «📝 Проводки»
Категория: desktop
Вариации запроса: журнал проводок бухгалтерия, загрузить проводки, дт кт журнал

**Пошагово.**

2. Ожидание: таблица ID | Дата | Дт | Кт | Сумма | Описание.
3. Период в этой версии фиксирован (август 2026); общий журнал — «Платежи → Проводки (бухгалтерия)».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «ОСВ: 0 счетов» / пустой отчёт
Категория: desktop
Вариации запроса: осв пустая, нет данных отчёт, нули в бухгалтерии

**Пошагово.**
1. Смените «Период» на месяц, где были платежи.
2. Проверьте, что платежи подтверждены (только «Завершён» создаёт проводки).
3. «Пересчитать историю» не влияет на проводки — они пишутся при подтверждении.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## ПКО/РКО: роли и ошибки
Категория: desktop
Вариации запроса: кто создаёт пко рко, ошибка ордера, права на кассу

**Ответ.** Касса доступна ролям с правом `cash_desk` (Кассир/Администратор/Бухгалтер). Ошибки суммы — красным под формой; 403 — нет прав (см. errors.md «Нет прав»). Каждый документ — с номером и описанием; удаление/правка — через поддержку (аудит).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Сверка кассы по видам оплаты
Категория: desktop
Вариации запроса: сверка нал безнал, почему наличных меньше, куда деньги

**Пошагово.**
1. «Платежи» → строка балансов: текущая смена нал/безнал отдельно.
2. «Бухгалтерия → Отчёты → ОСВ» — обороты 50 и 57.
3. Несходка наличных: ищите платёж со способом «наличные» вместо карты или РКО (расход).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
