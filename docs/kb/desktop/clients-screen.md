# desktop: Клиенты (12 статей)

> Категория: desktop · Экран «Клиенты»: таблица (только Активные), поиск, кнопки Добавить/Изменить/Деактивировать/Удалить/Обновить.
> Формы: «Новый клиент» — Фамилия*/Имя*/Отчество/Телефон*/Email*/Пол/Дата рождения.

## Как добавить клиента (пошагово с полями формы)
Категория: desktop
Вариации запроса: добавить клиента, новый клиент кнопка, завести карточку, создать посетителя

**Пошагово.**
1. «Клиенты» → «＋ Добавить». Ожидание: окно «Новый клиент».
2. Заполните: Фамилия*, Имя*, Телефон* (с +7), Email* (связывает с личным кабинетом), Пол, Дата рождения (ДД.ММ.ГГГГ).
3. «OK». Ожидание: клиент в таблице.
4. Пустое обязательное поле → «Заполните обязательные поля: фамилия, имя, телефон, email». Дубль email/телефона → текст ошибки сервера.

**Типичные ошибки.** Двузначный год «ДД.ММ.ГГ» станет 20ГГ (система дописывает); неверный формат → «Неверный формат даты: …».
📷 [SCR-clients-01]
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Поиск клиента на экране (фильтрация на лету)
Категория: desktop
Вариации запроса: поиск клиента, найти по телефону, фильтр списка, строка поиска клиенты

**Пошагово.**
1. «Клиенты» → поле поиска слева вверху.
2. Начните печатать ФИО, телефон или email. Ожидание: список фильтруется на лету.
3. Очистите поле — снова весь список.
4. Двойной клик по строке = «✎ Изменить» (форма правки с текущими значениями).

**Типичные ошибки.** Таблица показывает только Активных: неактивный клиент не найдётся здесь — смотрите фильтры/другие экраны или восстановление.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Изменить данные клиента
Категория: desktop
Вариации запроса: изменить клиента, правка карточки, отредактировать телефон, поменять email

**Пошагово.**
1. «Клиенты» → выделите строку → «✎ Изменить» (или двойной клик).

3. Email/телефон уникальны: дубль → ошибка сервера текстом.

## «⊘ Деактивировать» vs «🗑 Удалить» — разница
Категория: desktop
Вариации запроса: деактивировать или удалить, разница удаления, безвозвратно ли

**Ответ.** Оба действия не стирают историю:
- «⊘ Деактивировать» — клиент пропадает из активных списков, история (платежи, визиты) сохраняется.
- «🗑 Удалить» — подтверждение «УДАЛИТЬ безвозвратно?», но технически на сервере выполняется та же деактивация (физически не удаляется, чтобы не потерять историю). Клиент сразу исчезает из таблицы.
**Восстановление:** корзина/поддержка (clients-subs.md «Корзина»).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Дата рождения: форматы ввода
Категория: desktop
Вариации запроса: формат даты рождения, не принимает дату, дд мм гггг

**Ответ.** Принимаются: ДД.ММ.ГГГГ, ГГГГ-ММ-ДД, ДД.ММ.ГГ (двузначный год станет 20ГГ). Неверный формат → «Неверный формат даты: …» — исправьте и «OK» заново.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Обновить» на экране Клиенты
Категория: desktop
Вариации запроса: обновить список клиентов, кнопка обновить, не вижу нового клиента

**Ответ.** Кнопка «Обновить» перечитывает список с сервера. Если коллега только что создал клиента, а его нет — нажмите «Обновить» (или F5). Ожидание: список актуален.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Не создаётся клиент: «Заполните обязательные поля»
Категория: desktop
Вариации запроса: обязательные поля, не сохраняется клиент, ошибка формы

**Пошагово.**

2. Заполните → «OK». Ожидание: клиент создан.
3. Все поля заполнены, но ошибка — читайте текст: дубль email/телефона (найдите дубль поиском), ошибка сервера с кодом.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Импорт клиентов из CSV (A&A)
Категория: desktop
Вариации запроса: импорт клиентов, загрузить из csv, перенести базу, a&a импорт

**Пошагово.**
1. Подготовьте CSV с колонками: `ФИО;Телефон;Email;Дата рождения;Пол;Категория;Статус;Фото(URL)` (разделитель — точка с запятой).
2. «Интеграции → 🔗 A&A → 📥 Импорт CSV».
3. Поле пути + «📂 Обзор» → выберите файл → «📥 Импортировать».
4. Ожидание: «✅ Импортировано: N, ошибок: M». Ошибки — в журнале («📝 Журнал → 🔄 Обновить журнал»).

**Типичные ошибки.** Неверный разделитель (должна быть «;»), телефоны без +7, кодировка не UTF-8.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Клиент в таблице есть, но не находится поиском
Категория: desktop
Вариации запроса: не находит клиента, поиск не ищет, клиент пропал из списка

**Пошагово.**
1. Проверьте статус: ищется ли только среди Активных — деактивированный не попадёт.
2. Проверьте написание: пробелы, буквы ё/е, регистр.
3. Ищите по телефону — часть номера с конца (…1234).
4. «Обновить» список. Нет — восстановление из корзины (clients-subs.md).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
