# desktop: Лицензия и Мастер установки (7 статей)

> Категория: desktop · Экран «Лицензия»: статус/дата окончания/тариф/лимиты, кнопка активации.
> «Мастер установки»: пошаговая первичная настройка нового клуба.

## Активировать лицензию (окно «Активация»)
Категория: desktop
Вариации запроса: активировать лицензию, окно активации, код лицензии куда вводить

**Пошагово.**
1. «Лицензия» → «🔑 Активировать…». Ожидание: окно с полем «Код лицензии».
2. Вставьте код (без пробелов по краям) → «OK».
3. Ожидание: «Лицензия активирована», статус обновлён.
4. Ошибка: «Недействительный ключ» (проверьте копирование), «Лицензия просрочена» (к выдающему), WinError 10061 (связь с сервером — errors.md).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Статус лицензии на экране
Категория: desktop
Вариации запроса: статус лицензии, до какого числа, тариф лицензии, лимиты

**Ответ.** Экран «Лицензия» показывает: Статус (активна/просрочена), Дата окончания, Тариф, Лимиты (пользователи/клиенты/филиалы — по тарифу). Просрочка — сервер переходит в ограниченный режим (часть функций недоступна, «нет подписок» — errors.md).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Лицензия истекает через N дней»
Категория: desktop
Вариации запроса: предупреждение лицензии, истекает скоро, grace период

**Ответ.** За N дней до окончания система показывает предупреждение. Обратитесь к тому, кто выдаёт лицензии (платформа/владелец) для продления — новый код вводится кнопкой «🔑 Активировать…» поверх старой. После даты — grace-режим с ограничениями, затем блокировка функций.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Мастер установки: запуск и назначение
Категория: desktop
Вариации запроса: мастер установки, первичная настройка клуба, wizard, пошаговая настройка

**Ответ.** «Мастер установки» (в «Настройки») — пошаговая настройка нового клуба: профиль клуба, подключение, касса, уведомления, пользователи — без необходимости лазить по всем вкладкам. Запускается при первом развёртывании; повторно — вручную. Каждый шаг: объяснение → поля → «Далее»/«Назад».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Переактивация после сброса/переноса сервера
Категория: desktop
Вариации запроса: переактивация, сервер переехал, лицензия слетела, активировать заново

**Пошагово.**
1. Проверьте связь с новым адресом сервера («Настройки → Подключения»).
2. «Лицензия → 🔑 Активировать…» → тот же код лицензии клуба.
3. Ожидание: «Лицензия активирована».
4. Лицензия привязана к клубу, а не к ПК — переезд сервера не требует новой лицензии при сохранении БД.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «У вас нет подписок» — лицензия и модули
Категория: desktop
Вариации запроса: нет подписок, модуль недоступен, feature not available

**Пошагово.**
1. «Лицензия» — тариф покрывает модуль? Срок не просрочен?
2. Модуль включён в «Настройки → Параметры клуба» (`GYM_ACCESS`, `VENDING_ENABLED`, AI и т.д.).
3. Просрочена — продление у выдающего; grace — функции частично работают.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Кто выдаёт лицензии и как продлить
Категория: desktop
Вариации запроса: где взять код лицензии, кто выдаёт, продление лицензии клуб

**Ответ.** Лицензии выдаёт платформа владельца продукта (FitIntel). Клуб получает код от владельца/партнёра. Продление = новый код → «🔑 Активировать…». Вопросы по лицензиям — в поддержку разработчика («Помощь → Поддержка разработчика (MAX)») или тому, кто продал продукт.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
