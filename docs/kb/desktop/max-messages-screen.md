# desktop: MAX сообщения (13 статей)

> Категория: desktop · Экран «MAX сообщения» (в 1.6.2 — хаб с 8 подвкладками: Чаты, Рассылка,
> Привязки, Напоминания, +Возврат клиентов, Отзывы, Новости, Журнал). Источник фактов: экран Чаты/Рассылка/Привязки/Напоминания/Журнал.

## Открыть чат и ответить клиенту
Категория: desktop
Вариации запроса: ответить в чате, написать клиенту в max, чат с клиентом, поле ввода чата

**Пошагово.**
1. «MAX сообщения → Чаты» → «Обновить» (перечитать список).
2. Слева список чатов (имя + начало последнего сообщения) — кликните нужный. Ожидание: история справа («[дата] Клиент/Вы: текст»).
3. Поле ввода внизу → текст → «Отправить» (или Enter).
4. Ожидание: баннер «Отправлено и ушёл в MAX» или «(MAX не настроен — сохранён локально)».
5. Не выбран чат → «Сначала выбери чат слева.»
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «🔄 Синхронизировать MAX» — подтянуть новые сообщения
Категория: desktop
Вариации запроса: синхронизировать max, новые сообщения не приходят, подтянуть чаты

**Пошагово.**
1. «Чаты» → «🔄 Синхронизировать MAX». Ожидание: «Синхронизация: новых N».
2. MAX не настроен → предупреждение «задайте bot_token…» (настройка: «Уведомления → Клиенту → Каналы»).
3. Регулярно: сообщения подтягиваются по webhook автоматически; кнопка — принудительно.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Рассылка: отправить сообщение группе
Категория: desktop
Вариации запроса: рассылка max, отправить всем клиентам, массовая рассылка из desktop

**Пошагово.**
1. «MAX сообщения → Рассылка».
2. «Кому:» — Клиенты / Тренеры / Все / Конкретный клиент (тогда активен список «Клиент:»).
3. «Тип:» — Акция / Напоминание / Инфо.
4. Текст (пусто → «Введи текст сообщения.»).
5. «📣 Отправить». Ожидание: «Рассылка: в очереди N, sent=X, failed=Y» (уходит только по привязкам MAX).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Привязка MAX user_id к клиенту
Категория: desktop
Вариации запроса: привязать max id, user_id клиента, привязки max, как привязать

**Пошагово.**
1. «Привязки». Пояснение на экране: бот может писать первым только тем, кто запустил его в MAX.
2. «Клиент:» (список) + поле «MAX user_id» + роль (client/trainer).
3. «Привязать». Ожидание: «Привязка сохранена.» — строка в таблице (Клиент | MAX user_id | Роль | Дата).
4. Где взять user_id: клиент пишет боту /start → id виден в журнале/webhook-логе (IT).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Отправлено и ушёл в MAX» vs «сохранён локально»
Категория: desktop
Вариации запроса: локально сохранено, не ушло в max, баннер отправки

**Ответ.** «Отправлено и ушёл в MAX» — доставлено через API MAX. «(MAX не настроен — сохранён локально)» — бот не подключён (нет токена/webhook); сообщение сохранилось в журнале и будет отправлено после настройки кнопкой «Отправить ожидающие».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
