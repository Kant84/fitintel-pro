# desktop: Коммерция, Экспорт, Интеграции (11 статей)

> Категория: desktop · Экраны «Коммерция» (каталог/остатки/продажи) и «Экспорт» (фильтры, CSV/XML)
> и «Интеграции» (1С Fitness, A&A). Магазин в 1.6.2 — отдельная вкладка sidebar.

## Каталог товаров (Коммерция)
Категория: desktop
Вариации запроса: каталог товаров, магазин товары, коммерция каталог

**Пошагово.**
1. «Коммерция → Каталог». Ожидание: таблица товаров с ценами и остатками.
2. «＋ Добавить товар» → название, категория, цена, себестоимость, штрих-код → «Сохранить».
3. Правка — двойной клик; деактивация — галочка «Активен».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Остатки и инвентаризация
Категория: desktop
Вариации запроса: остатки, инвентаризация, пересчёт склада, списание

**Пошагово.**
1. «Коммерция → Остатки» → фильтр по складу/категории.
2. «Инвентаризация» → введите фактические числа → расхождения спишутся документом.
3. Ожидание: акт инвентаризации в «Бухгалтерия → Документы».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Продажа товара с кассы
Категория: desktop
Вариации запроса: продать товар, касса магазина, продажа из коммерции

**Пошагово.**
1. «Коммерция → Продажи → ＋ Новая продажа» → выберите товары, количество.
2. «К оплате» → способ оплаты → платёж в «Платежи» (категория «Товар»).
3. Подтвердите платёж — чек + списание остатка. Ожидание: статус «Завершён».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

Категория: desktop
Вариации запроса: экспорт csv xml, выгрузка данных, фильтры экспорта

## Интеграция 1С Fitness (CommerceML/API)
Категория: desktop
Вариации запроса: 1с fitness, обмен с 1с, commerceml, интеграция 1с

**Пошагово.**
1. «Интеграции → 🔄 1С Fitness».
2. Заполните: адрес 1С (http://IP:port/…), логин/пароль, режим обмена (CommerceML 2.05 / API V3).
3. «Проверить связь» → «Сохранить».
4. Обмен: «Выгрузить номенклатуру/контрагентов/документы» или расписание автообмена.
5. Ожидание: журнал обмена с результатами (успех/ошибки по объектам).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Интеграция A&A (clients_import/export, пустое окно)
Категория: desktop
Вариации запроса: a&a интеграция, пустое окно a&a, а и а

**Ответ.** «Интеграции → 🔗 A&A» — окно с кнопками «📥 Импорт CSV» / «📤 Экспорт» / «📝 Журнал» (на начальном этапе без действий — почти пустое). Назначение: перенос клиентских баз (A&A = внешний формат учёта). Формат CSV: `ФИО;Телефон;Email;Дата рождения;Пол;Категория;Статус;Фото(URL)` (clients-screen.md «Импорт»).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Вкладка «Банки» (1.6.2): 5 банков
Категория: desktop
Вариации запроса: вкладка банки, т-банк юкасса сбер альфа райф, настройка банка экран

**Ответ.** «Банки» — настройка эквайринга: карточки Т-Банк, ЮKassa, Сбер, Альфа, Райффайзен. ## Экспорт из таблиц на любых экранах
Категория: desktop
Вариации запроса: экспорт таблицы, кнопка экспорт на экране, выгрузить список

**Ответ.** У большинства таблиц — кнопка экспорта (CSV/XLSX) и «🖨 Печать»/«📄 В PDF» внизу экрана. Формат CSV — UTF-8 с BOM (Excel открывает кириллицу корректно). PDF — сохранение текущей таблицы в файл.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
