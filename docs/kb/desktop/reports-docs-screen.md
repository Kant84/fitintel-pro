# desktop: Отчёты и Документы (11 статей)

> Категория: desktop · Экран «Отчёты»: список из 10 отчётов, период, «Сформировать», «⇩ Экспорт CSV».
> Экран «Документы»: шаблоны с подстановками {client}/{tariff}/{days}, генерация, подпись, PDF.

## Десять отчётов: что каждый показывает
Категория: desktop
Вариации запроса: список отчётов, какие отчёты есть, отчёт посещаемости где

**Ответ.** «Отчёт:» — список: Операционный свод · Посещаемость по дням · Загруженность по часам · Давно не посещали (30 дн.) · Окончание абонементов (14 дн.) · Продажи и оплаты · Зарплата тренеров · P&L · ОСВ · График работы персонала.
**Особенности.** «Давно не посещали» и «Окончание абонементов» игнорируют даты (пороги 30/14 дней); P&L и ОСВ берут месяц из поля «по».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Сформировать отчёт за период
Категория: desktop
Вариации запроса: сформировать отчёт, построить за период, даты с по отчёт

**Пошагово.**
1. «Отчёты» → выберите отчёт из списка.
2. «С:» / «по:» — календарики (по умолчанию последний месяц).
3. «Сформировать». Ожидание: таблица результата; статус сверху.
4. Пусто → «Нет данных за период (или источник недоступен)».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Экспорт отчёта в CSV
Категория: desktop
Вариации запроса: экспорт отчёта csv, сохранить отчёт, выгрузка таблицы

**Пошагово.**
1. Сформируйте отчёт → «⇩ Экспорт CSV».
2. Ожидание: файл сохранён, «Сохранено: путь» (UTF-8 с BOM для Excel).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Давно не посещали (30 дн.)» — игнорирует даты
Категория: desktop
Вариации запроса: отчёт не посещали даты не работают, 30 дней отчёт, порог отчёта

**Ответ.** Отчёт берёт клиентов без визитов 30+ дней независимо от полей «С/по» — это зашитый порог. Для своего порога используйте AI-центр («Список риска» — 14 дней) или выгрузку с фильтрами.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Окончание абонементов (14 дн.)» — список продлений
Категория: desktop
Вариации запроса: кто скоро заканчивает, окончание абонементов отчёт, список на продление

**Ответ.** Клиенты, у которых абонемент заканчивается в ближайшие 14 дней (даты «С/по» игнорируются). Используйте для обзвона/рассылки: выгрузите CSV → «Клиенту → Рассылки» или звонки по списку.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Создать шаблон документа с подстановками
Категория: desktop
Вариации запроса: создать шаблон, шаблон договора, подстановки в документ, переменные

**Пошагово.**
1. «Документы» → «📝 Создать шаблон». Ожидание: форма.
2. Название; Тип — contract/act/agreement/scan/receipt/other.
3. Текст с подстановками: {client}, {tariff}, {days}; также работают {{client_name}}, {{date}}…
4. «💾 Сохранить шаблон». Ожидание: шаблон в таблице, доступен в «Сгенерировать».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Сгенерировать документ клиенту
Категория: desktop
Вариации запроса: сгенерировать документ, договор для клиента, акт создать

**Пошагово.**
1. «Документы» → «Сгенерировать». Ожидание: форма.
2. Шаблон — список; Клиент — список.
3. «OK». Ожидание: документ создан с подстановкой данных; строка в таблице «Документы».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Подписать документ и сохранить в PDF
Категория: desktop
Вариации запроса: подписать документ, pdf документ, сохранить договор в pdf

**Пошагово.**
1. Выделите документ → «✍ Подписать» → простая подпись → статус «(подписан)» зелёным.
2. Выделите → «📥 PDF» → «Сохранить в PDF» → выберите папку → файл готов.
3. Переключение таблиц: «📄 Шаблоны / 📋 Документы».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Зарплата тренеров (отчёт)
Категория: desktop
Вариации запроса: зарплата тренеров отчёт, отчёт по тренерам, расчёт в отчётах

**Ответ.** Отчёт «Зарплата тренеров» в списке — свод по тренерам за период (ставки/комиссии/начисления). Детальный расчёт и выплаты — в «Бухгалтерия → К зарплате» (подвкладка Зарплата в 1.6.2). В 1.6.2 добавлен хаб «К зарплате»: штатное расписание → параметры сотрудника → начисления → «Выплачено» с проводками.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Нет данных за период» в отчёте
Категория: desktop
Вариации запроса: пустой отчёт, нет данных за период, отчёт не строится

**Пошагово.**
1. Расширьте период («С/по»).
2. Проверьте, что данные есть (визиты/платежи в соответствующих экранах).
3. Учтите особенности: «Давно не посещали»/«Окончание» игнорируют даты; P&L/ОСВ берут месяц из «по».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Печать таблицы и «В PDF» (на экранах с таблицами)
Категория: desktop
Вариации запроса: печать таблицы, в pdf кнопка, распечатать список

**Пошагово.**
1. Внизу экрана с таблицей: «🖨 Печать» → предпросмотр → выберите принтер → «Печать». Пустая таблица → «На этом экране нет данных для печати».
2. «📄 В PDF» → диалог «Сохранить в PDF» → выберите папку → файл «<Название>.pdf», «Сохранено: путь».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
