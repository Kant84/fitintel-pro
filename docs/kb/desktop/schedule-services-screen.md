# desktop: Расписание и Услуги (14 статей)

> Категория: desktop · Экран «Расписание»: таблица записей (Дата|Время|Клиент|Услуга|Тренер|Статус),
> кнопки «＋ Добавить запись»/«Отменить запись»/«Обновить». Экран «Услуги»: справочник с категориями и тренерами.

## Добавить запись (окно «Новая запись»)
Категория: desktop
Вариации запроса: добавить запись, новая запись, записать клиента на услугу, форма записи

**Пошагово.**
1. «Расписание» → «＋ Добавить запись». Ожидание: окно «Новая запись».
2. Клиент — список; Услуга — список активных услуг.
3. Дата и время — виджет с календариком (по умолчанию «через час»), формат ГГГГ-ММ-ДД ЧЧ:ММ.
4. «Записать». Ожидание: запись в таблице.
5. Слот занят/вместимость исчерпана → «Запись не создана: <причина>».

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Отменить запись
Категория: desktop
Вариации запроса: отменить запись, отмена записи, удалить запись из расписания

**Пошагово.**
1. Выделите строку → «Отменить запись» → «Отменить запись: ФИО — дата?» → Да.
2. Ожидание: «Запись отменена», статус красным.
3. Не выделено → «Выберите строку в таблице».
4. Позже чем за 24 часа сервер может отказать — текст в «Не удалось отменить: …».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Статусы записей в таблице (цвета)
Категория: desktop
Вариации запроса: статусы расписания, зелёный красный статус, активная отменённая запись

**Ответ.** Активные записи — зелёным, отменённые — красным. Клиентские отмены из мини-приложения тоже попадают сюда со статусом. Список обновляется по «Обновить»/F5.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Добавить услугу (окно «Новая услуга»)
Категория: desktop
Вариации запроса: добавить услугу, новая услуга, создать занятие, форма услуги

**Пошагово.**
1. «Услуги» → «＋ Добавить услугу». Ожидание: окно.
2. Название* (пусто → «Введите название»); Категория — список: Сауна, Солярий, Бассейн, Массаж, Аэробика, Танцы, Перс. тренировка.
3. Цена ₽ — 1–1 000 000 (по умолчанию 500; ≤0 → «Цена должна быть больше 0»).
4. Длительность, мин — 1–600 (по умолчанию 60); Вместимость — 1–200 (по умолчанию 1).
5. Тренер — «— без тренера —» или профили тренеров.
6. «Активна» — галочка; «Сохранить»/«Отмена». Ошибки сервера — текстом («Не сохранено: код — причина»).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Назначить/сменить тренера у услуги
Категория: desktop
Вариации запроса: назначить тренера, сменить тренера, кнопка назначить тренера

**Пошагово.**
1. «Услуги» → выделите услугу → «✎ Назначить тренера».
2. В форме смените поле «Тренер» (и любые другие) → «Сохранить».
3. Ожидание: в таблице обновлён тренер.
4. Не выделено → «Выберите услугу в таблице».
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Удалить услугу
Категория: desktop
Вариации запроса: удалить услугу, убрать из справочника, кнопка удалить услуги

**Пошагово.**
1. Выделите услугу → «🗑 Удалить» → подтверждение.
2. Ожидание: услуга удалена.
3. С активными записями сервер откажет — сначала отмените/перенесите записи или деактивируйте услугу (галочка «Активна»).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Новый тренер (окно «Новый тренер»)
Категория: desktop
Вариации запроса: новый тренер, добавить тренера, создать профиль тренера

**Пошагово.**
1. «Услуги» → «👤 Новый тренер». Ожидание: окно.
2. Пользователь — список пользователей БЕЗ профиля тренера. Пусто → «Все пользователи уже имеют профили тренеров. Сначала создайте пользователя во вкладке "Пользователи"».
3. Специализация — текст («например: Бодибилдинг»); Ставка ₽/час (по умолчанию 1000); Комиссия % (0–100, по умолчанию 10); Макс. клиентов/день (1–50, по умолчанию 8).
4. «Создать». Ожидание: профиль создан, тренер доступен в услугах/расписании.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Не сохранено: код — причина» при услуге
Категория: desktop
Вариации запроса: ошибка сохранения услуги, не сохраняется услуга, красный текст ошибки

**Пошагово.**
1. Прочтите код и причину в сообщении (422 — валидация, 403 — права, 500 — сервер).
2. 422: проверьте диапазоны (цена >0, длительность 1–600, вместимость 1–200, комиссия 0–100).
3. 403: нужна роль с правом редактирования услуг (admin/manager).
4. 500: повторите; стабильно — логи api в момент сохранения.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Категории услуг: список и назначение
Категория: desktop
Вариации запроса: категории услуг, какие категории, список категорий

**Ответ.** Список категорий в форме услуги: Сауна, Солярий, Бассейн, Массаж, Аэробика, Танцы, Перс. тренировка. Категория группирует услуги в справочнике и отчётах; свои категории в текущей версии не создаются (выбирайте из списка).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Вместимость занятия и «слот занят»
Категория: desktop
Вариации запроса: вместимость, сколько человек на занятие, слот занят ошибка

**Ответ.** «Вместимость» — максимум одновременных записей. При исчерпании новая запись отклоняется: «Запись не создана: …». Увеличьте вместимость («✎ Назначить тренера» → правка) или создайте параллельное занятие.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Длительность услуги и шаг слотов
Категория: desktop
Вариации запроса: длительность услуги, шаг расписания, slot minutes

**Ответ.** «Длительность, мин» (1–600) определяет длину занятия. Шаг сетки онлайн-записи — параметр клуба `SLOT_MINUTES` (на nfs = 45 мин). Изменение длительности не двигает уже созданные записи.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Тренер не появляется в списке услуг
Категория: desktop
Вариации запроса: нет тренера в списке, тренер не доступен, пустой список тренеров

**Пошагово.**
1. Профиль тренера создан? («Услуги → 👤 Новый тренер» — если «Все пользователи уже имеют профили», значит создан).
2. Пользователь активен (не деактивирован): «Пользователи».
3. «Обновить» на экране Услуг.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Записать клиента на конкретное время
Категория: desktop
Вариации запроса: запись на время, на 18:00 записать, точное время записи

**Пошагово.**

3. «Записать». Ожидание: строка в таблице с вашим временем.
4. Пересечение с другой записью клиента → отказ с причиной.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Онлайн-записи клиентов: где видно
Категория: desktop
Вариации запроса: онлайн запись видно, клиент записался сам, пометка онлайн

**Ответ.** Записи из мини-приложения MAX появляются в той же таблице «Расписание» (источник виден в деталях/журнале). Уведомление сотрудникам — при настроенном MAX-боте клуба. Клиент отменяет сам до 24 ч («CANCEL_WINDOW» = 24 ч на nfs).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
