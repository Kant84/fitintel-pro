# desktop: Главная / Аналитика (12 статей)

> Категория: desktop · Экран «Главная» = «Аналитика»: 4 подвкладки (перетаскиваются мышкой).
> Источник фактов: DESKTOP_GUIDE (экран Обзор/Прогноз/Тепловая карта/AI Отток) + API analytics.

## Главная: 6 плиток KPI — что означает каждая
Категория: desktop
Вариации запроса: плитки главной, что значат цифры, kpi показатели, обзор главная

**Ответ.** Подвкладка «📊 Обзор», карточки (только чтение):
1. «Посещений сегодня» — визиты за сегодня.
2. «Выручка сегодня, ₽» — подтверждённые платежи за сегодня.
3. «Прогноз недели, ₽» — сумма дневных прогнозов на 7 дней.
4. «Клиентов в риске» — активный абонемент + нет визитов 14+ дней.
5. «К прошлой неделе, %» — динамика выручки со стрелкой ▲/▼.
6. Строка «Сегменты риска: Низкий N | Средний N | Высокий N» — распределение по модели оттока.
**Пошагово.** Нажмите «🔄 Обновить» для перечитывания цифр. Ожидание: карточки пересчитаны.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «🧮 Пересчитать историю (56 дн)» — когда нажимать
Категория: desktop
Вариации запроса: пересчитать историю, 56 дней, статистика пустая, после импорта данных

**Пошагово.**
1. После первой установки сервера или импорта базы: «Главная → Обзор».
2. Нажмите «🧮 Пересчитать историю (56 дн)». Ожидание: сбор статистики до минуты, затем карточки обновятся.
3. Повторять каждый день не нужно — метрики дня считаются автоматически при обращении к экрану.
4. Прогноз/тепловая карта всё ещё «Мало данных» → см. analytics-ai.md «Мало данных».

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Прогноз: построить график выручки/посещаемости
Категория: desktop
Вариации запроса: построить прогноз, график прогноза, метрика прогноз дней

**Пошагово.**
1. «Главная → 📈 Прогноз».
2. «Метрика:» — Посещаемость / Выручка / Новые клиенты / Риск оттока.
3. «Дней:» — счётчик 1–90 (по умолчанию 7).
4. «📈 Построить прогноз». Ожидание: голубая линия = факт, розовый пунктир = прогноз, зелёная вертикаль = «сегодня».
5. Мало истории (<14 дней) — текст «Прогноз: …» вместо графика.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Тепловая карта: посмотреть загрузку по часам
Категория: desktop
Вариации запроса: тепловая карта где, загрузка по часам, когда пик, heatmap на главной

**Пошагово.**
1. «Главная → 🔥 Тепловая карта».
2. «🔄 Загрузить тепловую карту». Ожидание: сетка Пн–Вс × 24 часа; яркость ячейки = число визитов.
3. Пусто и «Нет данных» — визитов в базе нет; карта строится из всей истории сразу (фильтра по периоду нет).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## AI Отток: обучить модель и обновить список риска
Категория: desktop
Вариации запроса: обучить модель, ai отток, список риска, обновить риск

**Пошагово.**
1. «Главная → 🤖 AI Отток».
2. «🎓 Обучить / дообучить». Ожидание: «Обучено! Примеров: N, точность: X». Мало данных → «Мало данных для обучения».
3. «📋 Обновить список риска». Ожидание: таблица Клиент ID | Вероятность оттока | Дней без визитов | Визитов за 30 дн.
4. Строка статуса: «Модель: обучена/не обучена | примеров: N | точность: X»; внизу график «Рост точности модели».
5. «✅ Сверить прогнозы с фактом» — контроль качества: «Сверено: N, проверенная точность: X».

**Типичные ошибки.** Ждать список риска без обучения — кнопка «Обновить список» берёт последнюю обученную модель.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Посещений сегодня» = 0, а клиенты ходят
Категория: desktop
Вариации запроса: нули на главной, посещений 0, цифры не меняются, главная пустая

**Пошагово.**
1. «🔄 Обновить» на Обзоре. Ожидание: цифры пересчитаны с сервера.
2. «🧮 Пересчитать историю (56 дн)» — если сервер/БД недавно развёрнуты или восстановлены из бэкапа.
3. Проверьте, что визиты реально создаются: «Входы/Выходы» — таблица пополняется при проходах?
4. Нет визитов вообще — проблема на входах (турникет/desktop), см. visits-access.md «Турникет не пускает».
5. IT: метрики дня пересчитываются при обращении к дашборду; ручной пересчёт — `POST /api/v1/analytics/recalc?days=N`.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «Клиентов в риске» — что с этим делать
Категория: desktop
Вариации запроса: что делать с риском оттока, клиенты в риске действия, работа со списком риска

**Пошагово.**
1. «AI Отток → 📋 Обновить список риска».
2. Откройте карточку клиента из списка (через «Клиенты» по ID/телефону).
3. Действия: сообщение в MAX («MAX сообщения → Чаты»), звонок, предложение заморозки/продления, бонус.
4. Массово: «Уведомления → Клиенту → Автонапоминания» (3/14 дней без визита) — те же клиенты.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Разница «К прошлой неделе, %» считается как
Категория: desktop
Вариации запроса: стрелка вверх вниз, процент к прошлой неделе, динамика выручки

**Ответ.** Плитка сравнивает выручку текущих 7 дней с предыдущими 7 днями: ▲ — рост, ▼ — падение. Это оперативный индикатор, не бухгалтерский отчёт (там — «Бухгалтерия → Отчёты → P&L»).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Подвкладка «Прогноз» не строится: «Прогноз: …»
Категория: desktop
Вариации запроса: прогноз не строится, сообщение вместо графика, forecast ошибка

**Пошагово.**
1. Прочтите текст после «Прогноз:» — обычно «Мало данных: нужно ≥14 дней истории».
2. «🧮 Пересчитать историю (56 дн)» → подождите минуту → «📈 Построить прогноз» заново.
3. Клуб моложе 2 недель — прогноз появится сам по мере накопления данных.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

Категория: desktop

## График «Рост точности модели» пустой
Категория: desktop
Вариации запроса: график точности пуст, обучений не видно, история обучения

**Ответ.** График заполняется после обучений («🎓 Обучить / дообучить»). До первого обучения — пусто, это норма. Каждое дообучение добавляет точку; точность растёт с количеством примеров.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
