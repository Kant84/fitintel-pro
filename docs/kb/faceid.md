# faceid — распознавание лиц

> Категория: faceid · Проверено для: 1.6.2 · Для кого: администратор, ресепшен.

## Как работает Face ID в клубе
Ключевые слова: face id, распознавание лиц, биометрия, как работает
**Ответ.** Собственный движок (self-hosted, без облачных сервисов): фото с камеры → сравнение с математическими шаблонами (ResNet-34, эмбеддинг 128) → решение турникета. Возможны режимы: регистрация через desktop, верификация на турникете (`/face-id/turnstile`), анти-спуфинг (защита от фото на экране). Порог уверенности стандарт 0.60 (ИНСТРУКЦИЯ §21, §30.3, ADMIN_GUIDE §3).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Регистрация лица: пошагово
Ключевые слова: зарегистрировать лицо, снять с камеры, добавить лицо
**Ответ.** «Face ID» → найдите клиента (мин. 2 символа) → «📷 Снять с камеры» → «📸 Снять» (или «📂 Загрузить файл» jpg/png/bmp) → проверьте «✓ Проверить меня» → «✅ Шаблон зарегистрирован». Требования к фото: лицо в центре, глаза открыты, однотонный фон, без посторонних, мин. 640×480 (ИНСТРУКЦИЯ §21.3, §21.5).
📷 [SCR-face-01: окно камеры с кнопкой «Снять»]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Ошибки при регистрации лица
Ключевые слова: лицо не обнаружено, низкое качество фото, несколько лиц, лимит шаблонов
**Ответ.** «Лицо не обнаружено» — повторите снимок, поправьте свет и угол. «Низкое качество фото» — увеличьте резкость/освещение (фильтр качества, стандарт 40). «Обнаружено несколько лиц» — уберите посторонних из кадра. «Лимит шаблонов» — удалите старые («🗑 Удалить шаблон») или увеличьте лимит в «Настройки движка…» (стандарт 5, max 20) (ИНСТРУКЦИЯ §21.8).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Настройки движка Face ID
Ключевые слова: настройки движка, порог уверенности, threshold, качество фото, хранение фото
**Ответ.** «Face ID → Настройки движка…» — 4 параметра: 1) Порог уверенности 0.1–1.5 (меньше = строже; стандарт 0.60); 2) Мин. качество фото ≥1 (стандарт 40); 3) Лимит шаблонов 1–20 (стандарт 5); 4) Хранение фото: «Нет» (по умолчанию — только векторы, 152-ФЗ) / «Да, хранить» (в volume face_photos, chmod 600) (ИНСТРУКЦИЯ §21.4, ADMIN_GUIDE §3).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Face ID не распознаёт на турникете
Ключевые слова: не узнаёт, отказ face id, порог сходства
**Ответ.** 1) Проверьте освещение у турникета (плохой свет — главная причина). 2) Качество фото при регистрации — перерегистрируйте при дневном свете. 3) Порог уверенности слишком строгий — уменьшите (например 0.60 → 0.55) в «Настройки движка…». 4) Камера: разрешение, угол, фокус. До настройки — впускайте вручную (ИНСТРУКЦИЯ §30.3, §40).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Согласие на биометрию (152-ФЗ)
Ключевые слова: согласие, биометрия 152, персональные данные, отзыв согласия
**Ответ.** Биометрия — особая категория ПДн: без активного согласия клиента регистрация шаблона запрещена (API вернёт 403 biometric_consent_required). Согласие фиксируется в карточке («Согласия»). Отзыв согласия мгновенно удаляет все шаблоны и фото. Шаблоны — необратимые векторы, восстановить фото из них нельзя (ИНСТРУКЦИЯ §21.7, ROADMAP 21.10).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Камера не найдена
Ключевые слова: камера не найдена, webcam, usb камера
**Ответ.** «Камера не найдена. Проверьте подключение…» — проверьте USB (прямо в порт, без хабов), не занята ли камера другим приложением (Zoom/браузер), драйверы. «Движок Face ID» на экране покажет статус (ИНСТРУКЦИЯ §21.8, §25.7).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Удаление шаблона
Ключевые слова: удалить лицо, удалить шаблон, сбросить face id
**Ответ.** «Face ID → Обновить список» → выделите шаблон → «🗑 Удалить шаблон» — безвозвратно. Для повторной регистрации — заново снимите фото (ИНСТРУКЦИЯ §21.4).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».
