# users-rbac: рабочие дни 12 ролей (13 статей)

> Категория: users-rbac · Кто что делает в течение дня/месяца по каждой роли.

## Рабочий день роли «Администратор»
Категория: users-rbac
Вариации запроса: день администратора, обязанности админа, что делает администратор клуба

**Регламент дня.**
1. Утро: открыть смену («Платежи → 🔓»), проверить health/обновления, журнал отказов турникета.
2. В течение дня: пользователи/роли/экраны, тарифы/услуги, кассовые конфликты, поддержка ресепшена (впуски/блоки).
3. Вечер: сверка снятия кассы, аудит дня (необычные действия), бэкап — по регламенту IT.
4. Периодика: обучение AI, отчёты директору, обновления ПО (с IT).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Рабочий день роли «Кассир»
Категория: users-rbac
Вариации запроса: день кассира, обязанности кассира, как работать на кассе

**Регламент дня.**
1. Начало смены: «🔓 Открыть смену» от своего имени, проверить остаток.
2. Приём платежей: «＋ Провести платёж» → правильный способ → «✓ Подтвердить» (чек!).
3. Возвраты — только с причиной; отмены — «Ожидает».
4. Конец смены: подтвердить все «Ожидает», X-отчёт, «🔒 Закрыть смену» со сверкой наличных; передать смену.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Рабочий день роли «Ресепшен»

Вариации запроса: обязанности ресепшена, стойка администратора, как работать на ресепшене

**Регламент дня.**
1. Встреча: поиск клиента, впуск («🟢 Впустить»), выпуск, шкафчики, браслеты (привязка/перевыпуск).

4. Конец смены: «Сейчас в зале» сверить, незакрытые визиты — «Завершить».

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Рабочий день роли «HR/Кадры»
Категория: users-rbac
Вариации запроса: обязанности кадровика, сотрудники документы, приём увольнение

**Регламент дня.**
1. Приём: карточка сотрудника (пользователь → роль → график → ставка), документы (трудовой договор — в «Документы», AES-256-GCM).
2. Увольнение: деактивация, снятие ролей/экранов, блокировка QR/браслета, сохранение документов.
3. Зарплата: штатное расписание, графики, данные для «К зарплате».
4. Согласия: ПДн/биометрия сотрудников (кадровое оформление).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Рабочий день роли «Платформенная поддержка»
Категория: users-rbac
Вариации запроса: обязанности поддержки, помощь клубам, чинить конфиг

**Регламент дня.**
1. Обращения: чат бота поддержки (по ТЗ), эскалации по регламенту ответа.

3. Конфигурация: помочь с env/параметрами клуба (без доступа к деньгам).
4. Релизы: уведомления клубов об обновлениях, контроль версий.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Смена роли сотруднику при переводе
Категория: users-rbac
Вариации запроса: перевод сотрудника, смена должности, новые права

**Пошагово (admin).**
1. Карточка сотрудника → «Роль и права» → отметьте новую роль → «Сохранить» (права применяются мгновенно).
2. «Экраны ролей» — проверьте видимость экранов новой роли.
3. Индивидуальные права старой роли не переносятся — переоформите, если нужно.
4. Уведомите сотрудника; действие — в аудите.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
