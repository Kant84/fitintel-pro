# music-dj — музыкальный пульт и DJ-агент

> Категория: music-dj · Проверено для: 1.6.2 · Для кого: администратор, менеджер, тренер (по правам).

## Как запустить музыку в зале (первый раз)
Ключевые слова: запустить плеер, музыка не играет, плеер включить, агент
**Ответ.** «Музыка/DJ → ⏵ Плеер: ВКЛ» → дождитесь «Плеер на этом ПК: РАБОТАЕТ». Затем «▶ Фон (плейлист)» → выберите плейлист. Агент (3 процесса mpv: Deck A, Deck B, PAD) стартует автоматически. Требования: mpv в комплекте сборки, папка с музыкой задана (МУЗЫКА_ИНСТРУКЦИЯ ШАГ 5–7, ИНСТРУКЦИЯ §9).
📷 [SCR-music-01: пульт «Музыка/DJ» со статусом playing]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Музыка не играет — диагностика
Ключевые слова: тишина, нет звука, mpv не стартует, 403 в логе агента
**Ответ.** По логу агента (`E:\music\logs\agent_gui.log` или окно консоли): 1) агент запущен? 2) `mpv.exe` на месте (`_internal/mpv/`)? 3) громкость Windows/выход звуковухи? 4) «Мастер» на пульте не 0? 5) `bad token` в логе → зону пересоздавали, токен устарел — агент перерегистрируется сам по machine_id. 6) `lib=—` → `client_settings.json` не рядом с exe (МУЗЫКА_ИНСТРУКЦИЯ «Проблемы», TROUBLESHOOTING §17.3).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как поставить трек на дек (A/B)
Ключевые слова: загрузить трек, трек на дек, выбрать песню
**Ответ.** Справа «Плейлисты»: выберите плейлист → трек → «→ A» / «→ B» (без эфира) или «▶ A» / «▶ B» (сразу в эфир). Двойной клик по треку — на активный дек + эфир. Можно «📁 Файл на A/B…» (любой файл с диска) или «📂 Папка на A/B…» (треки по кругу) (ИНСТРУКЦИЯ §9.2–9.3).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как свести два трека (переход)
Ключевые слова: сведение, эфир a, эфир b, кроссфейд, плавный переход
**Ответ.** 1) Трек на оба дека. 2) «Кроссфейд, сек» — длительность перехода 0–30. 3) «Эфир → B» (или A): играющий дек плавно в тишину, новый поднимается. Индикатор «ЭФИР» показывает активный дек, мастер и кроссфейд. Агент сам подмешивает следующий трек к концу (авто-микс) (ИНСТРУКЦИЯ §9.2).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Эквалайзер (бас/середина/верха)
Ключевые слова: эквалайзер, eq, бас, настройка звука
**Ответ.** Три полосы (−12…+12 дБ) отдельно для каждого дека: Бас ~80 Гц, Середина ~1.2 кГц, Верха ~6.5 кГц. «Применить EQ» — меняется на лету, музыка не прерывается. Рецепты: вечерний пик — Бас +4…+6; гулкий зал — Бас −4, Середина −2 (ИНСТРУКЦИЯ §9.4).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Пады (джинглы поверх музыки)
Ключевые слова: пады, сэмплы, джингл, сирена, объявление
**Ответ.** Сэмплер 1–8: «＋ Добавить сэмпл» → имя + путь к файлу (например `sfx/siren.mp3`) + громкость. Клик по паду — one-shot поверх музыки (отдельный канал). Защита от дублей: повторное нажатие через <2 сек игнорируется. Серые пады — не назначены (ИНСТРУКЦИЯ §9.5, §33).

**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Объявление тренера: дакинг микрофона
Ключевые слова: микрофон, объявление в зал, дакинг, голос поверх музыки
**Ответ.** Включите «🎤 Микрофон: ВКЛ» и говорите — агент автоматически приглушит музыку до ~20% и вернёт через 2 секунды тишины. Если не срабатывает: перезапустите плеер (ВЫКЛ → ВКЛ) (ИНСТРУКЦИЯ §31).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Energize (пиковый режим)
Ключевые слова: energize, энерджи, вечерний пик
**Ответ.** Кнопка «⚡ Energize» — энергичный плейлист + громкость 90. Может срабатывать автоматически по потоку входов через турникеты (порог настраивает администратор) (ИНСТРУКЦИЯ §9.1, МУЗЫКА_ИНСТРУКЦИЯ).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Аварийная тишина (MUTE ALL)
Ключевые слова: mute all, экстренная тишина, чп, выключить музыку сразу
**Ответ.** Красная кнопка «MUTE ALL» — мастер → 0 мгновенно. Возврат: ползунок мастера обратно + «Применить пульт» (ИНСТРУКЦИЯ §32).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Лицензия музыки (баннер внизу пульта)
Ключевые слова: лицензия музыки, рао, воис, договор, баннер жёлтый
**Ответ.** Учёт договора на коммерческий фон (РАО/ВОИС или провайдер): 🟢 действует — можно; 🟡 не указана — играет, но договор обязателен для коммерческого зала; 🔴 истекла — фон ЗАБЛОКИРОВАН (play/Energize вернут ошибку 402). Указание договора — у администратора (МУЗЫКА_ИНСТРУКЦИЯ «Лицензия»).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Плеер не выключается (mpv остаются)
Ключевые слова: плеер выкл не убивает, mpv остался, taskkill
**Ответ.** Обновите desktop (сборка 26.10+ убивает дерево процессов `taskkill /T`). Вручную: `Get-Process mpv | Stop-Process -Force` (TROUBLESHOOTING §17.3, ROADMAP F5).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».
