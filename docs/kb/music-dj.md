# music-dj — музыкальный пульт, DJ-агент (12 статей)

> Категория: music-dj · Проверено для: 1.6.2 по экрану «Музыка/DJ» (desktop) и app/api/v1/music.py.
> Движок воспроизведения — mpv; пульт управляет локальным/серверным плеером по API.

## Запуск плеера (начало работы зала)
Категория: music-dj
Вариации запроса: запустить плеер, как включить музыку, музыка не играет, старт mpv

**Пошагово.**
1. Вкладка «Музыка/DJ» → «▶ Старт» (кнопка запуска плеера).
   Ожидание: статус «Играет», время трека пошло, на индикаторе дек — уровень сигнала.
2. Плеер стартует на том ПК/сервере, где запущен агент (DJ-агент); убедитесь, что он запущен (служба/скрипт клуба).
3. Громкость — общий фейдер и по каналам (A/B).

**Типичные ошибки.** Кнопка старта молчит — DJ-агент не запущен или недоступен по API (см. «mpv не умирает»/диагностику).
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Загрузка треков на деки (A/B)
Категория: music-dj
Вариации запроса: загрузить трек, поставить на деку, треки на плейлист, как добавить музыку

**Пошагово.**
1. «Музыка/DJ» → библиотека/список треков → выберите трек → «→ A» или «→ B» (на деку).
   Ожидание: трек появился на выбранной деке с обложкой/длительностью.
2. Загрузка файлов: кнопка «➕ Добавить» в библиотеке → выбор MP3/FLAC с диска.
3. Требования: mp3/flac, без DRM; кириллица в именах поддерживается.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Сведение (crossfade) между деками
Категория: music-dj
Вариации запроса: сведение, crossfade, плавный переход, как плавно переключить трек

**Пошагово.**
1. Обе деки загружены, играет дека A.
2. «Музыка/DJ» → «CROSSFADE» → выберите время перехода (например 4–8 сек).
3. Нажмите «B» (переход на B) — трек B стартует с начала перехода.
   Ожидание: плавное затухание A и нарастание B без паузы.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Эквалайзер (EQ) на каналах
Категория: music-dj
Вариации запроса: эквалайзер, eq, бассы высокие, настроить звук

**Пошагово.**
1. «Музыка/DJ» → блок EQ (по полосам: bass/mid/high для каналов).
2. Двигайте ползунки: + усиление, − ослабление. Ожидание: звук меняется в реальном времени.
3. «Сброс» — вернуть все полосы в 0.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Пады (звуковые кнопки)
Категория: music-dj
Вариации запроса: пады, звуковые эффекты, джинглы, кнопки сэмплов

**Пошагово.**
1. «Музыка/DJ» → панель падов (4–8 кнопок).
2. Назначение: удерживайте/клик по пустому паду → выберите файл (джингл/аплодисменты).
3. Клик по паду — мгновенное воспроизведение поверх музыки. Ожидание: сэмпл играет, не прерывая деки.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Дакинг микрофона (музыка тише при объявлении)
Категория: music-dj
Вариации запроса: дакинг, микрофон глушит музыку, автогейн, объявления

**Пошагово.**
1. Подключите микрофон к ПК с агентом; включите его вход в системе.
2. «Музыка/DJ» → «Дакинг» → порог (dB) и глубина приглушения.
3. Запишите порог тестом: говорите в микрофон — музыка приглушается на заданную глубину, после тишины возвращается.
   Ожидание: плавное приглушение/восстановление.

**Типичные ошибки.** Порог слишком низкий — музыка «плывёт» от шума зала; слишком высокий — не срабатывает.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Energize (автоподдержание энергетики)
Категория: music-dj
Вариации запроса: energize, энергетика треков, bpm подбор

**Ответ.** Режим автоподбора: пульт держит заданную энергетику сета (по анализу треков/ручным тегам), подставляя следующие треки из библиотеки.
**Пошагово.**
1. Включите «ENERGIZE» → задайте целевой уровень.
2. Запустите автоплей/следующий трек. Ожидание: подбор идёт в рамках энергетики.
3. Ручной перебор всегда доступен — Energize не блокирует деки.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## MUTE ALL (экстренное отключение звука)
Категория: music-dj
Вариации запроса: mute all, выключить музыку сразу, экстренная тишина

**Пошагово.**
1. «Музыка/DJ» → кнопка «MUTE ALL».
   Ожидание: звук обеих дек и падов обнуляется мгновенно (без остановки треков).
2. Повторное нажатие — вернуть громкость.

**Где применяется.** Эвакуация, объявление через свою систему, авария. Состояние MUTE видно на экране красной индикацией.
**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Лицензии РАО/ВОИС для фоновой музыки
Категория: music-dj
Вариации запроса: рао, воис, лицензия на музыку, публичное исполнение

**Ответ.** Публичное исполнение фонограмм в коммерческом зале требует договоров с РАО и ВОИС — это обязанность клуба, ПО её не оформляет. FitIntel лишь воспроизводит ваши легально купленные треки.
**Пошагово.**
1. Оформите договоры на сайтах rao.ru / vois.ru (по площади зала и формату).
2. Храните платёжки/договоры — проверяющие запрашивают.
3. DJ-пульт к лицензированию отношения не имеет.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## «mpv не умирает» / плеер не останавливается
Категория: music-dj
Вариации запроса: mpv не умирает, плеер не гаснет, завис mpv, процесс висит

**Пошагово (IT клуба).**
1. Пульт шлёт команду стоп, но процесс mpv на агенте завис — громкость может остаться.
2. На ПК агента: `tasklist | findstr mpv` (Windows) / `pgrep mpv` (Linux).
3. Завершите процесс вручную → перезапустите плеер с пульта («▶ Старт»).
4. Повторяется — обновите mpv до актуальной сборки и проверьте права агента на завершение процессов.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Диагностика тишины (чек-лист)
Категория: music-dj
Вариации запроса: нет звука, тишина в зале, музыка играет а звука нет

**Пошагово (по порядку).**
1. Громкость фейдера A/B и общая — не на нуле? MUTE ALL не горит красным?
2. Трек реально играет? (время трека идёт, уровень на индикаторе).
3. Windows-громкость на ПК агента + правильное устройство вывода (колонки, не «по умолчанию»).
4. Кабель/усилитель зала включены.
5. Пульт «видит» агента? Перезапуск агента + «▶ Старт» заново.
   Ожидание: на каждом шаге звук появляется — фиксируйте, на каком шаге.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Пульты с нескольких ПК к одному агенту
Категория: music-dj
Вариации запроса: несколько пультов, управление с разных компьютеров, dj агент доступ

**Ответ.** Агент один (на ПК со звуком), пультов может быть несколько: каждый desktop настраивается на тот же сервер; команды идут через API к агенту. Одновременные команды выполняются последовательно — договоритесь, кто ведёт сет.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
