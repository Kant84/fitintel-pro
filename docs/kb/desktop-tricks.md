# desktop: приёмы работы (8 статей)

> Категория: desktop · Горячие клавиши, быстрые сценарии, доступность, скорость.

## Горячие клавиши по экранам
Категория: desktop
Вариации запроса: горячие клавиши список, клавиши по экранам, hotkeys где

**Основные (все экраны).** F5 — обновить данные; F11 — табло; Esc — закрыть диалог/табло; Enter — подтвердить в диалоге.
**Клиенты.** Ctrl+N — новый клиент.
**Правка.** Ctrl+Z — отмена последнего действия (меню «Правка»).
**Окна.** Tab/Shift+Tab — переход по полям; пробел/Enter — кнопка в фокусе.
**Совет.** Клавиши ускоряют работу ресепшена: поиск → Enter → стрелки → Enter на строке.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## F5 vs автообновление: когда что работает
Категория: desktop
Вариации запроса: f5 когда, автообновление экранов, данные не свежие

**Механика.** Списки грузятся при открытии экрана; F5 — принудительный перезапрос. Проходы турникета приходят по SSE (индикатор прохода — без F5; задержка до пары секунд норма). После действий коллег (новый клиент, платёж) — F5, если запись не появилась.
**Не приходит по SSE** — проверьте сеть (прокси рвёт SSE) и статус сервера.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Работа без мыши: быстрые сценарии
Категория: desktop
Вариации запроса: быстро работать без мыши, скорость на ресепшене, клавиатурные сценарии

**Сценарии.**
1. Впуск клиента: «Входы/Выходы → 🟢» → печать ФИО → стрелки → Enter → Enter (OK).
2. Поиск клиента: «Клиенты» → поле поиска → печать → Enter → стрелки → Enter (карточка).
3. Продажа: карточка → «Пакеты/Услуги → ＋» → Tab по полям → Enter.
4. Обновление: F5 везде.
Обучение новых сотрудников — этими цепочками (шпаргалка роли).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Вкладки и подвкладки: навигация с клавиатуры
Категория: desktop
Вариации запроса: переключение вкладок клавиатурой, навигация по подвкладкам

**Ответ.** Переключение основных вкладок sidebar — мышью (фокус на список вкладок → стрелки вверх/вниз → Enter, если фокус установлен). Подвкладки хабов (Главная/Бухгалтерия/Настройки) — клик мышью; порядок подвкладок перетаскивается мышью. Ctrl+Tab между подвкладками не поддерживается в текущей версии.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Масштаб интерфейса для слабовидящих
Категория: desktop
Вариации запроса: масштаб для слабовидящих, крупный шрифт, доступность

**Пошагово.**
1. «Настройки → Интерфейс» → Масштаб (ползунок) + Шрифт (крупный).
2. Тема «Контрастная» — максимальная читаемость.
3. Windows: масштаб дисплея 125–150% (Параметры → Дисплей) — дополнительно увеличит.
4. Табло (F11) — шрифт крупный по умолчанию (ФИО залу).
Проверьте читаемость с рабочего места целевого сотрудника.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Одновременная работа нескольких операторов
Категория: desktop
Вариации запроса: несколько операторов одновременно, работа вдвоём на разных пк

**Механика.** Несколько desktop одновременно — штатно: данные общие (сервер — источник истины). Конфликты редки (сервер валидирует: 409 при двойном входе, идемпотентность подтверждений). Правила:
1. Один кассир — одна смена: смена открывается на конкретного кассира.
2. Одна карточка клиента — правит один сотрудник за раз (иначе перезапись; аудит покажет).
3. Рассылку шлёт один ответственный (дубли проверяйте журналом).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Печать этикеток и ценников
Категория: desktop
Вариации запроса: печать этикеток, ценники товаров, этикетка товара

**Ответ.** Встроенной печати этикеток в текущей версии нет: печатайте из Excel (выгрузка каталога CSV → Word/Excel шаблоны этикеток) или из 1С (при интеграции). Для ценников — тот же путь: экспорт → печать. Требования к принтеру этикеток (термо, 203 dpi) — по вашему оборудованию.

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».

## Скорость загрузки списков: фильтры вместо скролла
Категория: desktop
Вариации запроса: список грузится долго, медленный список клиентов, фильтр вместо скролла

**Причина.** Длинные списки (тысячи клиентов) грузятся/листаются медленно.
**Правила.**
1. Ищите фильтром/поиском, не листайте (поиск по телефону быстрее всего).
2. Отчёты больших периодов — экспортом CSV, не экраном.
3. Не держите открытыми десятки окон/вкладок — память desktop растёт.
4. Старый ПК — уменьшите масштаб/тему, закройте лишнее (RAM).

**Если не помогло:** Ескалация: «Помощь → Поддержка разработчика (MAX)».
