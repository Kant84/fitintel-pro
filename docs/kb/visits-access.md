# visits-access — входы/выходы, турникет, браслеты, шкафчики

> Категория: visits-access · Проверено для: 1.6.2 · Для кого: ресепшен, кассир, администратор.

## Как впустить клиента вручную
Ключевые слова: впустить, ручной вход, пропустить клиента
**Ответ.** «Входы/Выходы → 🟢 Впустить» → выберите клиента → способ (Ручной/Карта/QR/Face ID) → зона (по умолчанию main) → OK. Сервер проверит: нет активного визита, есть активный абонемент, лимит визитов, время тарифа. Ошибки показываются текстом (ИНСТРУКЦИЯ §11.3, §30.4).
📷 [SCR-visits-01: форма «Впустить клиента»]
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как выпустить клиента
Ключевые слова: выпустить, завершить визит, выход
**Ответ.** Выделите строку со статусом ACTIVE → «🔴 Выпустить» (закрывает визит + открывает турникет) или «✓ Завершить» (закрыть без турникета — если клиент ушёл мимо). Ошибки «визит уже закрыт»/«выделите строку» — см. журнал (ИНСТРУКЦИЯ §11.4).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Турникет не пускает клиента — чек-лист
Ключевые слова: турникет отказ, не проходит, карта не работает
**Ответ.** По порядку: 1) Активный абонемент? («Абонементы»). 2) Лимит визитов не исчерпан? 3) Время тарифа подходит (дневной/ночной)? 4) Карта/браслет привязаны? («Браслеты/Карты → 📖 Прочитать карту»). 5) QR живой (5 минут, одноразовый). 6) Если всё ок, но железо молчит — IT клуба: контроллер СКУД → ITCService → сервер (SKUD_SETUP.md). Пока чинится — впустите вручную (ИНСТРУКЦИЯ §30).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как привязать браслет/карту клиенту (RFID)
Ключевые слова: привязать браслет, привязать карту, rfid, acr1252
**Ответ.** «Браслеты/Карты → Клиентская карта»: 1) найдите клиента; 2) «🔷 Очистить носитель» (поднесите карту к считывателю ACR1252/ACR122); 3) «💾 Привязать к клиенту» (поднесите снова) — UID запишется в «Носители клиента». Если карта чужая — сервер перепривяжет. Требование: считыватель в USB напрямую, без хабов (INSTRUCTION_RFID.md, ИНСТРУКЦИЯ §23.2).

**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Клиент потерял карту — перевыпуск
Ключевые слова: потерял карту, перевыпуск, сброс карты, новый браслет
**Ответ.** 1) Старый носитель: «Браслеты/Карты → 🗑 Сброс к заводским» (если карта найдена — уничтожьте данные). 2) Привяжите новый браслет/карту по инструкции привязки — старая запись заменится. История визитов сохраняется (ИНСТРУКЦИЯ §23.2, INSTRUCTION_RFID §1–2).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Считыватель не видит карту («Считыватель не найден»)
Ключевые слова: считыватель не найден, acr1252 не работает, usb
**Ответ.** 1) Проверьте USB: «🔍 Проверить считыватель» на экране «Браслеты/Карты». 2) Считыватель должен быть подключён напрямую в порт ПК (без хабов/удлинителей). 3) Драйвер PC/SC (Windows ставит автоматически для ACR1252). 4) Переподключите/перезагрузите ПК. Для программирования замков — ACR1252 обязателен (INSTRUCTION_RFID §6, ИНСТРУКЦИЯ §23.6).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## QR-код на вход: как работает
Ключевые слова: qr вход, динамический qr, пропуск qr
**Ответ.** Два вида: СТАТИЧЕСКИЙ QR — из «Браслеты/Карты» (выдаётся/перевыпускается); ДИНАМИЧЕСКИЙ QR — клиент в мини-приложении MAX «Мой QR», живёт 5 минут, одноразовый, выдаётся при активном абонементе или оплаченной брони в окне входа. Сканер турникета шлёт код на сервер → решение пускать/нет (ИНСТРУКЦИЯ §30.2, docs_MAX_bot_shop §4 п.5).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Face ID на турникете — как работает и требования
Ключевые слова: face id, распознавание лиц, камера вход
**Ответ.** Клиент встаёт перед камерой → фото → сервер сравнивает с шаблонами (порог уверенности настраивается, стандарт 0.60) → пуск/отказ. Требования к фото при регистрации: лицо в центре, освещение, без посторонних, мин. 640×480. Работает только при активном абонементе. Согласие на биометрию — обязательно (152-ФЗ) (ИНСТРУКЦИЯ §21, §30.3).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Как зарегистрировать лицо клиента
Ключевые слова: зарегистрировать лицо, добавить лицо, снять с камеры
**Ответ.** «Face ID» → найдите клиента (мин. 2 символа) → «📷 Снять с камеры» → «📸 Снять» (или «📂 Загрузить файл» jpg/png) → проверьте «✓ Проверить меня» → шаблон появится в списке. Ошибки: «лицо не обнаружено» (повторите, поправьте свет), «несколько лиц» (уберите посторонних), «лимит шаблонов» (удалите старые или увеличьте лимит в «Настройки движка…») (ИНСТРУКЦИЯ §21.3).

**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Шкафчики: выдача и аренда
Ключевые слова: шкафчик, аренда шкафчика, выдать шкафчик
**Ответ.** При входе шкафчик выдаётся автоматически (если настроен). Вручную: «Браслеты/Карты → 🅿 Аренда шкафчика» → выберите свободный → клиенту. При выходе шкафчик освобождается автоматически; турникет не выпускает при закрытом бесплатном шкафчике («Откройте шкафчик №N перед выходом!») — откройте и повторите выпуск (ИНСТРУКЦИЯ §11.4, §30.5).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Кто сейчас в клубе
Ключевые слова: кто в зале, активные визиты, сколько человек
**Ответ.** «Входы/Выходы» — строки со статусом ACTIVE (зелёные). Счётчики сверху: сегодня/неделя/месяц. API: `GET /visits/active` и `/visits/active/count` (ИНСТРУКЦИЯ §11.1, USER_GUIDE).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».

## Онлайн-замки Kerong (доска раздевалок)
Ключевые слова: онлайн замки, kerong, доска замков, аренда удалённо
**Ответ.** «Браслеты/Карты → ☁ Онлайн-замки»: доска замков по зонам, аренда/снятие из desktop; замок без аренды держит турникет (страж выхода); напоминания об освобождении. Контроллеры — через Kerong API (эмулятор/контроллеры), настройка замков — INSTRUCTION_RFID §3 (ИНСТРУКЦИЯ §23.3, ROADMAP F3).
**Если не помогло:** «Помощь → Поддержка разработчика (MAX)».
