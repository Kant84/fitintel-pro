# 👔 Шпаргалка: Администратор

## Доступные экраны
✅ 17 (все, кроме «Подключения»)

## Ключевые задачи
| Задача | Как сделать |
|--------|-------------|
| Добавить клиента | «Клиенты» → «＋ Добавить» |
| Продать абонемент | «Абонементы» → «＋ Продать абонемент» |
| Заморозить / разморозить | «Абонементы» → «❄ Заморозить» / «▶ Разморозить» |
| Провести платёж с чеком | «Платежи» → «＋ Провести платёж» → «✓ Подтвердить» (смена открыта!) |
| Возврат / отмена | «Платежи» → выделить → «↩ Возврат» / «✕ Отмена» |
| Открыть/закрыть смену | «Платежи» → «🔓 Открыть смену» / «🔒 Закрыть смену» |
| Привязать карту/браслет | «Браслеты/Карты» → найти клиента → «Привязать к клиенту» |
| Записать клиента на услугу | «Расписание» → «＋ Добавить запись» |
| Каналы уведомлений клиентам | «Клиенту» → MAX/Telegram webhook, события |
| Поддержка разработчика | «Помощь» → обращение уходит с логами и версиями |

## Важно
- 📊 «Главная»: красные строки в таблице оттока — позвонить клиенту
- 🚨 Ошибки: «Настройки → Логи»
