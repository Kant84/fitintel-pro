# FitIntel Pro — Технические характеристики, функционал и условия поставки

Версия документа: 1.6.1 · Дата: 30.10.2026 · Разработчик: FitIntel

---

## 1. Общие сведения

**FitIntel Pro** — комплексная система управления фитнес-клубом: клиентская база, абонементы, расписание и записи, контроль доступа (RFID/QR/Face ID), касса с фискализацией по 54-ФЗ, платежи и эквайринг, бухгалтерия, аналитика и AI-прогноз оттока, коммуникации с клиентами (мессенджеры), интеграции с 1С и оборудованием.

| Параметр | Значение |
|---|---|
| Архитектура | Клиент-серверная: сервер приложений + тонкий desktop-клиент + web-виджеты |
| Версия | 1.5.3 (релиз 02.10.2026), обновления через релизы с контрольными суммами |
| Поставка | Docker-образ сервера + установщик desktop (Inno Setup) + portable .exe |
| Количество рабочих мест | Не ограничено (регистрируются в системе) |
| Работа по сети | Локальная сеть клуба и/или интернет (VPN рекомендован для удалённого доступа) |

## 2. Технические характеристики

### 2.1 Серверная часть

| Компонент | Технология |
|---|---|
| Приложение | Python 3.11, FastAPI (OpenAPI/Swagger на `/docs`) |
| База данных | PostgreSQL 16 (основная), SQLite (внутренняя учётная система) |
| Кэш/очереди | Redis 7 (кэш allkeys-lru, брокер Celery) |
| Фоновые задачи | Celery worker (истечение абонементов, уведомления), APScheduler (аналитика 00:05) |
| Веб-шлюз | Nginx: прокси API, TLS 1.2/1.3, rate-limit (API 10 r/s, auth 5/мин) |
| Мониторинг | Prometheus + Grafana + Loki (логи) + Alertmanager + node-exporter + cAdvisor |
| Контейнеризация | Docker Compose (test/prod), образ `fitintel:prod` поставляется tar-архивом (`docker load -i`) |
| Аутентификация | JWT (access token), bcrypt; блокировка после 5 неудачных попыток на 5 минут |
| Авторизация | RBAC: 9 ролей, матрица прав, аудит действий (доступ/отказ), контроль видимости экранов по ролям |
| Лицензирование | Одноразовые ключи Ed25519 (`FIPRO-…`), привязка к серверу (machine-id), режимы soft/hard |
| 54-ФЗ | HTTP ДТО 10 (АТОЛ), Штрих-М Web JSON v2; адаптеры Эвотор/Меркурий (опция); ОФД через API оператора |
| Эквайринг | Тинькофф, Сбер (sbrf.dll/REST), Райффайзен (опция); ЮKassa/SБП онлайн |
| Интеграции | 1С:Фитнес клуб (HTTP API V3), CommerceML 2.0, CRM «ХИТ» (по спецификации B-Office), A&A (CSV/webhook) |
| Мессенджеры | MAX (бот, FSM-сценарии, чаты), Telegram; email (SMTP), SMS (smsc.ru), Web Push (VAPID) |
| AI | Модель оттока (scikit-learn, самообучение + сверка прогнозов), прогнозы выручки/посещаемости |
| Face ID | dlib/face_recognition (ResNet-34, эмбеддинг 128), настройки клуба (порог/качество/лимиты), анти-спуфинг и liveness (задел) |
| Безопасность данных | Шифрование паролей bcrypt, TLS, маскирование секретов в API, «право на забвение» (152-ФЗ, анонимизация) |
| Бэкап | pg_dump по расписанию (скрипты + API), ротация, проверка восстановления |

### 2.2 Тонкий клиент (desktop)

| Параметр | Значение |
|---|---|
| Платформа | Windows 10/11 x64 |
| Технология | PyQt6, onefile-сборка (PyInstaller), установщик Inno Setup |
| Вес | Установщик ≈107 МБ; portable-вариант один .exe |
| Подключение | HTTP/JSON к серверу по `http://<сервер>:8001/api/v1`; авто-перелогин при истечении токена |
| Профили подключения | Несколько «информационных баз» (как в 1С), выбор при входе |
| Оборудование на рабочем месте | Веб-камера (Face ID), USB-считыватель RFID (PC/SC, например ACR1252) — опционально |
| Темы | Светлая/тёмная, масштаб шрифта (Ctrl±), табло с часами (F11) |
| Печать | Предпросмотр → принтер, экспорт любой таблицы в PDF/CSV |

### 2.3 Производительность и ёмкость

| Параметр | Значение |
|---|---|
| Расчётная ёмкость | Клуб до 3 000 клиентов на сервер (ограничение тарифа лицензии, не техническое) |
| Одновременные пользователи | До 50 без деградации на рекомендованном железе |
| Пропускная способность СКУД | Проверка доступа < 300 мс (кэш прав доступа TTL 24 ч, офлайн-режим терминалов) |
| Фискальный чек | Пробой ≤ 3 с (зависит от ККТ) |
| Ограничения файлов | Вложения чатов до 10 МБ |

## 3. Полный функционал (по модулям)

1. **CRM:** клиенты (карточки, категории, поиск, деактивация), история клиента (timeline), анонимизация по 152-ФЗ.
2. **Абонементы:** тарифы (лимиты/безлимит, дневные/ночные окна), продажа, продление, заморозка (сдвиг срока), отмена, авто-истечение (Celery), история статусов.
3. **Расписание и услуги:** каталог услуг с тренерами, записи (вместимость, отмена за 24 ч), посещаемость тренеров, зарплата (прогрессивная ставка, KPI, бонусы/штрафы).
4. **Доступ в клуб (СКУД):** RFID-карты/браслеты (программирование Mifare, Kerong-замки, онлайн-замки TTLock/KERONG Cloud), статические и динамические QR (HMAC, TTL, привязка к устройству), Face ID (регистрация по камере, турникетный режим, анти-спуфинг), SKUD-интеграция (ITC checkaccess), anti-passback, графики доступа устройств, авто-освобождение шкафчиков.
5. **Касса (54-ФЗ):** кассовые смены (открытие/закрытие с отчётом нал/безнал раздельно), авто-фискализация при подтверждении платежа, чеки продажи/возврата, корректировки, X/Z-отчёты, «Снятие кассы» (инкассация, роли), настройка ККТ через UI, контроль «смена закрыта» на сервере.
6. **Платежи:** нал/карта/СБП/перевод/онлайн/баланс, статусы (Ожидает/Завершён/Возвращён), возвраты полные/частичные, кошелёк клиента (заморозка средств), ЮKassa (webhook с подписью и идемпотентностью, автосписания), рекуррентные платажи (ретраи), продажи/комплексные чеки.
7. **Бухгалтерия:** автопроводки (Дт 50/57 Кт 90.1, сторно), ПКО/РКО, ОСВ, P&L, баланс, CommerceML 2.0, реготчётность (6-НДФЛ, РСВ, УСН с XML-экспортом и календарём).
8. **Отчёты:** операционный свод, посещаемость по дням/часам, «давно не было», «истекают абонементы», продажи, зарплата тренеров, график персонала, P&L/ОСВ; экспорт CSV/PDF/XLSX.
9. **AI и аналитика:** дашборд (KPI, прогнозы, сравнение недель), тепловая карта, обучаемая модель оттока (список риска, сверка прогнозов), рекомендации цен (self-learning), авто-задачи.
10. **Коммуникации:** MAX (чаты, рассылки, привязки, автонапоминания об истечении/пропавших), Telegram-бот, email/SMS/webpush с журналом и дайджестом.
11. **Маркетинг:** сегменты базы, SMS/email-кампании (ROI, A/B-заготовка), реферальная программа, геймификация (XP, уровни, достижения, награды).
12. **Документы:** шаблоны с переменными, генерация PDF/DOCX, подписание (в т.ч. ЭП-эмуляция), массовая генерация по списку клиентов.
13. **Онлайн-запись:** публичный виджет записи (настройка, слоты, бронирование) для сайта клуба.
14. **Оборудование (DAL):** репозиторий драйверов .fnp, автообнаружение, ping/команды/журнал; реестр фитнес-оборудования (гарантии, ТО, Modbus/HTTP/MQTT).
15. **Администрирование:** пользователи и роли, матрица прав, экраны по ролям (строгая модель), аудит «История» с сроком хранения, feature flags (процентные раскатки, привязка к лицензии), мастер установки (7 шагов), white-label, мультитенантность (сети клубов).
16. **Мониторинг и надёжность:** /health, /metrics, дашборды Grafana, алерты (API down, ошибки 5xx, диск, память), бэкапы, авто-закрытие «зависших» визитов, автообновление токена клиента.

## 4. Лицензионные условия

| Условие | Описание |
|---|---|
| Формат ключа | Одноразовый ключ `FIPRO-<…>` (подпись Ed25519), генерируется в License Studio |
| Привязка | К серверу установки (machine-id). **Перенос на другой сервер = новый ключ** (выпускается бесплатно при сбое/замене сервера по заявке) |
| Тарифы | TRIAL (14 дней) / PRO / ENTERPRISE — отличаются лимитами и модулями |
| Лимиты тарифа | Максимум клиентов, устройств, тенантов (сетей) — указываются в ключе |
| Режим превышения | soft — предупреждение; hard — блокировка создания новых клиентов |
| Подписка | Обновления версий и поддержка (MAX) — в течение срока лицензии; продление — новым ключом |
| Активация | Самостоятельная при первом запуске (окно активации) или через экран «Лицензия» |
| Количество рабочих мест | Не ограничивается лицензией (ограничивается ролями и правами) |
| Оборудование | ПО не привязано к железу; ККТ, ридеры, турникеты приобретаются клубом отдельно |

## 5. Требования к установке

### 5.1 Сервер клуба

| Требование | Минимум | Рекомендовано |
|---|---|---|
| CPU | 2 vCPU | 4 vCPU |
| RAM | 4 ГБ | 8 ГБ |
| Диск | 40 ГБ SSD | 80 ГБ SSD (с учётом бэкапов и логов) |
| ОС | Ubuntu Server 20.04/22.04 LTS | Ubuntu 22.04 LTS; альтернатива: Windows Server 2019/2022 + Docker Desktop (WSL2) |
| ПО | Docker Engine 24+ и Compose plugin | то же + fail2ban, NTP |
| Сеть | Статический IP в ЛВС клуба; 100 Мбит/с | Gigabit; резервный канал для онлайн-оплат |
| Домен/TLS | Не обязательно для ЛВС | Домен + сертификат Let's Encrypt для доступа из интернета |
| Установка | 5 команд (`install.sh` из комплекта: генерирует `.env` с секретами, поднимает PostgreSQL/API/Nginx) | + мониторинг-стек (`deploy/monitoring`), cron-бэкап |

### 5.2 Рабочие места (desktop)

| Требование | Значение |
|---|---|
| ОС | Windows 10/11 x64 (64-разрядная) |
| RAM/диск | 4 ГБ RAM, 500 МБ свободно |
| Разрешение | от 1280×800 |
| Сеть | Доступ до сервера по TCP 8001 (или 80/443 через Nginx) |
| Периферия (опционально) | Веб-камера (Face ID); USB-считыватель RFID PC/SC (ACS ACR1252U и аналоги); принтер (чеки/отчёты) |
| Установка | Setup.exe (per-user, без администратора) или portable .exe |

### 5.3 Периферия клуба (приобретается отдельно)

| Оборудование | Требования |
|---|---|
| ККТ | АТОЛ с ДТО 10 (порт 16732, USB/TCP) или Штрих-М (Web JSON v2); регистрация ФН и договор с ОФД — ответственность клуба |
| Турникеты/СКУД | Контроллеры с вызовом HTTP `/skud/checkaccess` (ITC и аналоги); кабельная сеть до точек |
| Замки шкафчиков | Kerong KR-S80/ITC-30 (offline, Mifare) или онлайн (TTLock / KERONG Cloud / Sciener) |
| Камеры | ONVIF/IP-камеры для видеоаналитики (модуль — по дорожной карте) |

### 5.4 Сетевые порты (для IT-специалиста клуба)

| Порт | Назначение |
|---|---|
| 80/443 | Nginx → API (TLS) |
| 8001 | API напрямую (ЛВС) |
| 5432, 6379 | PostgreSQL/Redis — только внутри Docker-сети |
| 16732 | АТОЛ ДТО (в ЛВС клуба) |
| 9090 / 3000 / 3100 | Prometheus / Grafana / Loki (мониторинг, закрыть от интернета) |

### 5.5 Сторонние договоры (оформляются клубом)

Онлайн-эквайринг ЮKassa или банк (Сбер/Тинькофф) · договор с ОФД · SMS (smsc.ru) · почтовый ящик для рассылок · 1С:Фитнес клуб (если нужен обмен) · доступ к CRM «ХИТ» (если используется). Интеграции в ПО готовы; ключи вносятся в настройках.

## 6. Комплект поставки

1. Архив сервера `fitintel-pro_v1.5.3.zip` (код, compose.prod, скрипты install/backup/update, документация) или готовый образ `fitintel-prod_v1.5.3.tar.gz` (`docker load -i`).
2. `FitIntelDesktop-Setup_v1.5.3.exe` — установщик клиента; portable `FitIntelDesktop.exe`.
3. Документация: INSTALL_CLUB.md (5 команд установки), ADMIN_GUIDE, USER_GUIDE, FISCAL_GUIDE, API_OVERVIEW, TROUBLESHOOTING, RELEASES.md (с SHA256).
4. Лицензионный ключ FIPRO (по договору).

## 7. Поддержка и гарантии

- Поддержка: чат MAX с разработчиком (кнопка «Помощь» в клиенте), диагностика по логам одной кнопкой.
- Обновления: релизы с контрольными суммами; обновление — `git pull` + пересборка контейнера (или новый tar) и новый Setup поверх.
- Восстановление: бэкапы БД штатными скриптами; SLA восстановления — в пределах доступности последнего бэкапа.
- Ограничения: ПО не является бухгалтерской/кассовой программой в части регистрации ККТ в ФНС (выполняется через кассовое ПО ККТ); реготчётность (6-НДФЛ/РСВ/УСН) — в упрощённом виде из данных учёта.
