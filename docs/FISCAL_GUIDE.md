# Кассовый и финансовый модуль

## Карта подсистем (что за что отвечает)

| Подсистема | Путь | Назначение |
|---|---|---|
| Кассовые смены E33 | `/fiscal/*` | Состояние смены на сервере, балансы нал/безнал, остаток, инкассация, авто-фискализация при подтверждении |
| Смены кассира (legacy) | `/cash-desk/*` | Классические смены кассира: opening_balance, Z-отчёт, сверка (одна открытая смена на всех) |
| Кассовый аппарат | `services/fiscal/universal_fiscal.py` + `/fiscal/atol|shtrih` | Адаптеры АТОЛ/Штрих/Эвотор/Меркурий, ДТО 10 |
| Чеки | `/receipts/*` | Номер чека, QR, ОФД-статус (заглушка), отправка email/SMS, PDF |
| Платежи | `/payments/*` | PENDING→COMPLETE (чек!)→проводка; возвраты; online/webhook |
| Кошелёк | `/wallet/*` | Баланс, frozen, пополнение/списание/заморозка, история |
| Эквайринг | `services/bank/` | Терминалы: Сбер/Тинькофф/Райф; pay/cancel/settlement/preauth |
| Онлайн | `/yookassa/*`, `/recurring/*` | ЮKassa + автоплатежи с ретраями |
| Проводки | `accounting_entries` + «Бухгалтерия» | Дт/Кт журнал, ОСВ, P&L; внутренняя SQLite-учётка — аналог 1С без 1С |
| Реготчётность | `/reporting/*` | 6-НДФЛ, РСВ, УСН, календарь |

## Смены E33 (основной сценарий)

1. «⚙ Настройки кассы» (admin): драйвер, адрес `http://IP:16732` (АТОЛ ДТО 10), логин/пароль, ОФД.
2. «🔓 Открыть смену» — строка в `fiscal_shift`, история сохраняется.
3. Продажа: «＋ Провести платёж» → «✓ Подтвердить» → **чек автоматически** (guard смены → `sell`). При закрытой смене — 400, платёж «Ожидает».
4. «🔒 Закрыть смену» — отчёт: обороты закрываемой смены (нал/безнал раздельно) + накопленный «остаток прошлых смен» (переходит в `fiscal_pending`).
5. «💵 Снятие кассы» — обнуление остатка (admin/superadmin/accountant/бухгалтер; иначе 403).

Баланс считается по подтверждённым платежам с `completed_at >= opened_at`; нал = CASH, безнал = остальные способы; приход минус расход.

## Проводки (авто)

| Операция | Дт | Кт |
|---|---|---|
| Оплата наличными | 50 | 90.1 |
| Оплата безнал (карта/СБП/онлайн) | 57 | 90.1 |
| Расход (выдача) | 91.2 | 50/57 |
| Возврат | 90.1 | 50/57 (сторно) |

Таблица `accounting_entries` (source='payment' у авто). Внутренняя учётка (SQLite `fitintel_accounting.db`) дублирует механику для клубов без 1С: ПКО/РКО/реализация/поступление, ОСВ, оборотка, P&L, баланс (актив=пассив), ДДС, акт сверки.

## Переход на боевую ККТ

1. Настройки кассы → адрес боевой АТОЛ; 2. тестовый чек 1 ₽; 3. закрытие смены; 4. ФНС/ОФД — вне системы. Mock (`:18004`) можно остановить — мешать не будет.

## Онлайн-оплаты

- **ЮKassa**: env-ключи; webhook с HMAC-подписью и идемпотентностью; succeeded → платёж + ФН + кошелёк + абонемент; возвраты с контролем сумм; автосписание за продление.
- **Рекурренты**: графики day/week/month; при сбое — ретрай через 2^attempt часов; после max_retries — failed.
- **Сбер/Тинькофф терминалы**: через BankManager (см. ADMIN_GUIDE §3).

## Реготчётность

6-НДФЛ (13%), РСВ (22+5.1+2.9%) по `payroll_records` за квартал, XML-экспорт; УСН 6%/15% из оборотов учётки; календарь сроков. Данные начислений вводятся через `/reporting/payroll/records`.

## Ошибки

| Ошибка | Причина | Действие |
|---|---|---|
| 400 «Смена закрыта…» | чек при закрытой смене | «🔓 Открыть смену» |
| 400 «Платёж уже подтверждён…» | повтор | уже учтено |
| 403 «Снятие кассы…» | роль | admin/бухгалтер |
| 502 «Касса вернула ошибку: N» / «Касса недоступна» | отказ ККТ / dto_url | логи ККТ; проверка адреса, ping |
| 429 (Telegram/MAX) | rate limit 30/сек | пауза |
| 401 webhook | неверная подпись | WEBHOOK_SECRET |
| «Мало данных для обучения» (AI) | <14 дней истории | «Пересчитать историю» |

## Безопасность

`/fiscal/test/drivers` — только admin; пароль ДТО — в БД (ограничьте доступ); пустой `dto_url` = эмуляция чеков (не для боя).
