# Руководство пользователя FitIntel Pro

F1 на любом экране — его инструкция. Видимые экраны зависят от роли (строгая модель: не отмечено = не видно).

## Роли (ui_config) и типовые экраны

| Роль | Экраны по умолчанию |
|---|---|
| reception (ресепшен) | Главная, Клиенты, Входы/Выходы, Абонементы, Платежи, Face ID |
| cashier (кассир) | Главная, Клиенты, Абонементы, Платежи, Входы/Выходы |
| accountant (бухгалтер) | Главная, Платежи, Отчёты, Документы, Аналитика |
| trainer (тренер) | Главная, Расписание, Входы/Выходы, Клиенты |
| manager | + Отчёты, Документы |
| admin / superadmin | всё (+ Пользователи, Роли, ui_config у superadmin) |
| owner | Главная, Аналитика, Отчёты, Платежи |

## Кассир/ресепшен

**Продажа абонемента:** «Клиенты» → клиент → «Абонементы» → «＋ Продать» (тариф, дата) → оплата в «Платежи».
**Оплата с чеком:** «🔓 Открыть смену» → «＋ Провести платёж» → «✓ Подтвердить» (чек пробивается автоматически; при закрытой смене платёж останется «Ожидает» с ошибкой «Смена закрыта»). Баланс: нал и безнал раздельно; в чеке — ФИО/номер.
**Возврат/отмена:** «↩ Возврат» (причина обязательна, можно частично); «✕ Отмена» = полный возврат. Сторно уходит в проводки автоматически.
**Закрытие дня:** «🔒 Закрыть смену» → сверка нал/безнал → бухгалтер: «💵 Снятие кассы».
**Вход клиента:** по карте/браслету (RFID), QR (в т.ч. динамический с телефона), Face ID на турникете; ручной вход — «Входы/Выходы → Ручной вход». Система проверяет активный абонемент, лимит визитов и время (дневной/ночной тариф).
**Шкафчик:** выдача при входе; при выходе шкафчик освобождается автоматически; турникет не выпустит, если закрыт бесплатный шкафчик («Откройте шкафчик №N перед выходом!»).
**Запись на услугу:** «Расписание → ＋ Добавить запись» (клиент, услуга, дата/время). Отмена клиентом — только за 24 часа; проверка вместимости и дубля записи.
**QR клиенту:** «Браслеты/Карты» → привязка RFID/браслета; QR выдаётся/перевыпускается из credentials; динамический QR — из личного кабинета (TTL 5 мин, одноразовый).

## Тренер

«Расписание» — мои тренировки на сегодня; отметка посещения (attended/missed); продажи из зала; KPI за месяц: сессии × ставка (прогрессивно +5/15/30/50% от объёма) + комиссия % от продаж + бонусы (новые клиенты 500 ₽, удержание ≥80% → 5000 ₽, продажи ≥100 тыс. → 10 000 ₽) − штрафы (прогул 1000 ₽).

## Бухгалтер

«Бухгалтерия»: проводки (авто от платежей: Дт 50/57 Кт 90.1), ПКО/РКО, ОСВ, P&L, баланс. «Отчёты»: операционный, загрузка по часам, график персонала, зарплата тренеров; реготчётность: 6-НДФЛ, РСВ, УСН (XML-экспорт, календарь сроков). «Экспорт»: xlsx/csv/json по сущностям, задачи с JWT-ссылкой (24 ч), «право на забвение» (анонимизация клиента, 152-ФЗ).

## Менеджер/маркетинг

«MAX сообщения»: чаты (WebSocket), рассылки, привязки, автонапоминания (истечение абонемента, «пропавшие» клиенты, день рождения). «Маркетинг»: сегменты, SMS/email-рассылки, кампании (ROI, A/B). «Рефералка»: код REF-XXXXXXXX, двусторонние бонусы (500/300 ₽ по умолчанию), выплаты. «Геймификация»: XP, уровни, достижения, лидерборд, награды.

## AI

«Аналитика → Пересчитать историю (56 дн)» → «AI Центр → Обучить» → «Список риска оттока» (кому звонить). «Сверить прогнозы» — через 14+ дней повышает точность. При малых данных — сообщение «Мало данных для обучения» (нужно ≥14 дней истории).

## Клиент (self-service)

Личный кабинет: баланс/кошелёк, транзакции, мой динамический QR, онлайн-тренировки (каталог, live, записи, оценки), бронирования. Боты MAX/Telegram: /start /balance /visits /help (после привязки аккаунта).

## Кнопки «Платежи» — шпаргалка

| Кнопка | Действие |
|---|---|
| ＋ Провести платёж | запись «Ожидает» (предупреждение, если смена закрыта) |
| ✓ Подтвердить | чек → «Завершён» → баланс + проводка |
| ↩ Возврат / ✕ Отмена | возврат (частичный/полный), сторно-проводка |
| ⇩ Экспорт CSV | выгрузка платежей клиента |
| 🔓 / 🔒 / 💵 / ⚙ / Обновить статус | смена: открыть / закрыть (отчёт) / снятие кассы / настройки АТОЛ (admin) / опрос |

Подвкладки независимы: на «Проводках» кнопки платежей неактивны.
