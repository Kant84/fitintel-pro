## 2. Каталог ошибок (текст → причина → действие)

| # | Сообщение (как на экране) | Где | Причина → действие |
|---|---|---|---|
| 1 | «Токен истёк» (красный баннер) | любой экран | JWT access истёк (30 мин) → desktop сам перелогинивается по refresh; если баннер висит — «Выход» и войти заново; при повторе проверить saved_login |
| 2 | «Ошибка 401 Client Error…» | Отчёты/Документы | то же: токен умер между запросами → F5; не помогло — перелогин |
| 3 | «Ошибка загрузки: 401 Client Error…» | Документы | список документов запрошен с просроченным токеном → «Обновить» после перелогина |
| 4 | «Ошибка создания: 422 … /api/v1/clients/» | Клиенты | валидация: нет обязательного поля/неверный формат (email/телефон/дата) → заполнить поля со * корректно |
| 5 | «Ошибка входа: 409 … /visits/manual» | Входы/Выходы | у клиента уже есть активный визит → «Выпустить»/«Завершить» старый, затем впустить |
| 6 | «Касса недоступна: No connection adapters were found for 'IP:18004/requests'» | Платежи | до mock/ККТ не достучаться (сервис лежит/адрес неверен) → проверить адрес в «Настройки кассы», ping, запустить mock |
| 7 | «Касса вернула ошибку: 1» | Платежи | ККТ/mock в ошибочном состоянии → журнал ККТ, перезапуск mock'а; повторить «Подтвердить» |
| 8 | «Платёж уже подтверждён или недоступен» | Платежи | повторное «Подтвердить» по завершённому → ничего не делать, платёж учтён |
| 9 | «Неверный логин или пароль. Осталось попыток: N» | Вход | неверные креды; при N=0 — блокировка 5 мин (423) |
| 10 | «Expecting value: line 1 column 1 (char 0)» | Музыка (и др.) | ответ сервера не JSON (просроченный токен → HTML-страница, или 5xx) → F5/перелогин; если после обновления — логи api |
| 11 | «Ошибка создания: 400 … /roles/assign» | Пользователи | невалидная роль/дубль → выбрать роль из списка формы создания; роль назначается там же, а не отдельно |
| 12 | «500 … /payroll/calc?period=…» | Зарплата | сервер упал на расчёте → логи api (`docker compose logs api`), повторить; устойчивый 500 = баг → поддержка с логами |
| 13 | «urlopen error [WinError 10061] …» | Лицензия | сервер не отвечает (порт/адрес/сервер лёг) → проверить `curl http://IP/api/v1/health/`, доступность с ПК |
| 14 | «Ошибка: нет подписок» | Уведомления→Отправка | у получателя нет webpush-подписок → сначала подписка со страницы `/api/v1/notify/webpush/page` |
| 15 | «Push failed: 403 Forbidden {"reason":"BadJwtToken"}» | Уведомления→Журнал | VAPID sub нереальный домен → «Web Push»: sub = mailto:почта@реальный-домен |
| 16 | «Ошибка сервера (код 500)» (баннер) | Платежи/Face ID | общий сбой API → «Обновить», не помогло — логи + поддержка |
| 17 | «Ошибка сохранения: api-клиент без put/post» | Уведомления→Клиенту | старая версия вкладки/клиента (дефект сборки 1.6.1) → обновить desktop; в 1.6.2 не воспроизводится |
| 18 | «Внимание: Выберите базу для подключения» | Подключения | «Подключить» без выбора строки → выделить профиль, затем «Подключить» |
| 19 | «Профиль 'X' активирован. Перезапустите клиент.» | Подключения | норма: профиль применён → перезапуск desktop |
| 20 | «Готово: … выпущен, визит закрыт» | Входы/Выходы | информационный диалог успеха |
