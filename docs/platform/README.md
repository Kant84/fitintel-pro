# FitIntel Platform — документация (оглавление)

Навигация по документам платформы (папка `docs/platform/`). Дата сборки: 25.10.2026.

## Документы

| # | Документ | Что внутри (кратко) |
|---|---|---|
| 1 | **PLATFORM_USER_GUIDE.md** | Полная инструкция пользователя: жизненный цикл администраторов платформы (добавить/отозвать, p12 на Windows/iOS/Android, передача по ссылке), доступ к серверу клуба через **CLUB_ADMIN_KEY** (вход, веб-консоль, ротация ключа), описание всех экранов панели (Дашборд/Клубы/Лицензии/Аудит/Настройки), добавление нового клуба, типовые проблемы, чек-листы. **Начните с этого документа.** |
| 2 | **MTLS_PLATFORM_ACCESS.md** | Устройство защищённого канала: PKI (CA, серверные/клиентские сертификаты, сроки), выпуск и **отзыв сертификатов (CRL)**, файрвол хоста (DOCKER-USER), fail2ban, негативные тесты, таблица диагностики TLS-ошибок. Для тех, кто настраивает/чинит криптографию. |
| 3 | **PLATFORM_DEPLOY_GUIDE.md** | Развёртывание платформы **с нуля** (чек-лист нового сервера): этапы А (mTLS+WG+БД), Б (API), Г (License Studio), В (панель); авторизация (X-Client-CN/X-Club-Token), структура БД, эксплуатация (бэкапы, ротация), журнал «проблема → решение». |
| 4 | **REMOTE_ACCESS_WIREGUARD.md** | Удалённый доступ: схема туннелей, адресация 10.0.0.0/24, **выдача доступа админу** (peer), **подключение нового клуба** (пошагово, чек-лист), анатомия peer-конфига, отзыв доступа, диагностика handshake, **§8 — проверка «удалённый клуб» с телефона по LTE**. |
| 5 | **WG_PEERS.md** | Реестр пиров WireGuard платформы: пир ↔ IP ↔ кому выдан ↔ дата ↔ статус. Обновляется при каждой выдаче/отзыве. |

## Скрипты (deploy/platform/scripts/)

| Скрипт | Назначение |
|---|---|
| `gen_certs.sh` | Первичная генерация: CA + серверный сертификат + первый клиентский (при установке сервера) |
| `gen_client.sh` | Выпуск дополнительного клиентского сертификата админу (email → .p12) |
| `platform_admin_add.sh` | Добавить админа платформы: сертификат + CN в ADMIN_CNS + restart api (одна команда) |
| `platform_admin_remove.sh` | Отозвать админа: CN из ADMIN_CNS + CRL-отзыв + restart api/nginx (одна команда) |

## «Что читать, если…»

| Ситуация | Куда |
|---|---|
| Нужно выдать доступ новому админу | USER_GUIDE §1.2–1.3 (+ add-скрипт) |
| Админ уволился / потерян ноутбук | USER_GUIDE §1.4 (+ remove-скрипт) |
| Вход в клуб: «Войти», консоль, ключ | USER_GUIDE §3 (CLUB_ADMIN_KEY) |
| Подключить новый клуб сети | REMOTE_ACCESS §4 + USER_GUIDE §5 |
| Клуб/телефон не коннектится по WG | REMOTE_ACCESS §7 (диагностика handshake) |
| Новый сервер платформы с нуля | DEPLOY_GUIDE §3–8 (чек-лист) |
| Ошибки сертификатов (revoked/expired/400) | MTLS §6–7 |
| Хочу поменять TTL/пороги | панель → «Настройки» (USER_GUIDE §4) |
| Панель не открывается после изменений | USER_GUIDE §6 + DEPLOY_GUIDE §9 |

План развития платформы — раздел «Платформа» в `docs/ROADMAP.md`.
